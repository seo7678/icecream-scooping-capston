# Codex One-Shot Mission

이 저장소의 README와 `docs/` 문서를 먼저 읽고 현재 프로젝트 맥락을 이해하라.

목표는 “아이스크림 자동 로봇”을 만드는 것이 아니라, **아이스크림 판매 종사자의 반복 하드아이스크림 스쿠핑에서 높은 grip force와 반복 손목동작을 저감하는 적응형 반자동 스쿠핑 워크스테이션**을 실제 종합설계 수준으로 검증·구체화하는 것이다.

반드시 다음 순서로 진행한다.

1. 문제 존재 재검증
2. 기존 해결방법 조사
3. 특허/제품/논문 선행기술 조사
4. 사람 스쿠핑 동작 기구학 분해
5. 절삭/전단/마찰/점탄성 관점 root cause 분석
6. 최소 15개 구조 발산
7. 기존기술/복잡도/위생/속도 기준 Red Team
8. 최종 3개 후보 선정
9. 1~3 DOF 메커니즘 구체화
10. motor/gear/lead screw/shaft 등 engineering calculation
11. 부하 적응 제어 설계
12. portion control
13. V1 prototype/BOM
14. Manual vs Prototype 실험계획
15. FMEA/세척/안전
16. 경제성
17. 교수님 공격 질문 25개
18. Red Team 최종 판정
19. 최종 Capstone proposal 문서화

핵심 철학:

> 판단은 사람, 반복적인 힘과 궤적은 기계.

다음은 차별화로 인정하지 않는다.
- 모터 사용
- 자동으로 아이스크림 뜨기
- 가열
- 센서 추가
- AI 추가

선행기술과 실제 실패지점을 확인한 뒤에만 차별화를 정의한다.

가정값은 ASSUMPTION 표시하고, 없는 통계는 만들지 마라.

최종 연구질문:

> 사람의 위치판단 능력은 유지하면서, 높은 grip force와 반복 손목동작을 발생시키는 스쿠핑 구간만 저자유도 기계구조로 동력화하여 수동 스쿠핑 대비 작업자의 기계적 부하를 유의미하게 감소시키면서도 작업속도와 portion consistency를 유지할 수 있는가?
