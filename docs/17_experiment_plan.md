## 3. 핵심 실험 설계

### E0 — Drag force test (가장 먼저, 기계 없이)
- 장치: 수평 수동 슬라이드에 스쿱을 고정(pitch 고정, θ = 0), 깊이는 스페이서로 설정, 푸시풀 게이지로 당김(속도는 메트로놈으로 ~50 mm/s 유지).
- 요인: 온도 3 × 깊이 3 × 제품 2, 반복 5 → 90 stroke(4 L 통 ~6개).
- 산출: F_peak, F_mean → u = F/A(d). 온도당 u의 평균·95 % CI.
- **판정(G1):** −14 °C, d = 20 mm 평균 F < 60 N → C 우선 / 60–200 N → A·B / > 200 N → 온도관리 전제.
- 프로토콜: `experiments/protocols/P0-3_drag_force_test.md`

### E1 — 작업자 부하 (피험자 내 설계)
- 참가자: **12명**(대학생, 손·손목 부상 이력자 제외). 가능하면 매장 경력자 포함.
- 조건 4개: M3-std(매장 스쿱), M3-best(최선 수공구, 예: 열전도 스쿱), M2(접지-수동), M1(접지-동력). 온도 −14 °C(주), −18 °C(보조 블록).
- 순서: Latin square로 균형. 조건당 연습 3회 + 측정 8회. 블록 사이 2분 휴식.
- 표본 크기 근거: 쌍체 효과크기 d_z = 1.0, α = 0.05/3(Holm, 주요 비교 3개), 검정력 0.8 → n ≈ 12–14. **d_z는 가정**이며 E1 첫 4명으로 중간 점검(효과가 훨씬 작으면 n 증원).
- 주요 비교: M1 vs M3-best(H3), M2 vs M3-best(H2), M3-best vs M3-std(도구 효과).
- 분석: 선형 혼합모형 `KPI ~ 조건 × 온도 + (1|참가자) + (1|통)`, Holm 보정 대비, 효과크기와 95 % CI 보고. 감소율 = (M3-best − 장치)/M3-best × 100, 참가자 평균의 부트스트랩 CI.
- **판정:** H1(M3-best peak grip ≥ 30 %MVC), H2(M2 ≥ 50 % 감소), H3(M1 ≥ 80 % 감소)를 사전 판정선대로 판정.

### E3 — 기계 파라미터 연구
- Box–Behnken 3요인(온도, 최대 깊이, 이송 속도) × 3수준 = 15 조건 × 반복 3 = 45 stroke + 중심점 추가.
- 산출: F, τ_close, 질량, 성공률의 응답곡면. **n = ∂lnF/∂lnv** 추정(속도 요인) → G2.

### E4 — 궤적군·DOF
- 같은 목표 부피에서 T1 표준(dive–drag–정지 closing), T2 rolling close 60/80 mm(B 모사), T3 원호(진자 모사, z·x·θ 동시), T4 plunge + 회전(melon-baller 모사). −14 °C, 각 10회.
- **판정(H6, G2):** T1 성공률 ≥ 90 % → 2 DOF 확정. T2 ≥ 90 % 이고 n ≥ 0.3 → B 가능.

### E5 — 부하 적응
- 같은 온도에서 경도가 다른 두 제품 + 초콜릿 청크 제품, S0/S1/S2 각 10회.
- 산출: peak F, F > 150 N 횟수, 부피 달성률, 중단 횟수, 시간. 시뮬레이션(docs/14 §4)과 순위 비교.

## 4. 통제

| 항목 | 방법 |
|---|---|
| 온도 | 템퍼링 냉동고 ≥ 24 h 평형, 코어(5 cm) 목표 ± 1 °C, 시험 창 ≤ 3분, 매 stroke 표면 IR 기록 |
| 통 표면 | 스쿠핑 순서 규칙(가장자리부터 줄 단위), 표면 요철이 5 mm 넘으면 평탄화 |
| 제품 로트 | 같은 로트 사용, 로트 기록 |
| 스쿱 표면 | 매 stroke 전 같은 헹굼 절차(E8 제외) |
| 측정 영점 | 로드셀 매 블록 영점, 온도 기록 |

## 5. 윤리·안전

- **학교 IRB에 심의 필요 여부를 먼저 문의**(인간 대상 측정). 서면 동의, 중단 권리, 통증 시 즉시 중단.
- 매장 관찰·촬영은 점주·근무자 동의, 고객 얼굴 미촬영.
- 시험 아이스크림은 먹지 않음(폐기).
- rig 운전자는 안전교육 후, 가드·E-stop 점검표 확인.
