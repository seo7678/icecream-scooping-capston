## 1. 설계 하중 선정

| 하중 | 설계값 | 근거 |
|---|---|---|
| drag force F_x | **200 N**(하드웨어 상한), 운용 목표 ≤ 150 N | A01 케이스 중 hard(160 kPa × 907 mm² ≈ 145 N) + 여유 |
| 수직력 F_z | 0.5·F_x = 100 N | A04 |
| pitch 유지 토크 τ_hold | F·z_c = 200 × 0.023 = 4.7 N·m | calc §4 |
| closing 토크 τ_close | F·R = 200 × 0.035 = **7.0 N·m** | A05 |
| pitch 모터 정격 | ≥ 1.5 × 7.0 ≈ **10.5 N·m** → 기어드모터 정격 ≥ 8 N·m + 전류제한 10 N·m | SF 1.5 |

## 2. Sweep(x) 축

| 식 | 값 (F = 200 N, v = 100 mm/s) |
|---|---|
| T = F·p / (2π·η), SFU1610 (p = 10 mm, η = 0.9) | **0.354 N·m @ 600 rpm** |
| P = F·v | 20 W(기계) |
| 하드웨어 전류제한으로 F_max | 0.354 N·m ↔ 200 N (K_t = 0.05 N·m/A → I_lim ≈ 7.5 A) |

**선정:** SFU1610 볼스크류 + 24 V DC 60 W급(엔코더 부착), 하드웨어 전류제한.
- Tr10x2 사다리꼴 나사는 η = 0.31, **self-locking** → 전원 차단 시 손으로 뺄 수 없음(F6 위반) → sweep 축 부적합
- 스테퍼 + SFU1605는 1.36 kN까지 낼 수 있음 → 제품 부적합, V1에서만 기계식 과부하 요소와 함께

## 3. Pitch(θ) 축과 push-rod

| 항목 | 값 |
|---|---|
| ω (120°를 0.8 s) | 2.62 rad/s = 25 rpm |
| P = τ·ω (τ = 5.25 N·m) | 14 W |
| 모터 | 24 V 유성 기어드모터, 정격 ≥ 8 N·m @ ≥ 30 rpm, 엔코더 |
| push-rod 축력 (레버 l = 25 mm) | τ / l = 7.0 / 0.025 = 280 N |
| push-rod 좌굴(Ø8, L = 300 mm, 양단 핀) | P_cr = π²EI/L² = 4.26 kN → **SF ≈ 15** |

## 4. 스템

| 항목 | 값 (F = 200 N, F_r = 224 N, L_s = 300 mm) |
|---|---|
| 선정 | **304 튜브 Ø25 × 2** |
| σ_b = M·c/I | 87 MPa → 정적 SF_yield = 2.4 |
| 피로 기준 | 2×10⁶ 사이클, Kf ≈ 2 → 공칭 ≤ 50 MPa 목표. 운용 목표 F ≤ 150 N에서 σ_b ≈ 65 MPa → **목표 초과** |
| δ_tip | 1.08 mm @ 200 N, 0.54 mm @ 100 N |

**판단:** 운용 목표 F = 150 N에서도 피로 목표(50 MPa)를 넘는다. 제품은 **Ø25 × 3 (σ ≈ 50 MPa @ 150 N)** 또는 스템 길이 단축이 필요하다. V1은 Ø25 × 2로 시작하되 스트레인게이지로 실제 응력을 확인한다. → 요구 R1과 충돌하므로 docs/23 잔여위험에 기록.

## 8. 전류 → 힘 proxy

F_est = 2π·η_s·N·η_g·K_t·(I − I₀) / p. 효율이 15 % 틀리면 200 N에서 ±30 N 오차. **과부하 임계는 추정치 기준 0.8 × 하드웨어 한계**로 둔다(calc/load_adaptive_sim.py 초안에서 185 N 임계가 proxy 저독 10 % 때문에 한 번도 작동하지 않은 문제를 발견해 수정). I₀는 매 기동 시 공회전으로 재측정.
