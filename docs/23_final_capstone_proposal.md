# 23. 종합설계 최종 제안서

## 1. 프로젝트명

**하드아이스크림 스쿠핑 작업부하의 정량화와 반력접지형 2자유도 동력 스쿠핑 모듈의 설계·검증**
(Quantifying Hard-Ice-Cream Scooping Workload and Designing a Reaction-Grounded 2-DOF Powered Scooping Module)

## 2. 문제 배경

하드아이스크림 매장 직원은 디핑 캐비닛의 통에서 스쿱으로 아이스크림을 반복해서 뜬다. 한 스쿱은 절입 → 끌기 → 공 닫기 → 배출로 이루어지고, 이때 작업자는 아이스크림의 절삭저항을 손으로 공급하면서 그 반력이 손잡이에 만드는 모멘트와 축 토크를 grip과 손목으로 버틴다. 한국 배스킨라빈스 기준 싱글레귤러는 115 g, 파인트는 320 g이며, 매장은 1,700곳이 넘는다.

## 3. 문제 존재 근거 (재검증 결과, 근거 강도 표시)

| 근거 | 내용 | 강도 |
|---|---|---|
| Dempsey et al., *Appl Ergon* 2000 | 계측 스쿱으로 grip·손잡이 moment 측정. 주 결함 = 스쿠핑의 **나쁜 자세 + 높은 근력**. 온도가 **g당 누적 grip**에 유의 | 중 |
| 같은 연구 보상청구 분석 | 스쿠핑 ≈ 청구의 13–15 %, **1위는 넘어짐** | 약–중 |
| Howard & Conrad 1992 | 스쿠퍼 제2중수골 피로골절(손잡이 받침점 기전 추정) | 약(사례) |
| Shin 2019 | 한국 프랜차이즈 파트타이머의 손·팔·손목 부담 호소 | 약(질적, 원문 대조 예정) |
| IDFA 등 | 권장 디핑 −12 ~ −14 °C, 경도는 빙결률에 지수적 | 중 |

**주장하지 않는 것:** 질환 예방, 발생률, "세계 최초". **주장하는 것:** grip·손목 동작·손 힘 같은 **측정 가능한 물리량의 감소.**
세부 수치(현장 3명 43–52 % MGF 등)는 원문 미대조로 **발표 전 도서관 PDF로 확인**한다(docs/02).

## 4. 기존 해결방법

| 방법 | 줄이는 것 | 남는 것 |
|---|---|---|
| 적정 온도 관리 | 절삭저항 u 전체(가장 큰 레버) | 맛별 경도 편차, 반력 grip 구조 |
| 좋은 스쿱·Zeroll·가열 스쿱 | 표면 마찰·부착, 일부 자세 | 절삭 일, 반력 grip, closing 손목 회전 |
| 동력 손 스쿱(특허 1937–2005) | closing 회전 | **반토크가 손으로 되돌아옴**, 상용 생존품 없음 |
| 로봇팔(ARIS 등) | 전부 | 2천만 원대, ~1분/개, 전용 용기·보충 |

## 5. 기존 해결방법의 한계

- 모든 수공구는 절삭에 필요한 일 **W ≈ u·V**(u: 비절삭저항, V: portion 부피)의 경로와 마찰만 바꾼다. 그 일을 공급하고 반력을 버티는 주체는 여전히 손이다.
- 손에 드는 동력 공구는 작용-반작용 때문에 grip 부하를 없애지 못한다.
- 자동화는 사람을 완전히 빼는 방향뿐이고, 사람의 위치 판단을 남기면서 반력만 기계로 보내는 중간 단계 제품은 찾지 못했다.

## 6. 개발 필요성 — 조건부

필요성은 **증명 대상**이다. 적정 온도 + 최선 수공구에서도 부하가 남는지 먼저 잰다.

| 게이트 | 판정 |
|---|---|
| G0 | −14 °C·최선 도구에서 peak grip < 20 %MVC 그리고 절삭력 < 40 N → **기계 개발 중단**, 측정연구로 전환 |
| G1 | 절삭력 < 60 N → **무동력 C** / 60–200 N → **동력 A** / > 200 N → 온도관리 전제 |
| G2 | 속도민감도 n ≥ 0.3 이고 rolling close 성공 → **1 모터 B**로 원가절감 |

## 7. 목표

| 목표 | 판정선(사전 고정) |
|---|---|

## 8. 핵심 아이디어

> **판단은 사람, 반력과 반복 궤적은 프레임에 접지된 저자유도 기구.**

1. 작업자가 헤드를 원하는 통(웰)에 도킹하고 시작점을 고른다.
2. 절삭 반력은 **스쿱 → 스템 → z 잠금 → 헤드 프레임 → 웰 도킹 래치 → 캐비닛**으로 흐른다. 손에는 반력이 오지 않는다.
3. 스쿠핑 stroke(dive → drag → closing)만 **구동 2자유도(끌기 x, pitch θ)**가 수행한다.
4. 모터 전류로 부하를 추정해, 힘 상한을 넘으면 **깊이를 줄이고 stroke를 늘려 목표 부피를 채운다.**

## 9. 작동원리

스쿱 볼 중심 C를 표면 위 h에 잠그면 rim 최저점 깊이는 **d = R·cos θ − h** 이다(θ = 0에서 최대).

| 단계 | x | θ | 역할 |
|---|---|---|---|
| 배치 | 0 | θ₀ = acos(h/R) | rim이 표면에 닿아 기준 설정 |
| dive | 0 → 30 mm | θ₀ → 0 | 비스듬히 절입 |
| drag | 30 → ~180 mm | 0 (부하 시 ↑) | chip이 볼 안에서 curl |
| close | 정지 | 0 → 90–120° | rim이 앞쪽 구면 캡을 끊음 |
| lift/eject | – | 유지 → 과회전 | 홈에서 수직으로 빠짐 |

## 12. 기구학

- 과업 운동: 평면 (x, z, θ). z는 스트로크 중 잠금.
- 절삭 단면: A(θ, h) = 반축 R, R·cos θ인 타원의 표면 아래 면적. V = ∫A dx.
- 기준 stroke(가정): R = 35, h = 13 → d_max = 22 mm, A = 1,036 mm², 115 g에 stroke ≈ 182 mm.
- 1 모터 캠(B)의 한계: 압력각 tan α = a·dθ/dx → 레버 15–20 mm에서 closing ≥ 54–73 mm(rolling close만 가능).

## 15. 제어

- 상태기계: IDLE → TARE → ARM(접촉 기준) → DIVE → DRAG(깊이 적응 + 부피 적분) → CLOSE → HOLD → EJECT → HOME, 과부하 시 RETRACT/ABORT.
- 전류 proxy: F = 2π·η·K_t·(I − I₀)/p, 매 사이클 I₀ 재측정. **과부하 임계 ≤ 0.8 × 하드웨어 한계**(proxy 오차 반영).
- 시뮬레이션(가정 재료, 27조건): 150 N 초과 발생 — 고정 18회, 속도 적응 16회, **깊이 적응 9회**. 속도 적응은 힘을 거의 못 줄인다. 매우 단단한 조건은 어떤 전략도 실패 → **온도관리는 전제조건**.
- 안전: E-stop·hold-to-run·인터록을 드라이버 ENABLE에 하드와이어, 하드웨어 전류제한, 재기동 방지.

## 17. 차별화 (5줄)

1. 기존 동력 스쿱은 모두 손에 드는 공구라서 모터 반토크와 절입 반력이 작업자의 grip과 손목으로 돌아온다.
2. 기존 자동화는 사람을 빼는 대신 다자유도·전용 용기·~1분/개·2천만 원대를 받아들인다.
3. 우리 구조는 위치 판단은 사람에게 남기고, 반력은 웰 도킹 프레임으로 접지하며, stroke만 구동 2자유도로 수행한다.
4. 전류 기반 부하 추정으로 힘 상한 안에서 깊이를 줄이고 부피를 적분해 stroke를 늘리는 제어는 압력→진동 세기, 경도→캡슐 추출 선행기술과 다르다.
5. 효과는 반력 접지(M2)와 동력(M1)으로 분리해 측정한다. 특허성은 약하며, 가치는 공학적 기여와 측정에 있다.

## 21. 안전/위생

- 1차 방호는 **분리**(도킹 프레임 가드 + hold-to-run + 인터록). 힘 상한 200 N은 ISO/TS 15066 손 한계 140 N을 넘으므로 힘 제한만으로 안전하다고 주장하지 않는다.
- PLr(잠정): E-stop·hold-to-run·인터록 c.
- 식품 모듈 304, Ra ≤ 0.8 µm, 내부 R ≥ 3.2 mm, 공구 없는 분리, 숨은 공동 제거(FMEA에서 push-rod를 튜브 밖으로), 알레르겐 전용 모듈, 4시간 세척.
- FMEA 22개 모드, 상위: 숨은 공동(조치 완료), 알레르겐, 세척·미생물, 협착, proxy 드리프트, 파편. → docs/19

## 22. 경제성

- 제품 판매가 추정: 단일 스테이션 ~210–300만 원, 캐비닛 전체 ~380–510만 원(BOM × 2.5–3, 근거 없는 개략치). 로봇 대비 한 자릿수 이상 저렴.
- 과다배식 감소만으로의 회수: **portion당 5 g 이상 감소 & 하루 300 portion 이상 → ~7개월**, 1–2 g이면 회수 불가.
- 작업부하 저감은 실제 가치지만 금액화할 자료가 없음 → **근로환경 개선 설비**로 포지셔닝, 구매 주체는 가맹본부 가능성.
- 무동력 C가 채택되면 가격이 1/3 이하로 떨어진다.
