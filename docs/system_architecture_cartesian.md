# System Architecture — Cartesian Automatic Flavor-Selection Scooper

> 이 문서는 새 기준 아키텍처다. 권장안 요약과 결정 게이트는 `final_system_concept.md`. 작업자가 헤드를 직접 옮기던 이전 구조는 **Legacy Architecture M(수동 위치지정)** 으로 남기고(docs/11, 12, concept_brief 이전 판 `32daeaa`), 비교는 `architecture_comparison.md`에 있다.
> 숫자는 `calc/`의 **가정 하중·가정 치수** 결과다. 실측 전에는 결과가 아니라 설계 입력으로만 읽는다.

## 1. 한 줄 정의

> 작업자가 맛만 고르면, **3축 직교 위치결정기(X_M, Y_M, Z_M)** 가 그 맛의 통 좌표로 스쿠핑 헤드를 옮기고, 헤드는 **스쿱 피치 θ_s 하나**만 따로 움직인다. 절입–끌기–닫기는 X_M·Z_M·θ_s를 함께 보간한 궤적이며, 완성된 portion은 고정된 컵 스테이션으로 옮겨 저울 위에서 배출한다.

**이 기계를 "5축 로봇"이라고 부르지 않는다.** 정확한 표현은 다음과 같다.

| 구분 | 축 | 역할 |
|---|---|---|
| Global positioning | X_M, Y_M, Z_M (3) | 통 사이 이동, 표면 접근, 컵 스테이션 이동 |
| Local scooping actuator | θ_s (1) | 공격각 유지, 공 닫기(capture), 배출 |
| Scooping task DOF | 평면 3 (x_s, z_s, θ_s) | x_s = X_M − X_lane_start, z_s = Z_M − Z0(표면) 로 **전역축을 재사용** |
| 액추에이터 합계 | **4** | X, Y, Z, θ |

## 2. 용어

| 용어 | 정의 |
|---|---|
| XY Gantry | X/Y 가이드와 구동계 전체 |
| XY Carriage | X 빔 위를 달리는 X 캐리지(+ V1에서는 그 위의 Y 크로스슬라이드) |
| Z Carriage | Z 레일을 따라 오르내리는 Z 기둥(quill) |
| Scooping Head | Z 기둥 아래 끝의 기계 헤드: θ 기어드모터, 상부 레버, 클램프, 드립 우산 |
| Scoop End Effector | 음식에 닿는 부분: 스쿱 + 스템 + push-rod + 피벗 핀(공구 없이 분리) |
| Cup Station | 컵이 놓이는 고정 위치(매립형, 저울 내장) |
| Rinse Station | 스쿱 헹굼 고정 위치 |
| Tub Coordinate | 각 맛의 통 중심 좌표(기계 좌표계) |
| Safe Scoop Workspace | 통 안에서 스쿱이 벽·바닥에 닿지 않는 영역(keep-out 제외) |
| Home Position | X_H, Y_H, Z_H = 전원 투입 후 원점복귀 좌표(Z는 최상단) |
| Z_SAFE | 이 높이 이상에서만 XY 이동 허용 |

## 3. 전체 배치 (Diagram 1 — XY 갠트리 평면도, V1)

```
                        │
   ┌────────────────────────────── 고정 X 빔 (강관 100×50×4, 스팬 ~1,450 mm) ──────────────────────────────┐
   │  X 볼스크류 SFU2010 ══════════════════════════════════════════════════════════════ [NEMA23 폐루프]     │
   │         [X 캐리지 + Y 크로스슬라이드 + Z 기둥 + 스쿠핑 헤드]  ──▶ X_M (드래그 방향 = 빔 축)            │
   └───────────────────────────────────────────────────────────────────────────────────────────────────────┘
        ▲ 포스트                                                                                    ▲ 포스트
   ┌─────────┐ ┌───────────────────── 체스트 냉동고 위 데크(304, 단열) ─────────────────────┐ ┌──────────┐
   │ RINSE   │ │    ( TUB1 )            ( TUB2 )            ( TUB3 )                        │ │  CUP     │
   │ X 120   │ │    X 340               X 600               X 860       ← 모두 Y 0          │ │  X 1120  │
   │ 헹굼 도크│ │    Ø230 개구부         Ø230 개구부         Ø230 개구부                      │ │ 매립+저울 │
   └─────────┘ └────────────────────────────────────────────────────────────────────────────┘ └──────────┘
   HOME (X 0, Y 0, Z top)                                                  컵 베이 광전 센서 ──┘
```

좌표값은 **예시(ASSUMPTION)** 다. 실제 값은 Calibration Mode에서 등록한다(`coordinate_and_flavor_mapping.md`). 제품 비전은 이동 브리지(Y 장행정) + 2×4 통이다.

## 4. 측면 (Diagram 2 — Z 캐리지·헤드 측면도, 가장 깊은 스쿱 자세)

보수적 기하(컵이 데크 위 80 mm → Z_SAFE 140 mm) 기준. 컵 스테이션을 매립하면(Z_SAFE 60 mm) 데크 위 높이가 모두 80 mm 낮아지고 모멘트 레버는 807 → 727 mm로 줄어든다.

```
  데크 위 높이
  +1115 ┐ Z 기둥 상단 (최상단 위치일 때)
        │
   +730 ├──[Z 상부 블록]──┐  X 캐리지 / Y 크로스슬라이드 판
   +580 ├──[Z 하부 블록]──┘  ← 반력 모멘트가 여기서 갠트리로 넘어감 (레버 ~807 mm @ 최심)
        │  Z 기둥 (강관 60×60×4)   ← Z 볼너트 로드셀(표면 검출·F_z)
   +195 ├──[스쿠핑 헤드: θ 기어드모터 · 레버 · 클램프 · 드립 우산]
        │  스템 Ø30×3 (양끝 밀봉)  ∥  push-rod Ø8 (노출)
     0  ┼─ ─ ─ ─ ─ 데크 = 통 테두리 ─ ─ ─ ─ ─
        │
   −205 ┼  C (스쿱 피벗) — 가장 깊은 위치
   −227 ┼  드래그 힘 작용점 (C − 22 mm)
   −250 ┴  통 바닥
```

## 5. 동작 흐름

```
FLAVOR SELECT → LOOKUP (통 좌표 + 레인 + 표면 추정) → CHECK CUP (저울)
→ XY MOVE TO LANE START (Z ≥ Z_SAFE) → Z FAST → Z PROBE (로드셀 3 N) → Z0
→ DIVE (X·Z 보간, θ = −30°) → DRAG (X 진행, Z로 깊이 적응, 부피 적분) → CLOSE (θ −30° → +90°)
→ Z LIFT (≥ Z_SAFE) → XY MOVE TO CUP → Z DISPENSE → EJECT (θ −30° + 고정 빗 걸기 + X 후퇴)
→ PORTION CHECK (저울) → Z RETRACT → 다음 주문 또는 HOME
```

상태·전이 조건은 `control_state_machine.md`에 있다.

## 6. 핵심 설계 결정 (10문항에 대한 답)

| # | 질문 | 결정 | 근거 |
|---|---|---|---|
| 1 | 전역 XY 축으로 실제 drag까지 하는 것이 좋은가? | **예. 단, 드래그 축(X_M)이 볼스크류이고 드래그 방향을 빔 축과 맞출 때만.** 벨트 X로는 불가(GT2 작업장력 ~28 N, 200 N에서 ~10 mm 신장) | calc/output/scoop_load_path.md, gantry_motor_sizing.md |
| 2 | 헤드 안에 short-stroke x_scoop를 따로 두는 것이 좋은가? | **아니오(기본안).** 로컬 축은 전역 **구동계**만 하중 경로에서 빼고, **구조(기둥·블록·빔·스템)** 는 그대로 남긴다. 볼스크류 X에서 구동계 기여는 0.01 mm뿐. 로컬 축은 전역 XY를 벨트로 가볍게 만들 때만 의미가 있고, 그때는 XY 잠금이 추가로 필요하다(모터 5 + 잠금) | architecture_comparison.md §1 |
| 3 | Z 표면 검출은 무엇으로? | **Z 볼너트 인라인 로드셀, 임계 3 N, 마지막 10 mm를 10 mm/s로 접근.** 모터 전류(≥ 30 N)는 날이 아이스크림을 수 mm 눌러 표면 기준으로 쓸 수 없다 | calc/output/z_axis_sizing.md §3 |
| 4 | 파인 표면을 vision 없이 어디까지? | 스쿱마다 레인 시작점 1점 터치오프 + **자기 절삭 이력으로 만든 높이 지도(10 mm 격자)** + 드래그 중 힘 기반 깊이 적응 + 컵 저울 피드백. 사람이 손으로 판 깊은 구덩이, 이물, 맛 뒤바뀜은 **감지 불가**(운영 규칙으로 막음) | z_axis_surface_detection.md §4 |
| 5 | 한 지점만 파이는 문제 | **래스터 레인 + 층별 평삭**(레인 y = −40/0/+40 순환, 층 카운터). 나선·방사형은 요(yaw) 축이 필요해 기각 | calc/output/tub_lane_planner.md §2 |
| 6 | 자동 XY는 과도한 자동화인가? | **작업부하 문제만 보면 과도하다**(수동 위치지정 헤드로도 손 힘은 없어짐). 가치가 생기는 조건: 작업자 손이 사이클 동안 비어야 할 때(병렬 업무), 고정된 맛 세트, 밀폐형 기기가 허용될 때, 저울 기반 정량이 필요할 때 | architecture_comparison.md §2 |
| 7 | Cartesian이 로봇팔보다 정말 싸고 단순한가? | **예(구조·가격).** 액추에이터 4 vs 6–7, V1 BOM 추정 ~524만 원(냉동고 포함, 빌리면 ~479만 원) vs 협동로봇 본체만 4,400만 원대. 대가: 통 배치를 기계에 맞춰야 하고 기존 캐비닛에 넣을 수 없다 | research/components.md §6, BOM |
| 8 | 스쿠핑 반력을 XY 레일이 견디는가? | **용량은 충분(블록당 0.54 kN vs C0 17 kN), 강성이 문제.** 3D 프린터식은 200 N에서 스쿱 끝이 8–11 mm 밀림. 강관 기둥 + HG15 + 강관 빔 + 볼스크류 + Ø30 스템이면 ~1.0 mm | gantry_load_path.md |
| 9 | 표준 통을 그대로 쓸 수 있는가? | **예, 조건부.** 통은 데크 웰에 고정(옆힘 200 N), 벽 keep-out 때문에 기계는 통 부피의 약 60–80 %(격자 시뮬레이션 59 %, 면적 추정 83 %)만 뜨고 벽 링은 사람이 정리, 테이퍼 때문에 아래로 갈수록 레인이 짧아짐 | tub_lane_planner.md §1, §3, scoop_mechanism_compare.md |
| 10 | 식품 위를 움직이는 갠트리의 위생 | 모든 레일·스크류·벨트를 **드립 차단층 위**에 둔다: X 빔 전장 고정 드립 트레이, Y 이동 트레이, Z 기둥 벨로즈, 헤드 드립 우산. 밀폐 헤드, NSF H1 윤활, 식품 모듈 공구 없는 분리 | sanitation_architecture.md |

## 7. 축 구성과 구동계 (V1)

| 축 | 행정 | 구동 | 가이드 | 모터 | 브레이크/잠금 | 역할 |
|---|---|---|---|---|---|---|
| X_M | 1,150 mm | SFU2010 볼스크류 | HGR15 × 2 (빔 전면) | NEMA23 폐루프 ~2–3 N·m | 불필요(수평) | 통 간 이동 **+ 드래그**, X 볼너트 로드셀 = F_x |
| Y_M | ±80 mm (크로스슬라이드) | SFU1605 | HGR15 × 2 | NEMA17 폐루프 | 불필요 | 레인 이동 |
| Z_M | 400 mm | SFU1610 | HGR15 × 2 (기둥 측면) | NEMA17 폐루프 | **스프링 브레이크 + counterbalance(자중 × 1.05)** | 접근·깊이·들어올림·배출 높이, Z 볼너트 로드셀 = 표면 검출·F_z |
| θ_s | −30° ~ +90° (평행링크 유효 ±60°) | 유성 기어드모터 + 평행링크 push-rod | 피벗 핀 | 24 V DC ≥ 8 N·m, 엔코더, 전류센스 | 기어 자기유지 | 공격각·닫기·배출 자세 |

제품(2열 이상)에서는 Y를 **이동 브리지 + HTD 5M 벨트(3:1, 크로스샤프트 동기)** 로 바꾼다. 드래그가 X 방향이라 Y 구동은 옆힘(가정 60 N)만 받는다.

## 8. 이전 설계에서 바뀐 것과 유지된 것

| 항목 | Legacy M (수동 위치지정) | 현재 Cartesian |
|---|---|---|
| 위치 결정 | 작업자가 레일·밸런서로 헤드 이동, 웰 도킹 | X_M·Y_M 자동, 맛 → 좌표 조회 |
| 반력 접지 | 웰 도킹 래치(데크 높이) | 갠트리 구조 전체(레버 ~0.8 m) → **강성 설계가 핵심 과제로 바뀜** |
| 끌기(x) | 헤드 내부 볼스크류 | **전역 X_M** |
| 깊이 | z 잠금 + θ로 깊이(d = R cos θ − h) | **Z_M으로 깊이**, θ는 공격각 유지 |
| 공격 자세 | 개구부 앞(θ ≥ 0)에서 dive | **개구부 앞-아래(θ_s = −30°)** 로 lip 선행 절입 |
| 표면 기준 | rim 터치다운 후 수동 잠금 | 로드셀 터치오프 + 절삭 이력 지도 |
| 배출 | 작업자가 컵 위로 옮김 | 고정 컵 스테이션 + 저울 |
| 유지 | 식품 모듈(스쿱·스템·push-rod 분리), 외부 push-rod, 전류제한·가드 원칙, 가정 하중 50–200 N | 같음 |
