# Z Axis & Surface Detection

> 수치 출처: `calc/output/z_axis_sizing.md`, `tub_lane_planner.md`. 질량·절삭력·압입압력은 **ASSUMPTION**.

## 1. Z축의 역할

1. XY 이동 전 **Z_SAFE 이상**으로 헤드를 올림(충돌 방지 조건)
2. 통 위에서 표면 근처까지 빠르게 하강
3. **표면 접촉 검출**로 표면 기준 Z0 설정
4. 스쿠핑 중 **깊이 조절**(dive 경로, 부하 적응 시 Z 상승)
5. 들어올림, 컵 위 배출 높이 설정

## 2. 측면도 (Diagram 2 — Z 캐리지 상세)

```
            [NEMA17 폐루프 + 스프링 브레이크]      ← Y 크로스슬라이드 판에 고정
                    │ 커플링
              ┌─────┴─────┐
              │ SFU1610   │ 고정측 BK12
              │  볼스크류 │
              │           │      가스스프링(자중 × 1.05) ─┐
   [HGH15 블록]│  [볼너트]─┼─[로드셀 20 kg + 볼조인트]──┐  │
   ═══════════ │           │                          │  │
   [HGH15 블록]│           │                          ▼  ▼
              │           │        ┌───────────── Z 기둥 (강관 60×60×4) ─────────────┐
              │ 지지측 BF12 │        │  측면에 HGR15 레일 2줄 (블록은 판에 고정)          │
              └───────────┘        │  벨로즈 커버                                      │
                                   └───────────────┬──────────────────────────────────┘
                                                   │  헤드 브래킷
                                        [스쿠핑 헤드: θ 기어드모터 · 드립 우산]
                                                   │ 스템 Ø30×3 ∥ push-rod Ø8
                                                   ◖ 스쿱
```

- **로드셀은 볼너트와 Z 기둥 사이**에 두고 볼조인트로 축방향 힘만 받게 한다. 스쿠핑 모멘트(~161 N·m)는 HGH15 블록 4개가 받으므로 로드셀을 지나지 않는다. 3D 프린터의 "로드셀 노즐 프로브"와 같은 원리를 축방향으로만 쓴다.
- 같은 방식으로 **X 볼너트에도 로드셀**을 두어 드래그 힘 F_x를 직접 잰다(모터 전류 proxy 대신).

## 3. 구동 선정

| 항목 | 값 | 근거 |
|---|---|---|
| 행정 | 400 mm (Z_top ~160 → Z_min −205, 여유 포함) | calc §1 |
| 가동질량 | 7.3 kg → 자중 72 N (추정) | cartesian_model.MASS |
| 절삭 수직력 | ±100 N @ F_x 200 N (가정 k_v = 0.5) | A04 |
| 스크류 | SFU1610 (리드 10), 150 mm/s → 900 rpm | 역구동됨 |
| counterbalance | 가스스프링/정하중 스프링 = **자중 × 1.05** → 순 중력 −4 N(위로) | 전원·브레이크 동시 고장 시 **천천히 올라감(fail-safe up)** |
| 모터 | 폐루프 **NEMA17** (최악 축력 111 N → 0.2 N·m) | counterbalance 덕분에 소형 |
| 브레이크 | 스프링 작동 24 V, ≥ 0.25 N·m (NEMA17용 제품 `[SNIPPET]`) | 역구동 토크 0.005 N·m(균형), 0.1 N·m(균형 없음) |
| 최대 하강력 | NEMA17 0.45 N·m → ~254 N | 손 한계 140 N 초과 → 분리 필요 |

**셀프록 리드스크류(Tr10×2)를 쓰지 않는 이유:** 효율이 0.31이라 150 mm/s를 내려면 모터가 커지고, 셀프록이라도 브레이크 없이 정전 상태를 보장하는 설계는 아니다. 볼스크류 + 브레이크 + counterbalance가 속도·안전 모두 낫다.

## 4. 표면 검출 방식 비교

임계힘만큼 rim이 아이스크림을 누른 뒤에 접촉이 선언된다. 그 압입 깊이 δ가 절삭 깊이 오차가 된다(선접촉 근사, 압입압력 p 가정).

| 방법 | 임계힘 | δ (p = 1 MPa, 단단함) | δ (p = 0.3 MPa, 부드러움) | portion 흩어짐 | 비용 | 판정 |
|---|---|---|---|---|---|---|
| **Z 볼너트 로드셀** | 3 N | 0.03 mm | 0.31 mm | 0.2–2 % | 로드셀 + ADC | **채택** |
| 스프링 예압 + 마이크로스위치 | 10 N | 0.31 mm | 3.4 mm | 2–22 % | 최저 | 단단한 제품만 / 백업 |
| Z 모터 전류(서보) | ≥ 30 N | 2.8 mm | > 11 mm(모델 범위 밖) | 18 % ~ > 72 % | 0 | **기각** |
| 스테퍼 StallGuard류 | ≥ 50 N | 11 mm | 모델 범위 밖 | 수십 % | 0 | **기각** |
| 비접촉 ToF/초음파 | 0 N | – | – | 성에·결로·반사율로 mm급 보장 어려움(미검증) | 저 | 보조(통 유무·대략 수위) |
| 비전 | – | – | – | – | – | **사용 안 함**(고정 좌표로 해결 가능) |

δ의 평균은 보정할 수 있는 편향이다. 문제는 경도에 따른 δ의 흩어짐이고, 그래서 임계힘을 낮춰야 한다.

## 5. 접근·터치오프 절차

```
Z ≥ Z_SAFE에서 XY 이동 완료
→ θ_s = −30° (공격 자세: rim 최저점이 먼저 닿음)
→ Z 빠른 하강 (150 mm/s) : 목표 = Z_est + 10 mm        (Z_est: 절삭 이력 지도, 없으면 맛 테이블의 명목 표면)
→ 등속 10 mm/s 진입 후 로드셀 영점(tare)
→ ΔF ≥ 3 N 이 20 ms 지속 → 정지 (과주행 ~0.2 mm)
→ 표면 높이 S = Z_C − R·cos α + δ_bias            (δ_bias: 제품별 보정값, E0에서 측정)
→ Z_est보다 25 mm 이상 깊게 내려가도 접촉 없음 → NO_SURFACE 판정 (통 없음 / 거의 빔 / 큰 구덩이)
```

## 6. 파인 표면 — vision 없이 어디까지

기계는 **자기가 깎은 이력**을 안다. 이것을 격자 높이 지도로 들고 다니면, 카메라 없이도 대부분의 경우를 처리할 수 있다.

| 기능 | 방법 | 비용 |
|---|---|---|
| 절삭 이력 지도 | 통마다 10 mm 격자(~23 × 23셀). 스쿱 1회마다 절삭 단면으로 셀 높이를 깎음 | 소프트웨어 |
| 레인 시작점 1점 터치오프 | 매 스쿱, ~1.2 s | 로드셀 |
| 통 3점 프로브 | 통 장착 시, 수동 개입 후, 지도 오차가 클 때 | ~4 s |
| 드래그 중 깊이 적응 | F_x가 목표를 넘으면 Z 상승(힘 제한), 부피 적분으로 stroke 연장 | X 로드셀 |
| 컵 저울 피드백 | 예측 대비 실측 질량 → 맛별 보정계수, 오차가 크면 지도 재프로브 플래그 | 컵 로드셀 |

| 상황 | 대응 | 한계 |
|---|---|---|
| 새 통(평평) | 장착 시 3점 프로브 → 평면 지도 | 없음 |
| 중간 사용 통 | 지도 + 레인 시작 터치오프 | 지도와 실제 차이는 터치오프가 1점만 보정 |
| 거의 빈 통 | 테이퍼로 레인이 짧아짐 → 중앙 레인만, 필요 시 2 stroke. 바닥 여유 10 mm 도달 예측 시 "EMPTY" 경고 | 기계가 못 뜨는 벽 쪽 링(~17 %)은 사람이 정리 |
| 한쪽만 파인 통(기계가 판 것) | 지도가 알고 있음 → 가장 높은 레인부터 선택(층별 평삭) | – |
| 한쪽만 파인 통(사람이 판 것) | 레인 시작점이 우연히 걸리면 터치오프로 감지. 드래그 중 표면이 낮아지면 힘이 줄고 부피가 과대추정 → **저울이 미달 감지** → 3점 재프로브 | 사이 구간의 깊은 구덩이는 **사전 감지 불가** |
| 이전 스쿱의 구덩이 | 레인 패턴이 같은 줄을 연속으로 쓰지 않음 | – |
| 단단한 청크·얼음층 | 힘 급상승 → Z 상승·후퇴 | 청크를 "보지"는 못함 |
| 이물(스푼 등), 맛 뒤바뀜 | **감지 불가** | 운영 규칙: 기계 통에는 사람 스쿱 금지, 맛 재배치는 Calibration Mode로만 |
| 통 없음 | NO_SURFACE → NO_TUB 결함 | – |

**결론:** 고정 좌표 + 로드셀 터치오프 + 절삭 이력 지도 + 저울 피드백으로 기계 자신이 만든 표면 변화는 모두 처리된다. vision이 필요한 경우는 "사람이 기계 모르게 통을 건드린 경우"뿐이고, 이는 운영 규칙과 3점 재프로브로 막는다.
