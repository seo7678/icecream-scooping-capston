## 2. 차별화 가설 검증

| 가설 | 선행기술 대조 | 판정 |
|---|---|---|
| Human-in-the-loop 구조 | 손공구 반자동(D1, D2)이 이미 사람이 위치 지정 | **단독 폐기** — 반력 접지와 결합할 때만 의미 |
| **반력 접지(grounded) + 사람 위치지정** | 손공구는 접지 없음, 로봇·기계는 사람 위치지정 없음 | **유지** — 조합 미발견 |
| 선택적 동력 보조 | C02(반력암)는 산업용 일반기술 | 약함 — 접지 구조의 일부로만 |
| 저자유도 운동 합성 | 캠·링크 자체는 일반. 스쿱 stroke를 2 DOF(또는 1 DOF + rolling close)로 축약하고 **그 한계(압력각·closing 거리)를 정량화**한 것은 미발견 | **유지(공학적 기여)** |
| 전류/토크 기반 적응 이송 | 프리저 대셔 전류 제어는 있음. 스쿱은 미발견. 전류 jam 감지는 전동공구 일반 관행 | 약함 — **깊이 적응 + 부피 적분**과 결합할 때만 |
| **힘 상한 내 깊이 적응 + 부피 적분 stroke** | D6(진동 세기), D8(캡슐 추출 조정)과 다름 | **유지** — 자명성 공격 가능성은 있음 |
| 작업부하 저감 + 정량 결합 | 정량 가치는 미증명(docs/15) | **보류** — E3 결과 후 |
| 표준 통 최적화 워크스테이션(웰 도킹) | 전용 카톤·캡슐·전용 통 선행과 다름 | 유지(제품 비전 수준) |

## 3. 최종 차별화 진술 (5줄)

1. 기존 동력 스쿱(1937–2005 특허)은 모두 손에 드는 공구라서, 모터 반토크와 절입 반력이 다시 작업자의 grip과 손목으로 돌아온다.
2. 기존 자동화(로봇팔·전용 디스펜서)는 사람을 빼는 대신 다자유도, 전용 용기, ~1분/개의 속도, 2천만 원대 가격을 받아들인다.
3. 우리 구조는 위치 판단은 사람에게 남기고, 절삭 반력은 웰에 도킹한 프레임으로 접지하며, 스쿠핑 stroke만 구동 2자유도(끌기 x, pitch θ)로 수행한다.
4. 모터 전류로 부하를 추정해 힘 상한 안에서 절입 깊이를 줄이고, 부피를 적분해 stroke를 늘려 목표량을 채운다. 이 제어는 압력에 따라 진동 세기를 바꾸거나(KR20210015444A) 캡슐 추출을 바꾸는(US12343859B2) 선행기술과 다르다.
5. 이 차이가 유의미한지는 "grip과 손목 회전을 0에 가깝게 줄이면서 표준 통, 수동 수준 속도, 저가를 유지하는가"로 검증하며, 그 효과를 **반력 접지 효과(M2)와 동력 효과(M1)로 분리해 측정**한다.

## 4. 특허성에 대한 입장

- 특허로는 **약하다**(조합 발명, D1·D2 + D7·D9 자명성 공격 예상).
- 캡스톤의 가치는 특허가 아니라 ① 25년 만의 스쿠핑 부하 재측정, ② 접지·동력 효과의 분리 측정, ③ 저자유도 합성의 한계 정량화, ④ 깊이-부피 적응 제어의 실측 효과다.
- 출원을 원하면 V1 결과(특히 ④)를 보고 산학협력단과 상의한다.
