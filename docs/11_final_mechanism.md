# 11. Final Mechanism — Reference Architectures A, B, C

## 1. 공통 헤드 기하와 기구학

세 후보는 같은 스쿱 모듈을 쓴다. 차이는 x와 θ를 **무엇이 움직이느냐**뿐이다.

```
 측면도 (끌기 방향 +x →)

      ════════════[ 캐리지 ]════════════   ← x 가이드 (헤드 프레임)
                      ┃ ┃
          θ 입력 레버 ⊙ ┃ ┃  ← 스템(304 튜브, 양끝 밀봉) ∥ push-rod Ø8(스템 밖에 노출, FMEA #12)
                      ┃ ┃
                      ┃ ┃     평행사변형: 상부 레버 l = 25 mm = 하부 레버
                      ┃ ┃
                      ┗━⊙ C (스쿱 피벗, 볼 중심)
                        ◖── rim(날)
       ─ ─ ─ ─ ─ ─ ─ ─ ─│─ ─ ─ ─ ─ ─   아이스크림 표면 (z = 0)
                        │ h: C의 표면 위 높이 (z 잠금으로 고정)
                   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
```

**정의** (calc/scoop_model.py와 동일)

| 기호 | 의미 |
|---|---|
| θ | 스쿱 pitch. θ = 0: rim 평면 수직, 개구부가 +x를 향함. θ > 0: 개구부가 위로 기움 |
| h | C의 표면 위 높이. **스트로크 동안 z 잠금으로 고정** |
| d(θ) | rim 최저점 깊이 = R·cos θ − h. θ = 0에서 최대 d_max = R − h |
| A(θ, h) | 기운 rim을 x 방향으로 투영한 타원(반축 R, R·cos θ) 중 표면 아래 면적 = 끌기 1 mm당 잘리는 단면 |
| V | ∫ A dx (+ closing 캡) |

**스트로크 단계** (기준값 = ASSUMPTION, V1에서 최적화)

| 단계 | x | θ | 결과 |
|---|---|---|---|
| 0 배치 | 0 | θ₀ = acos(h/R) — rim이 표면에 닿음 | 사람이 헤드를 놓고 z 잠금 |
| 1 dive | 0 → 30 mm | θ₀ → 0 | 깊이 0 → d_max. 날이 비스듬히 들어가 plunge보다 peak 힘 작음(가설) |
| 2 drag | 30 → ~180 mm | 0 (A는 부하에 따라 0 ~ θ₀ 사이 조절) | chip이 볼 안에서 curl |
| 3 close | 정지(A) / 진행(B1, C) | 0 → θ₀(≈ 68° @ R=35, h=13)에서 rim이 표면 위로 나옴 → 90–120°까지 더 돌려 공을 볼에 앉힘 | rim이 앞쪽 구면 캡을 잘라 chip 끝을 끊음 |
| 4 lift | – | 유지 | 볼 바닥은 drag가 판 홈(단면 = A) 안에 있으므로 수직으로 걸림 없이 빠짐 |
| 5 eject | – | 과회전 + 고정 스트리퍼(시험 후 결정) | 공 분리 |

기준 수치: R = 35 mm, h = 13 mm → d_max = 22 mm, A ≈ 1,036 mm²(θ = 0), 115 g(ρ 0.65 가정) 스트로크 ≈ 182 mm (calc/output/load_adaptive_sim.md 헤더).

**핵심 관찰**
- θ = 0이 **최대 깊이 자세**다. 깊이는 θ의 짝함수(cos)이므로 θ = 0 근처에서 작은 pitch 흔들림은 깊이를 거의 바꾸지 않는다(2차). 깊이 적응은 θ를 수십 도 단위로 움직여야 한다.
- drag 중 절삭력은 C 아래 z_c(≈ 22–23 mm, d = 20–22 mm)에 작용해 **pitch 유지 토크 τ_hold = F·z_c**를 만든다(F = 150 N → 3.3–3.5 N·m). θ 구동계는 drag 내내 이 토크를 버텨야 한다(docs/13 §4).
- closing 동안 x를 멈추면 rim은 C 둘레의 구면만 쓸어 볼 외면이 재료를 밀지 않는다(볼 외면이 같은 구면 위에 있음).

## 2. Architecture A — 반력접지 2-DOF 동력 헤드 (주 설계안)

```
 평면도(위에서)                                 정면도
 ┌──────────── 헤드 프레임(4040) ───────────┐       ┌─────────────┐
 │ [θ 기어드모터]─레버                       │       │ 손잡이+트리거│ ← 사람
 │ [캐리지]══════ SFU1610 ═══════[x 모터]    │       │ [z 잠금]     │
 │   ┃스템                                  │       │   ┃ 스템     │
 └───┃──────────────────────────────────────┘       │   ◖          │
     ◖ → 끌기 방향                                   └─────────────┘
```

| 항목 | 사양(초안) | 근거 |
|---|---|---|
| x (sweep) | SFU1610 볼스크류, 스트로크 200 mm, 24 V DC 60 W급 + 엔코더, **하드웨어 전류제한 → F ≤ 200 N** | calc §2–3 |
| θ (pitch) | 24 V 유성 기어드모터 정격 ≥ 8 N·m @ ≥ 30 rpm + 엔코더, 전류제한 → τ ≤ 10 N·m. 스템 상단, push-rod 평행링크로 C에 전달 | calc §4–5 |
| z | **수동**: counterbalance(스프링/가스) + 잠금(캠 레버 클램프 또는 전자 브레이크). 헤드를 표면에 내려놓고 잠금 | 제품 모터 ≤ 2 |
| 반력 경로 | 스쿱 → 스템 → z 잠금 → 헤드 프레임 → **웰 둘레 도킹 플레이트(핀 2 + 래치)** → 캐비닛. 위치이동 암은 절삭 반력을 받지 않는다 | calc §11, docs/12 |
| 식품 모듈 | 스쿱(304) + 스템(V1 Ø25×2 / 제품 Ø25×3, 양끝 밀봉) + **외부 노출** push-rod Ø8 + 피벗 핀 Ø8, **공구 없는 퀵릴리스**로 통째 분리. 알레르겐용 예비 모듈 1벌 | H3, docs/19 #12·#14 |
| 센서 | 두 모터 전류(힘/토크 proxy), 엔코더, 리밋 스위치, 손잡이 enable 트리거, E-stop | docs/14 |
| 제어 | FSM + **깊이 적응 + 부피 적분**(S2) + 과부하 후퇴 | docs/14 |

장점: 궤적·깊이·closing을 소프트웨어로 바꿀 수 있어 **맛별 경도 차이에 적응**하고, 같은 하드웨어로 V1 실험 결과를 그대로 반영한다.
단점: 모터 2개와 제어기, 비용·안전 관리 부담.

## 3. Architecture B — 1 모터 + 캠 합성 (원가절감 파생안)

**B1 트랙캠:** x 모터 1개. θ는 캐리지에 달린 레버(a = 15–20 mm) 끝 롤러가 **고정 트랙**을 따라가며 θ = f(x)로 결정.

```
   ════[캐리지]══════════════▶ x (모터 1)
        ┃ 레버 a ─ 롤러 ─ ╭────────────╮
        ┃                  │ 고정 트랙 θ(x)│  ← 교체형 판(스쿱 스타일별)
        ◖
```

**계산 결과(calc/output/cam_feasibility.md):** tan α = a·dθ/dx. 압력각 30° 이하로 closing 120°를 만들려면
- a = 15 mm → closing 거리 ≥ 54 mm, a = 20 mm → ≥ 73 mm, a = 40 mm → ≥ 145 mm
- 롤러 접촉력 ~290–380 N, closing 구간에서 sweep 축 요구력 +110–150 N(closing 일 ≈ 11 J를 x 모터가 부담)
- → 사람처럼 짧게(≤ 30 mm) 꺾어 닫는 closing은 **불가**. "굴리며 닫기(rolling close)"만 가능.

**B2 시간 캠:** 한 캠축이 크랭크-슬라이더(x)와 판캠(θ)을 동시에 구동. 크랭크 사점 dwell 동안 판캠이 closing → 짧은 closing 가능. 대가: 캠축·링크·판캠 가공.

**B의 적응 한계:** 궤적이 고정이므로 조절 가능한 것은 모터 속도뿐이다. 재료 속도민감도 n이 작으면 속도를 줄여도 힘이 거의 안 준다(calc/output/load_adaptive_sim.md: S1). → **B는 n이 크고(≥ 0.3), rolling close로 공이 되는 경우에만 성립**(G2).

## 4. Architecture C — 무동력 접지 트랙캠 (저자동화 대안)

B1에서 모터를 빼고 캐리지에 **손잡이(레버비 λ ≈ 2)**를 단다. 사람이 당기면 트랙캠이 dive-drag-rolling close를 만든다.

| 항목 | 값 |
|---|---|
| 손잡이 힘 | F/λ (+ closing 구간 추가분). F = 60 N이면 ~30 N, F = 150 N이면 ~75 N + closing 55–75 N |
| 사람의 일 | 여전히 ≈ u·V(20–40 J/스쿱 가정) — **팔·어깨로 이전**될 뿐 |
| 손목 | 중립 파워그립, 회전 없음, 반토크 없음 |
| 적응 | 사람이 속도·재시도를 판단 |
| 장점 | 모터·전원·제어 없음, 가장 싸고 안전하고 세척 쉬움 |
| 단점 | F가 크면 팔 부하가 새 문제가 됨 → G1에서 F < 60 N일 때만 채택 |

## 5. A vs B (vs C) 비교

| 기준 | A (2 모터) | B (1 모터 + 캠) | C (무동력 캠) |
|---|---|---|---|
| 궤적 유연성 | 소프트웨어로 임의 x(t), θ(t) | 트랙판 교체로만 | 트랙판 교체로만 |
| 적응 | **깊이 적응 + 부피 적분** + 속도 + 후퇴 | 속도 + 후퇴 | 사람 판단 |
| 토크 | x ≤ 200 N, θ ≤ 10 N·m 각각 | x 모터가 closing 일까지 부담(+110–150 N 구간) | 사람이 부담 |
| 속도 | stroke ≤ 3 s 목표 | 같음(속도 적응 시 느려짐) | 사람 속도 |
| 제작 | 볼스크류 + 기어드모터(구매품 위주) | 트랙 가공(CNC/와이어) 또는 캠축 | 트랙 가공 |
| 비용 | 중 | 저–중 | 최저 |
| 위생 | 식품 모듈 동일, 구동부 비식품영역 | 동일 + 트랙·롤러 비식품영역 배치 필요 | 동일 |
| 제어 | FSM + PI(깊이) + 감시 | FSM + 속도 규칙 | 없음 |
| 새로움 | 깊이-부피 적응 제어(선행 미발견) | 캠 합성과 그 한계 정량화 | 반력 접지 수공구(선행 미발견) |
| 실험 가치 | **최고**(모든 변수 독립 제어) | G2 판정용 | G1 판정용 |

## 6. 개발 경로

```
V1 연구 rig (3축: z, x, θ — 모든 후보를 흉내)
   │  P1 실험: F(T), n, τ_close, rolling close 품질, 깊이 적응 효과
   ├── G1: F < 60 N ────────────▶ C 제작 (무동력)
   ├── G1: F ≥ 60 N ──▶ G2: n ≥ 0.3 & rolling close OK ──▶ B1 제작 (원가절감)
   │                    └─ 아니면 ─────────────────────▶ A 제작 (주 설계안)
   └── F > 200 N @ −14 °C ──▶ 온도관리를 전제조건으로, 장치 운용범위 재정의
```

**현재 설계 동결(docs/23):** 제품 아키텍처는 **A**로 동결하고, B·C는 실험 게이트가 열어줄 때만 진행하는 **조건부 분기**로 둔다. V1 rig는 A의 식품 모듈·스템·push-rod를 그대로 쓴다.
