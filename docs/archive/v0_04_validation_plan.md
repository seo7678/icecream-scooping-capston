# 04. Validation Plan

## 가장 먼저 증명할 것

1. 수동 스쿠핑에 실제 어느 정도 힘/토크가 필요한가?
2. 어떤 운동이 가장 큰 부담을 만드는가?
3. 단순 2DOF로 정상적인 한 스쿱을 만들 수 있는가?
4. 동력보조가 작업자 힘을 줄이면서 cycle time을 유지할 수 있는가?
5. 정량성이 수동보다 개선되는가?

## Baseline

Manual scoop.

## Prototype

Power-assisted / semi-automatic scoop.

## KPI

- peak force [N]
- average force [N]
- force-time integral [N·s]
- scoop torque [N·m]
- cycle time [s]
- scoop mass [g]
- mass CV [%]
- successful scoop rate [%]
- motor current [A]
- energy/cycle [Wh]

## 시험 변수 후보

- 아이스크림 온도
- 제품/경도
- scoop edge geometry
- feed speed
- scoop rotation speed
- penetration depth
- heated edge ON/OFF

## 핵심 비교

Force reduction [%] = (Manual - Prototype user force) / Manual × 100

실험 전에는 성능값을 임의로 만들지 않는다.
