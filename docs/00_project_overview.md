# 00. Project Overview

## 가칭

**아이스크림 판매 종사자의 반복 작업부하 저감을 위한 적응형 반자동 스쿠핑 워크스테이션**

## 문제정의

하드아이스크림의 반복 스쿠핑은 높은 손힘, 손목/전완의 반복동작, 절입·전단·비틀림 동작을 요구한다. 프로젝트의 목적은 질환 예방을 단정하는 것이 아니라, **스쿠핑 시 작업자가 직접 제공해야 하는 기계적 힘과 반복동작을 줄이는 것**이다.

## 사용자

- 하드아이스크림 전문점
- 아이스크림 프랜차이즈
- 카페/디저트 매장
- 반복적으로 하드아이스크림을 배식하는 종사자

## 제품 포지셔닝

완전자동 로봇이 아니라 **직원용 Power-Assisted / Semi-Automatic Scooping Workstation**.

작업자가 잘하는 것:
- 맛 선택
- 어느 위치를 뜰지 판단
- 컵/콘 배식

기계가 대신할 것:
- 절입력
- sweep force
- scoop rotation
- 반복 궤적
- 필요 시 정량 성형/자동 배출
