# 15. Portion Consistency — 반자동화의 두 번째 가치가 될 수 있나?

> 모델·표: `calc/portion_model.py` → `calc/output/portion_model.md`, `fig_portion_tradeoff.png`

## 1. 모델

```
m = ρ · k_p · V,   V = ∫ A(d(x), θ) dx (+ closing 캡)
CV_m² ≈ CV_ρ² + CV_kp² + (∂lnA/∂d · σ_d)² + (σ_L / L)²
```

| 변수 | 무엇이 정하나 | 기계가 통제? |
|---|---|---|
| D(=2R) | 스쿱 | 고정(설계) |
| d(깊이) | z 기준 + θ | **예** — 단 표면 요철이 σ_d를 만듦 |
| L(끌기 길이) | x | **예**(엔코더, σ_L ≈ 1–2 mm) |
| θ(t) 궤적 | θ 모터/캠 | **예** |
| ρ(overrun, 기포) | 제품·배치·통 위치 | **아니오** |
| k_p(curl 공극·압축) | 궤적·온도 | 부분적 |
| 경도 | 온도·배합 | 아니오(적응으로 대응) |

## 2. 결과

| 발견 | 수치 | 의미 |
|---|---|---|
| 같은 부피 → peak 힘 ∝ A, stroke ∝ 1/A | W = F·L ≈ u·V 고정 | 깊게·짧게 vs 얕게·길게는 **힘과 정량의 교환** |
| 깊이 1 mm 오차의 질량 민감도 | d = 15 mm: 9.5 %/mm · d = 20: 7.0 %/mm · d = 30: 4.4 %/mm | **깊게 자를수록 정량이 좋다**(대신 peak 힘↑) |
| 기계식 부피제어의 CV 예측 | 낙관 5.0 % · 기준 9.1 % · 비관 16.9 % (모두 ASSUMPTION) | **CV 하한 = √(CV_ρ² + CV_kp²)** — 부피를 아무리 정확히 해도 밀도 편차는 못 없앤다 |
| 사람 CV | **자료 없음** | 사람은 공 크기를 눈으로 보며 보정한다(시각 피드백) → 생각보다 낮을 수 있음 |

## 3. 수동 대비 실제 개선 가능성 — 정직한 평가

| 시나리오 | 결과 |
|---|---|
| 사람 CV가 10 % 이상 | 기계(기준 9 %)가 약간 낫거나 비슷 → **부가가치 약함** |
| 사람 CV가 15–20 % 이상 | 기계가 뚜렷이 나음 → 부가가치 있음 |
| 사람 CV가 5–8 % | 기계가 나쁘거나 비슷 → **정량은 가치에서 제외** |
| 매장이 저울로 최저중량을 맞춤(미확인) | CV보다 **top-up 횟수·과다 g**가 비용을 결정. 기계 portion을 목표보다 약간 크게 설정하면 top-up은 줄지만 과다 g가 늘어남 → 최적 설정점 = 목표 + k·σ_m |

**결론:** 정량은 **증명 전까지 부가가치로만** 둔다. 1차 가치는 작업부하 저감이다. P0-2에서 사람 CV·top-up·과다 g를 먼저 잰다.

## 4. 기계식 정량을 좋게 만드는 설계 규칙

1. **가능한 한 깊게 자른다**(힘 예산 안에서). A의 S2 제어는 힘 목표 안에서 최대 깊이를 쓰므로 정량에도 유리하다.
2. **부피 적분**으로 stroke 종료를 정한다(고정 길이 대신). 깊이가 줄면 자동으로 길어진다.
3. 표면 기준을 매 사이클 새로 잡는다(ARM 접촉 판정).
4. 통 표면을 평탄하게 유지하는 **스쿠핑 순서 규칙**(가장자리부터 줄 단위)을 운영 매뉴얼에 넣는다.
5. 파인트 이상은 덩어리 수 × 부피로 맞추고, **최종 확인은 매장 저울**(헤드에 무게센서 넣지 않음).
