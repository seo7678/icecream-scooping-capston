# Coordinates & Flavor Mapping

> 원칙: **통 위치가 고정되어 있으면 카메라가 아니라 기계 좌표로 해결한다.** 맛 → 통 → 좌표는 조회표이고, 통 안의 어디를 뜰지는 레인 패턴과 절삭 이력 지도가 정한다.

## 1. 좌표계

| 좌표계 | 원점 | 축 | 쓰임 |
|---|---|---|---|
| **Machine M** (X_M, Y_M, Z_M) | HOME 코너(X 0, Y 0), Z는 **데크(통 테두리) 평면 = 0** | X_M: 빔 축 = 드래그 방향 / Y_M: 레인·열 방향 / Z_M: 위 | 모든 이동 명령 |
| 공구점 | **스쿱 피벗 C** | – | Z_M은 C의 높이. 스쿱의 가장 낮은 점은 어떤 θ에서도 Z_M − R 이상 |
| **Tub-local t** (x_t, y_t, z_t) | 통 중심, 테두리 높이 | M과 평행 | X_M = X_tub + x_t, Y_M = Y_tub + y_t, Z_M = z_t + rim_z |
| **Scoop-local s** (x_s, z_s, θ_s) | 레인 시작점, 터치오프 순간의 C | x_s: +X_M, z_s: 위 | x_s = X_M − X_lane_start, z_s = Z_M − Z0 |
| **Cup C** (X_C, Y_C, Z_C) | 컵 중심, 컵 테두리 높이 | M과 평행 | 배출 높이 = Z_C + R + 15 mm |
| **Home H** (X_H, Y_H, Z_H) | (0, 0, Z_top) | – | 전원 투입 후 원점복귀 |

## 3. 맛 조회표 스키마

| 필드 | 예 | 설명 |
|---|---|---|
| flavor_id | `VAN` | 맛 코드 |
| name | Vanilla | HMI 표시 |
| tub_slot | 1 | 데크 웰 번호 |
| tub_center | (340.0, 0.0) | X_M, Y_M [mm] (Calibration Mode에서 등록) |
| rim_z | 0.0 | 테두리 높이 보정 [mm] |
| tub_geom | D_top 230, D_bottom 210, depth 250 | 통 모델(테이퍼) |
| surface_z_est | −62.0 | 절삭 이력 지도에서 온 다음 레인 표면 추정 [mm] |
| lane_set | [−40, 0, +40] | y_t 레인 |
| layer / lane_idx | 3 / 1 | 층 카운터, 다음 레인 |
| scoop_params | α 30°, d_max 28 mm, F_target 110 N | 맛별(단단한 맛은 d_max·F_target 낮춤) |
| k_portion | 1.00 | 저울 피드백 보정계수(§6) |
| allergen | false | true면 전용 식품 모듈 요구 |
| status | OK / LOW / EMPTY / DISABLED | 수위·결함 상태 |
| map_valid | true | 사람이 통을 건드렸거나 저울 오차가 크면 false → 3점 재프로브 |

예시 JSON과 조회·레인 선택 코드: `firmware/coordinate_map_example.md`.

## 4. 레인 패턴 — 같은 지점만 파는 문제

- **래스터 레인 + 층별 평삭:** 한 층 = 레인 y_t = −40 → 0 → +40 순환. 층이 끝나면 다음 층.
- **레인 선택:** 절삭 이력 지도에서 **표면이 가장 높은(재료가 가장 많은) 레인**부터 고른다. 지도는 스쿱마다 절삭 단면만큼 셀을 깎아 갱신한다(10 mm 격자, 통당 ~530셀).
- **레인 길이:** 수위가 낮아지면 테이퍼로 짧아짐(중앙 136 → 120 mm, ±40 레인 110 → 90 mm). 옆 레인에서 1 portion이 안 되면(부피 < 95 %) 중앙 레인만 쓰거나 2 stroke.
- **나선·방사형은 쓰지 않는다:** 드래그 방향을 바꾸려면 요(yaw) 축이 필요하다.

## 5. Keep-out (충돌 금지 영역)

| 영역 | 조건 |
|---|---|
| 통 벽 | C가 반경 r_c = R_tub(표면 깊이 + d) − R − 10 mm 원 밖으로 나가지 않는다 |
| 통 바닥 | C ≥ −250 + 10 + R = −205 mm |
| 통 사이·데크 | Z_M < Z_SAFE에서는 **현재 통의 safe workspace 안** 또는 컵/헹굼 스테이션 영역 안에서만 XY 이동 |
| 컵 베이 | Z_M < Z_SAFE로 들어가기 전 컵 베이 광전 센서가 "비어 있음"이어야 함 |
| 프레임·인클로저 | 소프트 리밋(각 축 하드 리밋보다 5 mm 안쪽) |

## 6. 원점복귀와 Calibration Mode

**원점복귀(전원 투입·결함 복구 후):**
1. **Z 먼저 위로**(Z 홈 스위치, 25 mm/s) — 통 안에 스쿱이 있을 수 있으므로
2. X 홈, 3. Y 홈 (각 25 mm/s, 스위치 후 2 mm 백오프, 5 mm/s 재접근)
4. HOME (0, 0, Z_top)로 이동, 폐루프 드라이버 위치오차 0 확인

**Calibration Mode(관리자 전용, 인터록 도어 열림 상태에서는 저속 조그만 허용):**

| 단계 | 방법 | 저장 |
|---|---|---|
| 통 중심 등록 | 식품 모듈 대신 **센터링 핀 도구**(원뿔 끝)를 장착 → 조그로 웰 중심의 표식에 맞춤 | tub_center |
| 테두리 높이 | 센터링 핀으로 데크/테두리에 터치오프(로드셀) | rim_z |
| 맛 배정 | HMI에서 슬롯 ↔ 맛 선택, 알레르겐 표시 | flavor_id, allergen |
| 통 교체 | 새 통 장착 후 3점 프로브 → 절삭 이력 지도 초기화 | surface map, layer = 0 |
| 컵·헹굼 스테이션 | 같은 방법 | cup, rinse 좌표 |
| 검증 | 각 좌표로 Z_SAFE에서 이동해 육안 확인 | 체크섬·버전과 함께 플래시 저장 |

**맛 위치 변경은 Calibration Mode로만 한다.** 운영 중 통을 바꿔 끼우면 기계는 알 수 없다(vision 없음) → 운영 규칙과 교육으로 막는다.
