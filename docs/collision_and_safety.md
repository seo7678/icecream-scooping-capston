# Collision & Safety

> 순서는 ISO 12100을 따른다. ① 본질안전설계 → ② 방호(가드·인터록·감지) → ③ 사용정보. 규격 조항 인용은 `research/standards.md`의 증거 태그를 그대로 따른다.
> 이 문서는 **사람**(작업자·손님)과 **기계·제품**(통, 컵, 헤드)을 나눠 다룬다. Z_SAFE 규칙은 기계·제품 보호용이며, 사람 보호 기능으로 세지 않는다.

## 1. Legacy와 무엇이 달라졌나

| 항목 | Legacy M (수동 위치결정) | Cartesian (자동 XY) |
|---|---|---|
| 동작 개시 | 작업자가 트리거를 누르는 동안만(hold-to-run) | 맛 버튼 한 번 → **자동으로 여러 축이 움직임** |
| 작업자 손 위치 | 손잡이 위(동작 중 항상 접촉) | 동작 중에는 기계 밖 |
| 1차 방호 | hold-to-run + 도킹 인터록 | **인클로저로 분리** + 도어 인터록 + 컵 베이 존재감지 |
| 최대 구동력 | 드래그 축만 | X 1,131 N, Y 358–509 N, Z 254 N (`gantry_motor_sizing.md`, `z_axis_sizing.md`) |

모든 축의 최대 힘이 ISO/TS 15066의 손·손가락 준정적 한계 140 N `[MULTI]` 보다 크다. 그래서 **힘 제한으로 안전하다고 주장하지 않는다.** 사람이 움직이는 축에 닿을 수 없게 하는 것이 1차 방호다.

## 2. 인클로저와 접근 (평면)

```
 ┌──────────────────────────── 폴리카보네이트 인클로저 ─────────────────────────────┐
 │  X 빔 + Y 크로스슬라이드 + Z 기둥 (모든 가동부는 이 안)                          │
 │                                                                                  │
 │   [RINSE]     ( TUB1 )        ( TUB2 )        ( TUB3 )      ║ 칸막이 + 헤드 슬롯 ║ │
 │                                                             ║ (Z_SAFE 높이)      ║ │
 ├────────────── 인터록 도어(통 교체용, 경첩) ─────────────────╫────────────────────┤ │
 │                                                             ║   ┌──────────┐     │ │
 │  E-stop ●  (작업자 쪽 전면, 도어 밖)                         ║   │ 컵 베이   │ ◀── 유일한 상시 개구
 │  HMI [VAN][CHO][PNB][START/STOP]                            ║   │ 2빔 광전  │     │ │
 └─────────────────────────────────────────────────────────────╨───┴──────────┴─────┘
```

- **도어(통 교체·청소):** 인터록 스위치 2개(이중 채널) → 안전 릴레이 → 드라이버 STO + 주 접촉기. 도어가 열린 상태에서는 Calibration Mode의 저속 조그(≤ 25 mm/s, hold-to-run)만 허용한다.
- **컵 베이:** 작업자가 컵을 놓는 유일한 상시 개구다. 헤드가 들어오는 **칸막이 슬롯**(Z_SAFE 높이, 스템과 헤드가 지나갈 폭)이 있어서, 베이 안의 손이 슬롯을 통해 기계 내부에 닿을 수 있다. 그래서 **베이 2빔 광전 센서는 전 축 STO에 하드와이어**한다(Z만 막는 것으로는 부족).
- 그 결과 V1에서는 **기계가 움직이는 동안 다음 컵을 놓을 수 없다.** 처리량 손실은 컵 놓기 ~3 s/스쿱(`motion_and_cycle_time.md`)이며, 제품 단계에서 회전 컵 캐러셀이나 2-베이 구조로 푼다.

## 4. 안전기능과 PLr (잠정, ISO 13849-1 위험그래프)

| 안전기능 | 입력 | 출력 | S | F | P | PLr | 구현 |
|---|---|---|---|---|---|---|---|
| SF1 비상정지 | E-stop(ISO 13850, 정지범주 0) | 드라이버 STO + 주 접촉기 | S2 | F1 | P1 | **c** | 안전 릴레이, 이중 채널 |
| SF2 도어 인터록 | 도어 스위치 2개 | STO | S2 | F1 | P1 | **c** | 안전 릴레이 |
| SF3 컵 베이 존재감지 | 2빔 광전(또는 라이트 그리드) | **전 축** STO | S2 | F2(컵을 놓을 때마다 접근) | P1 | **c–d** | 안전 등급 센서가 이상적. V1은 일반 광전 + 안전 릴레이(**PL 미달 가능성 명시**) |
| SF4 Z 유지 | 무전원 | 스프링 브레이크 + counterbalance | S2 | F1 | P2(통 안에 손을 넣을 일 드묾) | **b–c** | 기계식 이중(브레이크 + 1.05 균형) |
| SF5 재기동 방지 | 리셋 버튼 | 안전 릴레이 수동 리셋 | – | – | – | SF1–3에 포함 | – |
| 비안전(기계 보호) | Z_SAFE 게이트, keep-out, 30 N 이송 충돌 감지, F_STOP | 펌웨어 정지 | – | – | – | PL a 수준(사람 보호로 세지 않음) | `firmware/state_machine.md` §3 |

F2 때문에 SF3가 가장 높은 등급을 요구한다. 작업자가 하루에 수백 번 손을 넣는 곳이 컵 베이이기 때문이다. **제품 단계에서는 안전 등급 라이트 커튼(Type 2 이상)이 필요하다**(분석, 규격 조항 미확인).

## 5. Z_SAFE 규칙 (기계·제품 보호)

```
if Z_M < Z_SAFE:  XY MOVE 금지
  예외 1) state == SCOOP_DRAG 이고 목표점이 현재 통의 safe workspace 안
  예외 2) state == EJECT 이고 목표점이 컵 베이 안, 베이 빔 비어 있음
Z_SAFE = max(0, 컵 테두리 높이) + R(35) + 25 = 60 mm (컵 매립) / 140 mm (컵 올림)
```

- **구현 위치 3곳:** ① 계획 단계 경로 검사(`coordinate_map_example.md` §5), ② 실시간 XY 게이트 `request_xy_move()`(`state_machine.md` §3.1), ③ 이송 중 30 N 충돌 감지.
- **원점복귀는 Z가 먼저 위로 간다.** 전원 투입 시 헤드가 통 안에 있을 수 있다.
- Z_SAFE는 통 테두리·데크·컵 위를 지날 때 스쿱 최저점(C − R)이 장애물보다 25 mm 위에 있게 하는 값이다. 통 안의 표면 높이와는 무관하다.

## 6. 속도·한계

| 동작 | 속도 | 근거 |
|---|---|---|
| XY 이송 (Z ≥ Z_SAFE) | 250 mm/s, 1 m/s² | 사이클·임계속도 |
| Z 빠른 이동 | 150 mm/s | – |
| 표면 접근(마지막 10 mm) | 10 mm/s | 압입 오차 ≤ 0.3 mm |
| 컵 베이 하강 | 50 mm/s | 컵 충돌 에너지 감소 |
| 드래그 | 80 mm/s | 절삭 |
| 원점 | 25 mm/s → 5 mm/s 재접근 | – |
| 도어 개방 조그(Calibration) | ≤ 25 mm/s, hold-to-run | 관리자 전용 |

| 한계 | 값 |
|---|---|
| 하드 리밋 | X·Y·Z 양끝 스위치 6개(홈 겸용 포함) → STO |
| 소프트 리밋 | 하드 리밋 5 mm 안쪽 |
| θ 범위 | −32° … +92°(평행링크 ±60° + 여유), 기계적 스토퍼 |
| 드라이버 전류 | X: 드래그 200 N에 해당하는 토크 × 1.2까지만 |
| 정지시간 | **측정 전.** V1에서 250 mm/s 이송 중 STO 후 관성 이동 거리를 재고, 도어 인터록에 잠금(guard locking)이 필요한지 판단 |

## 7. 검증 시험

| 시험 | 방법 | 통과 기준 |
|---|---|---|
| S-1 E-stop | 모든 상태에서 E-stop | 전 축 STO, Z 브레이크 잠김, 리셋 없이는 재기동 안 됨 |
| S-2 도어 | 이송·드래그 중 도어 개방 | STO. 관성 이동 거리 기록 |
| S-3 베이 빔 | 이송·배출 중 베이에 손 모형 | 전 축 STO ≤ 50 ms, 이동 ≤ 5 mm(측정) |
| S-4 Z_SAFE | Z_SAFE − 1 mm에서 XY 명령 주입 | 100 % 거부, 로그 |
| S-5 정전 | 드래그 중 전원 차단 | 헤드가 떨어지지 않음(위로 천천히) |
| S-6 충돌 | 이송 경로에 스펀지 블록 | 30 N에서 정지 |
| S-7 과부하 | 냉동 왁스 블록 | F_STOP에서 정지 + Z 상승 |

잔여 위험과 사용정보(교육, 표지)는 V1 시험 후 위험성평가 표로 정리한다. **이 문서는 안전을 보장한다고 주장하지 않는다.** 식별한 위험, 그 대책, 측정할 값을 적을 뿐이다.
