## 4. 차별화 — 쓸 수 있는 말과 못 쓰는 말

**못 쓰는 말:** 최초·유일성 주장. 스니펫 수준 조사로는 없음을 증명할 수 없다.

**쓸 수 있는 말(근거 범위 안):**
- "조사한 범위(웹 검색 55회, 스니펫 수준)에서는 **팔 없이 Cartesian 갠트리로 여러 표준 통의 하드 아이스크림을 뜨는 구조를 찾지 못했다.** 확인된 제품·연구는 모두 로봇 팔이다."
- "구성요소 대부분은 따로 개시되어 있다. 차별점은 **조합과 제어 방법**에 있다."

**방어 가능성이 있는 조합(제어 방법):**
1. 통마다 접촉(로드셀)으로 표면 기준을 잡고, **절삭 이력 지도**로 다음 레인과 Z_est를 정하는 방법(E4 + E5)
2. 갠트리 X축 드래그와 θ 닫기 시점을 **부피 적분**으로 정하는 방법(E3)
3. 컵 무게로 맛별 보정계수를 갱신해 **다음 스쿱의 목표 부피**를 바꾸는 방법(E6, E5와 결합)

심사관은 P1(통 스쿠핑 로봇) + P3(갠트리 + 계량) + 음료 로드셀로 자명성을 주장할 수 있다. 그래서 위 세 가지도 **"가능성"** 수준이다.

**특허가 아닌 공학적 차별화**(캡스톤 발표에서 더 중요):

| 항목 | 값 | 근거 |
|---|---|---|
| 액추에이터 수 | 4(X, Y, Z, θ). 협동로봇 6축 + 그리퍼 대비 | `architecture_comparison.md` §3 |
| 시제품 비용 | ~524만 원(냉동고를 빌리면 ~479만 원) vs 협동로봇 본체만 ~4,400만 원 `[SNIPPET]` | BOM, `research/components.md` |
| 설계 규칙 | 드래그 방향 = 빔 축, 로드셀은 볼너트(모멘트 경로 밖), 강성 지배 | `gantry_load_path.md` |
| 측정 근거 | 드래그 힘·깊이·portion을 직접 측정하는 시험 계획(E0–E4) | `docs/17_experiment_plan.md` |

## 5. 위험과 조치

| 위험 | 종류 | 내용 | 조치 |
|---|---|---|---|
| **R1 Dexai US11597084B2** | **FTO(실시 위험)** | 등록 특허. "자유공간 낮은 토크 / 스쿠핑 중 상황별 높은 토크"가 우리 펌웨어의 상태별 힘 한계와 겹칠 수 있다 | 청구항 원문 확인(독립항의 구성: 팔? 토크 한계 전환 조건?). 겹치면 회피안: 힘 한계를 **상태가 아니라 위치(Z < 표면 기준)** 로 전환하거나, 이송 충돌 감지를 힘이 아닌 **추종 오차**로 대체 |
| R2 P1 + P3 조합 | 신규성·진보성 | 구조 개념 자체는 자명하다고 볼 수 있음 | 출원을 고려한다면 제어 방법(§4의 1–3)을 중심으로 |
| R3 Niska P2 와이퍼 | FTO | 내부 와이퍼 배출. 우리 1순위 배출은 **외부 고정 빗**이라 원리가 다르지만, 예비안(스쿱 내부 디셔형 밴드)은 겹칠 수 있음 | 청구항 확인 전에는 내부 밴드 예비안을 쓰지 않음 |
| R4 P6 공개일 | 신규성 | 접촉 표면 측정 + 계량 흐름이 거의 같음 | GitHub 공개일 확인 |
| R5 조사 범위 | 방법론 | 스니펫만, 중국 실용신안 약함 | Espacenet/KIPRIS에서 CPC **A23G9/28, A23G9/22, B25J9/026** 분류 검색. ROBOTICECREAM 기구학 확인 |

**가장 큰 선행기술 위험은 R1이다.** 신규성(R2)은 캡스톤에서 주장하지 않으면 되지만, R1은 제품을 만들어 팔 때 실제로 문제가 될 수 있는 등록 특허다.
