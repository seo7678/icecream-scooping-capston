# 00. Executive Summary

**프로젝트:** 하드아이스크림 스쿠핑 작업부하의 정량화와 반력접지형 2자유도 동력 스쿠핑 모듈의 설계·검증
**상태 (2026-09-26):** 문제 재검증·선행조사·구조 선정·계산·실험계획 완료. **실측 데이터 0건** — 다음 단계는 P0 측정(docs/24).

## 1. 결론 한 문단

하드아이스크림 스쿠핑이 높은 근력과 나쁜 자세를 요구한다는 근거는 있다(중간 강도). 다만 한국 매장에서의 크기와 발생률 자료는 없다. 좋은 스쿱과 가열 스쿱은 마찰과 자세만 바꾸고, 절삭에 필요한 일(W ≈ u·V)과 손잡이 반력은 그대로 손에 남긴다. 동력 손 스쿱은 1937년부터 특허가 반복되었지만, 반토크가 손으로 돌아오는 구조라 상용 제품으로 살아남지 못했다. 그래서 이 프로젝트는 **위치 판단은 사람에게 남기고, 반력은 웰에 도킹한 프레임으로 받고, 스쿠핑 stroke만 구동 2자유도(끌기 x, pitch θ)로 수행하는 헤드**를 주 설계안(A)으로 동결했다. 무동력(C)과 1모터 캠(B) 대안도 버리지 않았고, 결정 게이트 G0–G2에서 **측정값으로 고른다.** 가장 먼저 할 일은 스쿱 절삭력을 처음으로 직접 재는 것이다(P0-3). 문헌에는 이 값이 없고, 두 가지 추정은 5–15배 차이가 난다.

## 2. 최종 성공 기준 12문항에 대한 답

| # | 질문 | 답 (근거 문서) |
|---|---|---|
| 1 | 문제가 실제로 존재하는가? | **예, 중간 강도.** 계측 연구(Dempsey 2000: 높은 근력·나쁜 자세, 온도↓ → g당 누적 grip↑), 사례보고, 한국 질적 사례. 발생률 없음, 청구 1위는 넘어짐. (02) |
| 2 | 기존 스쿱·온도관리로 왜 충분/부족한가? | 온도가 가장 큰 레버이고 우리 장치도 이를 전제한다. 도구는 일과 반력 구조를 바꾸지 못한다. 충분한지는 **통제 비교 자료가 없어 판정 불가** → P0-2·E1에서 "최선 도구 + 적정 온도"를 baseline으로 측정. (03) |
| 3 | 굳이 새로운 기계가 필요한가? | **조건부.** G0(최선 조건 peak grip < 20 %MVC 그리고 F < 40 N이면 중단), G1(F < 60 N이면 무동력 C). (01 §7) |
| 4 | 자동화 수준은 왜 이 정도인가? | 문제는 위치 판단이 아니라 반복되는 힘과 반력이다. 손공구 동력화는 반력을 못 없애고, 완전자동은 비용(2천만 원대)·속도(~1분/개)·전용 용기 문제를 안는다. 반력을 접지한 저자유도 반자동이 최소 개입이다. (03, 10) |
| 5 | 기계가 무엇을 대신하나? | 절입·끌기 힘, closing 토크, **그 반력(grip으로 버티던 것)**, 부하 상태의 손목 회전. 사람은 맛·위치 판단, 도킹, 컵, 배출 트리거, 파인트 눌러담기를 계속 한다. (06 §5) |
| 6 | 최소 자유도는? | 과업은 평면 3 DOF(x, z, θ). z를 표면 기준으로 잠그면 **구동 2 DOF**. θ를 캠에 새기면 1 DOF까지 가능하지만, closing을 ≥ 54–73 mm rolling close로 바꾸고 깊이 적응을 포기해야 한다. (06, 11, calc/cam_feasibility) |
| 7 | 기존 특허/제품과 무엇이 다른가? | 손공구 선행(US4758150 등)은 반력이 손으로, 로봇 선행(US20240245265A1, US12343859B2)은 사람을 뺀다. **반력 접지 + 사람 위치지정 + 힘 상한 내 깊이 적응·부피 적분** 조합은 찾지 못했다. 특허성은 약하다. (04, 20) |
| 8 | 필요한 힘·토크는? | **미측정.** 가정 케이스 50–200 N으로 사이징: x 0.354 N·m @ 600 rpm(SFU1610), θ ≥ 8 N·m 기어드모터, 전류제한 200 N / 10 N·m. (13) |
| 9 | 학부생이 만들 수 있나? | 예. 구매품 위주 3축 rig, ~293–327만 원(추정). (16, BOM) |
| 10 | 무엇이 몇 % 좋아졌는지 어떻게 증명? | 참가자 12명 피험자 내 설계: 수동(표준/최선) vs 접지-수동 vs 접지-동력, 통 포스 플랫폼 공통 기준, 혼합모형 + Holm, 판정선 사전등록(손 힘 ≥ 80 %↓, grip ≤ 10 %MVC, 손목 excursion ≥ 50 %↓, 사이클 ≤ ×1.2). (17) |
| 11 | 세척·안전은 현실적인가? | 식품 모듈을 공구 없이 분리, 304, 숨은 공동 제거(FMEA에서 push-rod를 튜브 밖으로 변경), 알레르겐 전용 모듈. 안전은 **분리 우선**(가드 + hold-to-run + 인터록). 200 N은 손 한계 140 N을 넘으므로 힘 제한만으로 안전하다고 주장하지 않는다. (19) |
| 12 | 매장이 살 이유가 있나? | **아직 증명 안 됨.** portion당 과다배식 ≥ 5 g 감소 & 300 portion/일이면 ~7개월 회수, 1–2 g이면 회수 불가. 작업부하 가치는 금액화 불가 → 근로환경 설비로 포지셔닝, 가맹본부가 구매 주체일 가능성. (18) |

## 3. 핵심 설계 결정

| 결정 | 이유 |
|---|---|
| 범위를 캐비닛 전체 → **단일 웰 모듈 + 3축 연구 rig**로 축소 | v0는 Red Team에서 FAIL 4개(docs/22) |
| 비교 기준 = **적정 온도 + 최선 수공구** | 허수아비 비교 방지 |
| **반력 접지**(웰 도킹 래치 ≥ 0.5 kN) | 손공구 선행의 공통 약점 해결, 위치이동 암은 가벼운 밸런서로 충분 |
| 제품 모터 ≤ 2, Z는 수동 잠금 | 최소 DOF 분석 |
| 가열·비전·무게센서 삭제, ejector는 시험 후 | 선행 풍부 / 불필요 / 매장 저울 존재 |
| **깊이 적응 + 부피 적분** 제어 | 시뮬레이션: 150 N 초과 18 → 9회. 속도 적응은 효과 작음 |
| 과부하 임계 ≤ 0.8 × 하드웨어 한계 | proxy 저독 시 판정 불능 문제 발견 |
| push-rod 외부 노출, 스템 밀봉, 알레르겐 모듈 | FMEA |
| 스템 Ø25×3(제품) | 150 N에서 Ø25×2는 피로 목표 초과 |

## 4. 가장 위험한 가정과 가장 중요한 다음 실험

## 5. 조사의 한계 (정직하게)

이번 조사는 클라우드 세션의 네트워크 정책 때문에 **논문·특허 원문을 열람하지 못하고**, 검색 결과 요약만으로, 세션당 200회 검색 한도 안에서 이루어졌다. 모든 근거에 `[MULTI]`/`[SNIPPET]`/`[UNCERTAIN]`/`[미검증]` 태그를 달았고, 원문 대조를 P0-0으로 첫 작업에 넣었다.
