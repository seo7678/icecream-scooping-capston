# 16. Prototype V1 — 3축 연구 rig + 단일 웰 스테이션

## 1. V1이 답해야 할 질문 (만드는 이유)

| 질문 | 게이트 |
|---|---|
| 적정 온도에서 스쿱 절삭력 F·토크 τ는 얼마인가? 온도에 따라 어떻게 변하나? | G1 |
| 속도를 줄이면 힘이 줄어드는가(n)? rolling close로 공이 되는가? | G2 |
| 2 DOF(x, θ) + z 잠금으로 공이 되는가(H6)? 1 DOF(캠 모사)로는? | DOF 확정 |
| 반력 접지만(M2)과 접지+동력(M1)은 수동(M3) 대비 작업자 부하를 얼마나 줄이나? | H2, H3 |
| 깊이 적응(S2)이 실제로 peak 힘을 줄이나? 부피 적분 정량은 몇 % CV인가? | 제어·정량 |

**V1은 식품 제품이 아니다.** 역학 검증용 연구 장비이며, 시험한 아이스크림은 먹지 않고 폐기한다(H8). 그래도 식품접촉 부품(스쿱·스템·push-rod·핀)은 처음부터 304로 만든다 — 제품 설계와 같은 형상으로 세척 시간을 측정하기 위해서다.

## 2. 구성

```
 정면도 (소형 체스트 냉동고 위에 설치)

   ┌──────────────── 4040 프레임 (W 700 × D 600 × H 900) ────────────────┐
   │   [NEMA23+브레이크]                                                  │
   │        ║ Z: SFU1605 300 mm ── [Z 로드셀]                              │
   │        ╠══ X: SFU1610 300 mm ══[캐리지]══[DC 60 W+엔코더]             │
   │        ║            [X 인라인 로드셀]                                 │
   │        ║            [θ 기어드모터 on 반력암+로드셀]                    │
   │        ║                 ┃ 스템 Ø25×2 (304) + push-rod Ø8            │
   │  ┌─PC 가드(인터록)─┐      ┃                                           │
   │  │                 │      ◖ 스쿱(304, 매장 동일 모델)                   │
   ├──┴─────────────────┴──────▓▓▓▓ 4 L 통 ▓▓▓▓──────────────────────────┤
   │            체스트 냉동고(−14 °C 설정)  [통 3축 포스 플랫폼]              │
   └─────────────────────────────────────────────────────────────────────┘
      E-stop(적/황)   hold-to-run 버튼   M2용 손잡이(캐리지 부착, 로드셀)
```

## 3. 운전 모드

| 모드 | 무엇을 흉내 내나 | 구동 | 측정 |
|---|---|---|---|
| **M1** 동력 | A (및 B: θ를 x의 함수로 전자캠) | x, θ 모터, z 잠금 | 로드셀·전류·통 플랫폼 |
| **M1-arc / plunge** | 진자(C10)·plunge 등 대안 궤적 | z, x, θ 모두 | 같음 |
| **M2** 접지-수동 | C (및 C02) | x 모터 분리(커플링 해제), 사람이 손잡이로 당김, θ는 x 엔코더 기반 전자캠 | 손잡이 로드셀, IMU, 통 플랫폼 |
| **M3** 자유 수동 | 현재 방식(baseline) | 사람이 계측 스쿱으로 | 계측 스쿱, IMU, grip, 통 플랫폼 |

M1–M3에서 **통 플랫폼이 같은 물리량(재료가 받은 힘)을 재므로** 조건 간 비교가 공정하다.

## 4. Food-contact vs Mechanical PoC 구분

| 구분 | 부품 | 재질·마감 | 규칙 |
|---|---|---|---|
| 식품접촉(food zone) | 스쿱, 스템, push-rod, 피벗 핀, 퀵핀, 열전대 탐침 | 304, 용접부 연마, 노출 나사산 없음 | H2–H4 (V1은 Should, 제품은 Must) |
| splash zone | 스템 상단 클램프, 가드 하단 | 304 또는 세척 가능한 PC | FDM 금지 |
| 비식품 | 프레임, 모터, 스크류, 전장, 센서 브래킷 | 알루미늄, FDM 허용 | 통 바로 위에는 드립 트레이 |

## 7. V1 위험

| 위험 | 대책 |
|---|---|
| 통을 꺼내면 표면이 빨리 녹음 | rig를 냉동고 위에 두고 통은 냉동고 안 플랫폼에. 시험 창 ≤ 3분, 표면온도 기록 |
| 로드셀 저온 드리프트 | 매 시험 전 영점, 온도 기록, 저온 보상형 선택 |
| 스테퍼 Z가 과도한 힘 | shear-pin, 소프트 한계, 가드 |
| 궤적이 공을 못 만듦 | M1-arc/plunge로 대안 궤적, 사람 궤적 영상(P0-6) 반영 |
| 스쿱 볼 용접 품질 | 외주 1건, 연마 |
| 일정 지연 | P0 결과가 G0/G1을 통과하지 못하면 V1 자체를 축소(측정연구로 전환) |
