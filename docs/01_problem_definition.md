# 01. Problem Definition

## 1. 작업

하드아이스크림 매장 직원은 디핑 캐비닛의 통(tub)에서 스쿱으로 아이스크림을 떠서 콘·컵에 공 모양으로 담거나(싱글/더블), 파인트~하프갤런 용기에 여러 맛을 눌러 담는다(한국 BR 기준 115 g, 320 g, 620 g, 960 g, 1,200 g — research/products.md).

한 번의 스쿱은 **절입 → 끌기(drag/sweep) → 공 닫기(closing) → 들어올림 → 배출 → 헹굼**으로 이루어진다(docs/06).

## 2. 문제 진술 (측정 가능한 형태)

> 하드아이스크림 스쿠핑에서 작업자는 **스쿱-아이스크림 사이의 절삭저항**을 손으로 공급하고, 동시에 그 반력이 손잡이에 만드는 **모멘트와 축 회전 토크를 grip과 손목으로 버틴다.** 이 부하는 온도가 낮을수록, 제품이 단단할수록, 반복이 많을수록 커진다.

우리가 줄이려는 것은 질병이 아니라 아래의 **물리량**이다.

| 기호 | 물리량 | 단위 | 측정 |
|---|---|---|---|
| F_hand,peak | 작업자 손이 공구에 가하는 peak 힘 | N | 손잡이 로드셀 |
| %MVC_grip | 최대악력 대비 grip force | % | grip 센서 / 악력계 정규화 |
| ∫F dt | 힘-시간 적분(누적 부하) | N·s | 적분 |
| θ_wrist | 손목 굴곡/신전·요척편위·전완 회내외 excursion | ° | IMU 2개 |
| N_rot | 스쿱당 손목·전완 큰 회전 횟수 | 회 | 영상/IMU |
| t_cycle | 스쿱 사이클타임 | s | 영상 |
| CV_m, N_topup | 스쿱 질량 변동, 추가 스쿱 횟수 | %, 회 | 저울, 관찰 |

## 3. 범위

| 포함 | 제외 |
|---|---|
| 하드아이스크림 스쿠핑의 절입·drag·closing | 소프트서브(스쿠핑 없음) |
| 단일 통에서의 스쿠핑 모듈과 연구용 rig | 31종 전체 캐비닛 자동화(후속 제품 비전으로만 기술) |
| 작업자 부하·사이클·정량의 정량 측정 | 질병 발생률 연구, 의료적 효과 |
| 위생·안전 설계 원칙 적용 | KC·NSF 인증 획득 |
| 파인트 눌러담기의 잔여 부하 **측정** | 눌러담기 자동화 |

## 4. 주장하지 않는 것

- 손목질환을 예방한다 / 질병을 없앤다 / 완벽히 안전하다 / 세계 최초
- 스쿠핑이 산재 청구의 주원인이다(**틀림**: Dempsey 2000 요약에서 1위는 넘어짐 — research/papers.md A1)
- 직원 다수가 손목질환을 앓는다(분모 있는 자료 없음)

## 5. 연구질문 (재정의)

> **적정 디핑온도와 최선의 수공구를 쓰는 조건에서도 남는 스쿠핑 부하 가운데, 반력(grip·손목 토크)과 손목 회전을 프레임에 접지된 저자유도(≤ 2 actuated DOF) 헤드로 옮기면, 수동 대비 작업자 손 힘과 손목 동작을 얼마나 줄이면서 사이클타임과 portion consistency를 유지할 수 있는가?**

원래 질문과의 차이:
1. "적정 온도 + 최선의 수공구"를 **비교 기준(baseline)**으로 명시했다. 나쁜 조건의 수동과 비교하면 효과가 과장된다.
2. "기계화"를 **반력 접지(grounding)**와 **동력(powering)** 두 효과로 나눴다. 접지만으로 충분하면 모터는 필요 없다.

## 6. 가설과 반증 기준

| ID | 가설 | 반증되면 |
|---|---|---|
| H1 | 권장 디핑온도(−14 ± 1 °C) + 매장 표준 스쿱에서도 수동 스쿠핑의 peak grip이 **≥ 30 %MVC**이다 | G0에서 기계 개발 중단 → 측정연구 + 온도/도구 가이드로 전환 |
| H2 | 반력 접지만(모드 M2, 사람이 당김)으로 peak 손 힘과 손목 excursion이 수동 대비 **≥ 50 %** 감소한다 | 접지 구조의 가치 약함 → 동력 필요성 재평가 |
| H3 | 접지 + 동력(모드 M1)은 작업자 peak 손 힘을 수동 대비 **≥ 80 %** 줄인다 | 동력화 가치 약함 → C(무동력) 채택 |
| H4 | 장치 사이클타임 ≤ 수동 중앙값 × 1.2 | 매장 수용성 FAIL → 워크플로 재설계 |
| H5 | 장치의 질량 CV ≤ 수동 CV, 또는 top-up 횟수 감소 | 정량은 부가가치에서 제외 |
| H6 | 2 actuated DOF(x, θ) + 수동 Z로 −12 ~ −16 °C에서 성공률 ≥ 90 % | 3 DOF 필요 → 복잡도 재평가 |

수치 기준(30 %, 50 %, 80 %, 90 %)은 **팀이 합의한 판정선**이며 문헌값이 아니다. 실험 전에 고정하고 바꾸지 않는다(사후 기준 조정 금지).

## 7. 결정 게이트

| Gate | 시점 | 입력 | 판정 |
|---|---|---|---|
| **G0 문제 크기** | 3주차 | P0-2 수동 baseline, P0-3 drag force | −14 °C·최선 도구에서 peak grip < 20 %MVC **그리고** F < 40 N → 기계 개발 중단, 측정연구로 전환 |
| **G1 자동화 수준** | 4주차 | P0-3 F(T) | F < 60 N → **C(무동력 접지)** 우선 · 60–200 N → **A/B(동력)** · > 200 N → 온도관리를 전제조건으로, 장치 운용범위 정의 |
