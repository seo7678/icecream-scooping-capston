# Claude Stepwise Workflow

이 저장소의 README와 docs를 읽고 프로젝트를 이해한다.

한 번에 최종안을 만들지 말고 다음 단계별로 하나씩 수행하고 매 단계 종료 후 STOP한다.

1. 반복 스쿠핑 인간공학 문제 검증
2. 사람 스쿠핑 운동 분해
3. 기존 제품/특허/자동화 선행기술
4. 자동화 수준 결정: 수동 보조 / powered hand tool / semi-auto / full-auto
5. 절삭저항 저감 방법
6. 저자유도 메커니즘 10개 이상
7. 작업자 부하 감소 검증법
8. portion consistency / productivity
9. 매장 적용형 시스템
10. 경제성
11. 안전/위생/FMEA
12. 교수님 공격 및 최종안

각 단계마다:
- 확인된 사실
- 현재 결론
- 불확실성
- 다음 단계 확인사항
을 작성한다.
