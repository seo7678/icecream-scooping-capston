# 09. Concept Generation (21 concepts)

> 이 단계는 **발산**이다. 평가·제거는 docs/10에서 한다.
> 비용은 제품 1대 BOM의 **개략 등급**(근거 없는 상대 비교용): ₩ < 10만 · ₩₩ 10–50만 · ₩₩₩ 50–150만 · ₩₩₩₩ 150–500만 · ₩₩₩₩₩ > 1,000만
> 부하 성분 ①–⑤는 docs/03 범례(① 절삭 일 ② 반력 grip ③ closing 손목 회전 ④ 자세 ⑤ 반복).

## 공통 기호

```
  x : 끌기 방향   z : 수직   θ : 스쿱 pitch   C : 볼 중심(피벗)   h : C의 표면 위 높이
  ─── 아이스크림 표면        ▓ 아이스크림        ◖ 스쿱 볼        ═ 레일/가이드       ⊙ 회전 관절
```

---

### C01 동력 손 스쿱 (powered hand-guided)
```
  손 ▶ [모터|배터리]━━━━◖(회전)
                          ▓▓▓▓▓
```
- 원리: 손잡이 속 모터가 볼/날/claw 회전(선행 D1, D2, D4)
- DOF 1–2 · 액추에이터 1–2 · 사람: 위치·절입 밀기·반력 유지 · 센서: 없음/전류
- 힘 저감: ③만. **반토크가 손으로 돌아와 ② 유지** · 정량: claw 기하 · 형상: 양호 · 속도: 수동과 비슷
- 세척: 모터 근접(나쁨) · 안전: 회전부 손 근처 · 선행: **매우 높음(1937–2005)** · 제작: 중 · 비용 ₩₩

### C02 토크 반력암 + 동력 closing (counterbalanced powered scoop)
```
   베이스⊙━━(평행링크 암, 스프링 밸런서)━━⊙[헤드: θ 모터]
                                            ┃ 손잡이(사람이 끌기)
                                            ◖
```
- 원리: 산업용 너트러너 반력암처럼 암이 토크를 받고, 사람은 손잡이로 끌기, 모터는 closing
- DOF: 수동 위치 3 + 동력 θ 1 · 사람: 위치·**끌기 힘(①) 공급** · 센서: 전류
- 힘 저감: ②③ 제거, ① 남음(팔로) · 형상: 자유로운 closing · 세척: 헤드만 식품영역 · 선행: 반력암은 일반 산업기술, 스쿱 적용은 못 찾음 · 제작: 중 · ₩₩₩

### C03 선형 feed + 스쿱 회전 (2-DOF, **A 후보**)
```
   ═══[캐리지 x]═══════════▶ (모터1, 볼스크류)
         ┃ 스템(push-rod 내장)      ⊙θ (모터2, 스템 상단)
         ◖⊙ C  ── 표면 ── d
        ▓▓▓▓▓▓▓▓▓▓▓▓▓▓
```
- 원리: x로 끌고, θ로 dive·깊이·closing. z는 표면 기준 잠금(수동)
- DOF 2(구동) + 1(수동 잠금) · 액추에이터 2 · 사람: 위치·잠금·트리거 · 센서: 두 모터 전류, 엔코더
- 힘 저감: ①②③④ 모두 · 정량: 부피 적분 가능 · 형상: 프로그램 가능 · 속도: stroke ≤ 3 s 목표
- 세척: 스쿱+스템 분리형 · 안전: 전류제한 + 가드 · 선행: F1+F2 조합 못 찾음 · 제작: 중 · ₩₩₩

### C04 Z + sweep + 회전 (3-DOF)
- C03 + 동력 z. 임의 평면 궤적(진자, plunge 모사). 액추에이터 3 · 제어: 궤적 계획 · 제작 중–고 · ₩₩₩₩
- **연구 rig로는 최적**(최소 DOF를 실험으로 찾기 위한 상위집합), 제품으로는 과잉

### C05 곡선 레일 궤적 (curved rail)
```
   ╭═══════════════╮  ← 곡선 가이드
   ┃캐리지가 레일 접선 방향으로 기울며 이동 → θ = f(x)
   ◖
```
- 원리: 캐리지가 곡선 레일을 따라가며 위치와 자세가 함께 결정. 1 구동(끌기)
- 한계: 위치 경로와 pitch가 같은 곡선에 묶여 **깊이와 closing을 따로 만들 수 없음** · 곡선 레일 가공 · ₩₩₩

### C06 단일 트랙캠 (**B 후보 B1**)
```
   ═══[캐리지 x]═════════▶ (모터 1)
        ┃  레버 a ── 롤러 ⟶ ╭──╮ 고정 트랙(θ(x) 새김)
        ◖
```
- 원리: 모터 1개가 x를 끌고, 고정 트랙의 롤러가 θ = f(x)를 만든다
- 제약: 압력각 → closing을 **≥ 55–75 mm에 걸친 rolling close**로만(calc/cam_feasibility) · 적응: 속도만
- 세척: 트랙·롤러는 비식품영역에 둘 수 있음 · 선행: 못 찾음(캠 자체는 일반) · 제작: 트랙 가공 · ₩₩

### C07 캠 + 회전 follower, 시간 기반 (**B 후보 B2**)
```
   모터 → 캠축 ─┬─ 크랭크-슬라이더 → x(φ)   (사점에서 x dwell)
                └─ 판캠 + 요동 follower → θ(φ)
```
- 원리: 한 축에서 x와 θ를 시간(φ)으로 동기. 크랭크 사점 dwell 동안 판캠이 closing → **짧은 closing 가능**
- 한계: 캠축·링크 추가, stroke·깊이 고정, 적응은 속도만 · 제작: 중–고 · ₩₩₩

### C08 4절 링크 (coupler에 스쿱)
```
   ⊙━━━━━⊙      coupler(스쿱 부착)
    ╲    ╱
     ⊙━━⊙  크랭크 1 모터
```
- 원리: coupler 곡선·자세로 dive-drag-close 근사(3–5 정밀 자세 합성)
- 한계: 궤적 데이터 없이 합성 불가, 조정 불가, 귀환 경로가 제품을 통과할 수 있음, 식품영역 핀 증가 · ₩₩

### C09 크랭크-슬라이더 x + 별도 θ 모터
- x를 크랭크로(속도 정현파), θ는 모터 2. C03 대비 이점 없음(볼스크류가 더 단순·정밀) · ₩₩₩

### C10 고정 피벗 회전 스쿱 (진자)
```
        ⊙ 피벗(모터)
         ╲  R_p ≈ 250 mm
          ╲
           ◖ ← 원호로 통을 가로지름
   ───────▓▓▓▓▓───────
```
- 원리: 1 모터가 긴 팔을 흔들어 원호 절삭. 원호가 dive·drag·exit를 자연히 만듦(사람 팔 원호와 비슷)
- 한계: 깊이가 원호를 따라 변함(초승달 chip), exit 시 pitch 변화 ±23°뿐 → **closing 부족**, 피벗 토크 = F × 250 mm ≈ 37 N·m(F = 150 N), 통이 줄면 피벗이 통 안으로 내려가야 함 · ₩₩

### C11 회전 통 (turntable)
- 통을 돌리고 스쿱은 고정. 캐비닛 웰마다 턴테이블 필요(31종), 종이 통 구동, 통 표면 나선형 패임 · ₩₩₩ × 통 수

### C12 진동/오실레이팅 스쿱
- 삽입방향 진동으로 마찰 감소(KR100450044B1), 압력 기반 세기 조절(KR20210015444A)
- 손에 들면 손-팔 진동 노출 추가 · 선행: 높음 · ₩₩
- **변형:** 접지형 헤드에서 기존 θ 모터로 ±1–2° 디더링 → 추가 하드웨어 0으로 **실험인자**화 가능

### C13 가열 날 스쿱
- rim에 히터(US5000672). 부착·마찰 ↓, 절입력 일부 ↓
- 문제: 표면 녹음·재동결(texture), 화상(70 °C는 1 s 임계 부근), 배선 방수, 선행 풍부 · ₩
- **변형:** 히터 대신 헹굼 도크의 온수로 스쿱 예열 → **실험인자**(헹굼 직후 vs 냉각 후)

### C14 회전 반구 커터 (melon-baller)
```
   rim 지름을 축으로 180° 회전 → 구면을 따라 잘라 반구 portion
   ──⊙══◖══⊙──
     ▓▓▓▓▓▓
```
- 원리: rim이 구면을 쓸어 **기하로 정해진 부피**(정량 유리). 1 DOF + 절입
- 한계: 통 표면에 반구형 구덩이가 남아 다음 portion이 불안정, 공이 curl이 아닌 통짜(외관 차이), claw 회전 선행(D2) · ₩₩

### C15 스크레이퍼 + 성형 챔버
- 얇게 긁어 챔버에 모은 뒤 압축 성형. 압축으로 overrun 손실 → 무게·식감 변화, 챔버 = 틈·세척 문제, 걸림 위험, 선행(EP2712528A1) · ₩₩₩

### C16 수동 접지 레버/트랙캠 스쿱 (**C 후보**, 무동력)
```
   ═══[캐리지 x]═══════  ← 사람이 손잡이(레버비 λ)로 당김
   손잡이 ━━┛ ┃  레버 ── 롤러 ⟶ 고정 트랙 θ(x)
             ◖
```
- 원리: C06의 모터를 사람 손잡이로 대체. 반력은 프레임, 손목 중립 파워그립, closing은 트랙캠
- 힘 저감: ②③④ 제거, ①은 팔로(손잡이 힘 = F/λ) · 정량: 고정 궤적 · 세척: 최상 · 안전: 무동력 · 선행: 못 찾음 · ₩
- **G1에서 F가 작게(< 60 N) 나오면 가장 강력한 후보**

### C17 코어링 튜브 + 피스톤
- 수직 원통을 박아 넣고 피스톤으로 밀어냄. 원통형 portion(콘에 부적합), 전 둘레 절입 + 벽 마찰로 힘 큼, 선행(auger scoop, US5385464) · ₩₩₩

### C18 협동로봇 완전자동
- 6–7축 팔 + 비전. 선행·상용(ARIS, Columbia, Flexiv) · 속도 ~1분/개 · ₩₩₩₩₩

### C19 템퍼링 + 최선 수공구 (기계 없음)
- 디핑 캐비닛 −12 ~ −14 °C 유지 + 최선 스쿱 + 헹굼. **모든 개념의 비교 기준(baseline)** · 비용 ≈ 0 + 운영

### C20 초음파 날 스쿱
- 20–40 kHz. 직선 날에서 큰 감소 보고(출처 불확실). 곡면 스쿱 호른 설계는 연구 수준, 발생기 고가, 소음 · ₩₩₩₩

### C21 회전 와이어 루프 구 커터
- 반원 와이어가 지름축으로 360° 회전해 구를 잘라냄(치즈 와이어 원리). 절삭 면적 최소 → 힘 ↓
- 한계: 회전축이 구를 관통(구멍), 잘린 구를 들어낼 수단 필요, 와이어 파단·위생 · ₩₩
