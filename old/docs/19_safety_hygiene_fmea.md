# 19. Safety & Hygiene — FMEA

> 기준 원장: `research/standards.md`. S(심각도)·O(발생도)·D(검출도, 높을수록 검출 어려움)는 1–10, RPN = S × O × D.
> 등급은 팀의 **초기 평가**이며 V1 시험 후 갱신한다. RPN ≥ 150 또는 S ≥ 8은 조치 필수.

**우선 조치 (RPN 상위·S ≥ 8):** #12(설계 변경 완료) → #14 알레르겐 → #11·#13 세척·미생물 → #1 협착 → #20 proxy → #8 파편.

**이 FMEA가 바꾼 설계:**
1. **push-rod를 스템 밖으로 노출**하고 스템 튜브는 양끝 밀봉(#12). docs/11의 "튜브 내부 push-rod" 초안을 대체한다.
2. **식품 모듈 2벌**(일반 / 알레르겐)(#14).
3. 스템 Ø25×3(#8, docs/13 §4와 일치).

## 2. 안전기능 PLr 초기 산정 (ISO 13849-1 위험그래프, 잠정)

| 안전기능 | S | F | P | PLr(잠정) | 구현 |
|---|---|---|---|---|---|
| E-stop | S2(손가락 열상·압궤 가능) | F1(가드 뒤, 노출 드묾) | P1(80 mm/s 저속, 회피 가능) | **c** | 안전 릴레이 + NC 접점 |
| hold-to-run | S2 | F1 | P1 | **c** | ENABLE 직렬, 이중 접점 |
| 가드/도킹 인터록 | S2 | F1 | P1 | **c** | 인터록 스위치 ENABLE 직렬 |
| 힘 상한 | S1(상한 이하 접촉은 가역적 손상 가정) | F1 | P1 | **a–b** | 드라이버 하드웨어 전류제한 |

**주의:** 200 N 힘 상한은 ISO/TS 15066의 손·손가락 준정적 한계 140 N을 넘는다. 따라서 **힘 제한만으로 안전하다고 주장하지 않는다.** 1차 방호는 **분리**(가드 + hold-to-run + 인터록)다.

## 3. 위생 설계 규칙 적용 현황

| 규칙 | 적용 | 상태 |
|---|---|---|
| 식품영역 304/316 | 스쿱·스템·push-rod·핀 | V1부터 적용 |
| Ra ≤ 0.8 µm | 용접부 연마 | 제품 단계 확인(V1은 PoC) |
| 내부 모서리 R ≥ 3.2 mm | 피벗 브래킷 | 도면 단계 반영 |
| 숨은 공동 없음 | push-rod 외부 노출, 스템 밀봉 | **FMEA #12로 변경** |
| 공구 없는 분리 ≤ 30 s | 볼락 퀵핀 2개 | E7에서 실측 |
| FDM 금지(식품·splash) | 브래킷은 비식품영역만 | 적용 |
| 구동부 비식품영역 | 모터·스크류·전장은 프레임 위 + 드립 실드 | 적용 |
| 헹굼 | 흐르는 물 또는 ≥ 57 °C 도크(제품) | 제품 단계 |
| 한국 '기구' 규격 | 금속 용출 성적, '식품용' 표시 | 상용화 단계 |

## 4. 세척 SOP 초안 (제품)

1. 4시간마다, 그리고 알레르겐 맛 교체 시: 트리거 해제 → E-stop → 퀵핀 2개 해제 → 식품 모듈(스쿱 + 스템 + push-rod) 분리
2. 온수 세척(식기세척기 사용 가능 여부는 재질·밀봉 확인 후) → 헹굼 → 소독 → 건조
3. 예비 모듈 장착(퀵핀) → 트리거로 TARE 사이클 확인
4. 도킹 플레이트·드립 트레이 닦기, 일일 1회 헹굼 도크 청소
5. 기록지 서명(시간, 담당)
