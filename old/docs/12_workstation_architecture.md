# 12. Workstation Architecture

> ⚠️ **Legacy Architecture M — 수동 위치지정(2026-09 이전 기준안).** 현재 기준 아키텍처는 **Cartesian 자동 맛 선택 구조**다 → [`system_architecture_cartesian.md`](system_architecture_cartesian.md), [`final_system_concept.md`](final_system_concept.md), 비교는 [`architecture_comparison.md`](architecture_comparison.md).
> 이 문서 전체(레일·스윙 암·웰 도킹·작업자 워크플로)는 **Legacy M 대안**이다. 모듈별 '정말 필요한가?' 판정 중 가열·비전·무게센서 삭제, 헹굼 필요, 가드 필요는 새 구조에도 그대로 적용된다.


> 원칙: 억지로 규모를 키우지 않는다. 모듈마다 "정말 필요한가?"를 묻고, 필요성이 낮으면 삭제한다.
> 캡스톤 산출물은 **단일 웰 스테이션(V1)**이다. 전체 캐비닛 워크스테이션은 **제품 비전**으로만 기술한다.

## 1. 모듈별 필요성 판정

| 모듈 | 후보 | 정말 필요한가? | 판정(제품) | 판정(V1) |
|---|---|---|---|---|
| A. 수평 위치이동 | 수동 슬라이드, 리니어 레일, counterbalance, 스프링 밸런서 | 헤드(~3 kg 가정)를 웰 사이로 옮겨야 하므로 **예**. 단 절삭 반력은 도킹이 받으므로 **가벼운 밸런서 암이면 충분** | 캐비닛 뒤 상단 레일 + 스윙 암 + 툴 밸런서(수동) | **삭제**(단일 웰 고정) |
| B. Z 표면 접근 | 수동, 중력, 모터 리드스크류 | 접근은 필요, **모터는 불필요**. θ₀로 rim을 표면에 먼저 닿게 하면 h = R·cos θ₀가 기하로 정해짐 | 수동 + counterbalance(약간 무겁게) + 잠금 | **모터**(연구: 깊이·진자·plunge 궤적 재현용) |
| C. 스쿠핑 코어 | dive + drag + closing | **예** — 이것이 프로젝트 | A(x + θ) | 3축 z, x, θ |
| D. 부하 적응 | 전류, 토크 추정, 로드셀 | 힘 상한(안전)은 **필수**. 깊이 적응은 **맛별 경도 편차가 크면 필요**(V1에서 판정). AI 불필요 | 모터 전류 + 하드웨어 전류제한 | 로드셀(정답값) + 전류(proxy 검증) |
| E. 정량 | 깊이·길이·부피 적분, 무게 | 부피 적분은 소프트웨어만 → 비용 0. 무게 센서는 매장 저울이 이미 있음 → **헤드 무게센서 삭제** | 부피 적분(소프트웨어) | 저울로 결과 측정 |
| F. Ejector | 과회전 + 고정 스트리퍼, 내부 wiper, retention rod | **미정.** 헹굼으로 젖은 볼에서 공이 스스로 떨어지면 삭제. wiper·retention rod는 특허 D7 확인 전 회피 | 시험 후 결정 | 과회전 + 스트리퍼 시험 |
| G. 분리형 위생 모듈 | 스쿱 + 스템 + push-rod 퀵릴리스 | **필수**(H3) | 공구 없는 분리 ≤ 30 s | 같은 설계(재질은 PoC 허용 범위) |
| H. 헹굼 도크 | 흐르는 물 / ≥ 57 °C 온수 | 맛 간 교차오염·알레르겐(견과류) 때문에 **필수**. 헤드 홈 위치에서 스쿱만 담그도록 | 레일 끝 도크 | 수동 헹굼 |
| I. 가열 | 히터 | **삭제**(선행 풍부, 화상, 재동결). 헹굼 온수 예열을 실험인자로 | 없음 | 인자 |
| J. 비전/AI | 카메라 | **삭제**(위치 판단은 사람) | 없음 | 없음(영상 기록만) |
| K. 가드 | 프레임이 웰 개구부를 덮음 | **필수**(S2: 힘 제한만으로 손 보호 불충분) | 도킹된 헤드 프레임 = 가드 | 폴리카보네이트 가드 + 인터록 |

## 2. 제품 비전 — 캐비닛 워크스테이션 (후속 단계)

```
 평면도                           고객 쪽 (전면 유리)
 ┌───────────────────────────────────────────────────────────────┐
 │  [웰][웰][웰][웰][웰][웰][웰][웰]   ← 앞줄                         │
 │  [웰][웰][웰][웰][웰][웰][웰][웰]   ← 뒷줄     디핑 캐비닛          │
 │   ▣ 각 웰 둘레: 고정 도킹 플레이트(304, 핀 2 + 래치 받침)            │
 └───────────────────────────────────────────────────────────────┘
  ═══════════════ 레일 (캐비닛 뒤 상단, 작업자 쪽) ══════════════════
     [캐리지]─(스윙 암 + 툴 밸런서)─[스쿠핑 헤드]       [헹굼 도크][컵 받침]
                          작업자 쪽
```

| 요소 | 기능 | 반력 부담 |
|---|---|---|
| 레일 + 캐리지 + 스윙 암 | 헤드를 웰 사이로 이동(수동, 저마찰) | 없음(헤드 무게만, 밸런서가 상쇄) |
| 도킹 플레이트(웰마다) | 헤드 위치결정(핀) + 전복 방지(래치) | **절삭 반력 전부**(calc §11: 래치 설계하중 ≥ 0.5 kN) |
| 헤드 프레임 | x 가이드, θ 모터, z 잠금, 손잡이, **웰 개구부를 덮는 가드** | 반력 전달 |
| 헹굼 도크 | 스쿱 담금 헹굼 | – |

**제품 비전의 미해결 위험:** 캐비닛 모델마다 상판·뚜껑 구조가 다르다(P0-4). 31개 웰에 도킹 플레이트를 설치하는 비용·설치성, 뚜껑 개폐와의 간섭, 앞줄/뒷줄 도달 범위는 목업으로 확인해야 한다.

## 3. 작업자 워크플로

**제품(A 기준, 싱글레귤러 1개)**

| # | 작업자 | 기계 | 시간 예산(가정) |
|---|---|---|---|
| 1 | 헤드 손잡이를 잡고 목표 웰로 이동, 도킹(핀에 내려놓으면 래치 자동) | – | 1–2 s |
| 2 | 뜰 위치 선택: 헤드를 웰 안에서 좌우로 약간 이동(웰 개구부가 통보다 크면) 또는 통 회전 없이 x 방향 고정 | θ → θ₀(rim 접지 자세) | 0.5 s |
| 3 | z 잠금 해제 → 스템이 내려가 rim이 표면에 닿음 | 접촉 감지(θ 전류 상승) → z 잠금 | 0.5–1 s |
| 4 | 트리거를 누르고 유지(hold-to-run) | dive → drag(깊이 적응) → close | ≤ 3 s |
| 5 | 헤드를 들어 컵 위로(밸런서) | 공 유지(θ 90–120°) | 1–2 s |
| 6 | 배출 버튼 | 과회전 + 스트리퍼(채택 시) | 0.5 s |
| 7 | 맛을 바꿀 때 헹굼 도크 | 도크에서 자동 담금(선택) | 1–2 s |
| 합계 | | | **~6–10 s** (수동 사이클 실측과 비교, P5) |

파인트 이상: 4–5를 반복해 용기에 덩어리를 떨어뜨리고, **눌러담기는 사람이 한다**(잔여 부하로 측정).

**V1 단일 웰 스테이션**

|---|---|---|
| 1 | 온도 평형된 통을 단열 홀더/냉동고 웰에 장착, 표면 온도·코어 온도 기록 | – |
| 2 | 시험 조건(깊이, 속도, 궤적 모드) 선택 | – |
| 3 | 시작 버튼(hold-to-run) | z 터치오프 → 궤적 실행 → 로그 |
