# 08. Design Requirements

우선순위(사용자 지정): **Performance > Cost > Complexity > Reliability > Cleanability > Safety > Maintainability > Manufacturability**
단, 안전·위생 요구 중 "필수(Must)"는 우선순위와 무관하게 만족해야 한다(법·표준 하한).

표기: **M** = Must(불만족 시 설계 불가) · **S** = Should(목표) · **V1** = 연구용 시제품 기준 · **P** = 제품 기준
목표치 중 문헌 근거가 없는 것은 **팀 판정선**이며 실험 전 고정한다.

## 2. 성능 (P)

| ID | 요구 | 목표 | 근거 | 검증 |
|---|---|---|---|---|
| P1 | 작업자 peak 손 힘 감소(수동 대비, 같은 온도·같은 참가자) | **≥ 80 %**(모드 M1) | H3, 팀 판정선 | E1 |
| P2 | grip %MVC(장치 사용 중) | **≤ 10 %MVC** | 팀 판정선 | E1 |
| P3 | 장치 사용 중 손목 굴곡/신전·편위 excursion | 수동 대비 ≥ 50 % 감소 | H2 | E1 IMU |
| P4 | 스쿱당 부하 상태 손목 회전 | 0회 | closing 동력화 | 영상 |
| P5 | 사이클타임(배치→배출) | ≤ 수동 중앙값 × 1.2 | H4 | E2 |
| P6 | stroke(drag+closing) 시간 | ≤ 3 s | 사이클 예산 | E3 |
| P7 | 성공률(공 형성, 부서짐·미달 없음) | ≥ 90 % (−12 ~ −16 °C) | H6 | E3 |

| P9 | 운용 온도 범위 | −16 ~ −12 °C 전 범위 성공률 P7 만족. 범위 밖이면 "템퍼링 필요" 표시 | calc sim | E4 |
| P10 | 전류 proxy 힘 추정 오차 | ≤ ±15 % (교정 후) | 제어 요구 | P1-2 |

## 3. 인간공학·워크플로 (E)

| ID | 요구 | 목표 | 검증 |
|---|---|---|---|
| E1 | 헤드 이동 힘(counterbalance 후) | ≤ 20 N(수평), 들어올림 ≤ 20 N | 손잡이 로드셀 |
| E2 | 손잡이 | 파워 그립, 중립 손목, 활성화 트리거 | 설계 검토 |
| E3 | 캐비닛 앞쪽(고객 쪽) 시야를 가리지 않음 | 작업자 쪽 뒤편 설치 | 목업 |
| E4 | 컵을 드는 손은 자유 | 한 손 조작 + hold-to-run | 목업 |

## 4. 위생 (H) — research/standards.md §7

| ID | 요구 | 등급 |
|---|---|---|
| H1 | 식품영역 = 스쿱 + 통 위에서 떨어질 수 있는 모든 부품 | M |
| H2 | 식품영역 304/316 SS, Ra ≤ 0.8 µm, 내부 모서리 R ≥ 3.2 mm(권장 6), 노출 나사산·틈 없음 | M(P), S(V1) |
| H3 | 식품접촉 모듈(스쿱+스템+push-rod) **공구 없이 ≤ 30 s 분리** | M |
| H4 | 구동부(모터·볼스크류·베어링·배선)는 비식품영역, 식품영역 위에서는 드립 차단 | M |
| H5 | FDM 출력물은 비식품영역에만 | M |
| H6 | 헹굼: 흐르는 물 또는 ≥ 57 °C 온수 도크 | S(P) |
| H7 | 한국 '기구' 규격: 금속 용출, '식품용' 표시 | M(P) |
| H8 | V1의 식품 시험품은 **시식하지 않는다**(시험용 폐기) | M(V1) |

## 5. 안전 (S) — docs/19

| ID | 요구 | 등급 |
|---|---|---|
| S1 | 하드웨어 전류제한으로 sweep 힘 ≤ 200 N, pitch 토크 ≤ 10 N·m | M |
| S2 | 힘 제한만으로는 손 안전 불충분(140 N 초과) → 작업영역 **가드 + hold-to-run** 으로 분리 | M |
| S3 | 비상정지(ISO 13850 형식), 정지범주 0 | M |
| S4 | 손가락 접근 가능한 협착 틈 ≥ 25 mm 또는 가드 | M |
| S5 | 과부하 판정 임계는 추정치 기준 ≤ 0.8 × 하드웨어 한계(proxy 오차 반영) | M |
| S6 | 전원 투입·리셋 후 자동 재기동 금지 | M |
| S7 | 가열을 쓰면 손 접촉면 ≤ 43–48 °C | M(해당 시) |
