# Architecture Comparison

> 세 가지 비교를 한다. (1) 끌기를 누가 하나: 전역 X vs 로컬 x_scoop vs 도킹 헤드. (2) 위치를 누가 정하나: 수동(Legacy M) vs 자동 XY. (3) 자동이라면 무엇으로: Cartesian vs 로봇팔.
> 수치는 `calc/output/*.md`의 **가정 하중(F_x = 200 N)·가정 치수** 결과다.

## 1. 끌기(drag)를 어느 축이 하나

| 아키텍처 | 구성 | 모터 | 끌기 반력 경로 |
|---|---|---|---|
| **1. 전역 X 드래그** | X_M(볼스크류)이 이동과 드래그를 겸함, θ_s 로컬 | X, Y, Z, θ = **4** | 스쿱 → 스템 → 헤드 → Z 기둥 → Z 블록 → X 캐리지 → **X 볼스크류·레일** → 빔 → 프레임 |
| 2. 로컬 x_scoop | 전역 XY는 벨트(위치결정 전용) + 잠금, 헤드 안에 짧은 x_s 볼스크류 + θ_s | X, Y, Z, x_s, θ = **5** + XY 잠금 1–2 | 스쿱 → … → Z 기둥 → Z 블록 → X 캐리지 → **X 레일 + 잠금** → 빔 → 프레임 (전역 벨트는 빠짐) |
| 3. 도킹 헤드 | 가벼운 갠트리가 헤드를 통 위 도킹 플레이트에 내려놓고, 헤드 안의 z_s·x_s·θ_s가 스쿠핑 | X, Y, Z, z_s, x_s, θ = **6** + 도킹 래치 | 스쿱 → 스템 → 헤드 → **도킹 플레이트(데크 높이)** → 프레임 (갠트리 전체가 빠짐) |

### 1.1 정량 비교

| 기준 | 1. 전역 X | 2. 로컬 x_s | 3. 도킹 |
|---|---|---|---|
| 스쿱 끝 드래그 방향 변위 @ 200 N, 기계형 구조 + Ø30 스템 | **0.99 mm** | 0.98 mm | 0.49 mm |
| 같은 값, 3D 프린터식 구조(MGN12·4040·GT2) | 10.9 mm | 7.8 mm | (도킹이면 구조 무관) |
| 옆방향 변위 @ 60 N, 기계형 | 0.20 mm | 0.20 mm | 0.15 mm |
| 전역 구동계가 하중 경로에 있나 | 예(볼스크류: 0.01 mm) | 아니오(대신 잠금 필요) | 아니오 |
| 갠트리 구조가 하중 경로에 있나 | **예** | **예** | 아니오 |
| X 가동질량(추정) | 11.8 kg | ~15 kg(x_s 모듈 +3 kg) | 갠트리는 가볍고 헤드가 ~+5 kg |
| XY 이송(추정) | 볼스크류 ~250 mm/s | 벨트 ~500 mm/s → 사이클 ~2 s 단축 | 벨트 + 도킹 시간 +1–2 s |
| 기계 복잡도 | 낮음 | 중 | 높음 |
| 식품 주변 부품 | 헤드·식품 모듈 | 같음 + x_s 모듈이 통 위 | **통마다 도킹 플레이트**(식품 주변 표면 증가) |
| 정비성 | 보통 | 헤드 모듈 교체 쉬움 | 복잡 |
| 제어 | X–Z–θ 좌표 보간(CNC식) | 로컬 축 독립 | 도킹 시퀀스 + 로컬 3축 |
| 캡스톤 제작 난이도 | 낮음 | 중 | 높음 |

### 1.2 판단

- **로컬 x_scoop는 "갠트리가 절삭 하중을 받는다"는 문제를 풀지 못한다.** 반력은 여전히 Z 기둥과 XY 캐리지를 지난다. 빠지는 것은 전역 **구동계**뿐이고, 볼스크류 X라면 그 기여는 0.01 mm다. 반대로 GT2 벨트 X라면 2.3–3.0 mm가 빠지지만, 그때도 구조가 7.8 mm를 남긴다.
- 갠트리 구조를 하중 경로에서 빼는 유일한 방법은 **도킹(아키텍처 3)** 이다. 하지만 모터 6개, 통마다 도킹 플레이트, 로컬 3축이 필요해 V1에는 과하다.
- **결론: 아키텍처 1을 V1과 제품의 기준안으로 한다.** 조건은 세 가지다.
  1. X_M은 볼스크류(SFU2010급)여야 한다.
  2. 드래그 방향을 빔 축과 맞춰, 옆방향으로 빔이 비틀리지 않게 한다.
  3. 구조는 "기계형"(강관 기둥, HG15, 강관 빔, Ø30 스템)이어야 한다.
- 아키텍처 2는 V1 이후 **사이클타임이 병목**으로 확인되면 검토하는 "고속 갠트리" 변형이다(벨트 XY로 ~2 s 단축, 대신 잠금 추가). 아키텍처 3은 제품에서 **갠트리 질량·비용을 줄여야 할 때**의 선택지다.

## 2. 수동 위치지정(Legacy M) vs 자동 XY

| 기준 | Legacy M: 작업자가 헤드를 도킹 | 자동 XY (Cartesian) |
|---|---|---|
| 작업자 신체부하 | 손 반력·손목 회전은 없음. 3 kg 헤드를 밸런서로 이동·도킹 | 버튼 + 컵 놓기/가져가기만 |
| 작업자 점유 시간 | 사이클 전체(~6–10 s 추정) | ~3 s. **기계가 도는 동안 손이 빔**(결제·토핑·포장 병렬) |
| 기계 사이클 | ~2–3 s stroke + 사람 이동 | 11–23 s(추정, calc/output/cycle_time_estimate.md) |
| 비용(추정) | 단일 스테이션 판매가 ~210–300만 원(docs/18) | V1 BOM ~524만 원(추정, 냉동고·인클로저 포함). 제품가는 미산정 |
| 복잡도 | 모터 2 | 모터 4 + 인클로저 + 인터록 |
| 세척 | 식품 모듈 분리 | 같음 + 갠트리 위생 설계(드립 트레이·벨로즈) |
| 유지보수 | 적음 | 축·센서·원점 관리 |
| 설치 공간 | 기존 디핑 캐비닛에 레일·도킹 추가 | **자체 냉동 데크와 통 배치가 필요**(기존 캐비닛에 넣기 어려움) |
| 신뢰성 | 부품 적음 | 축·센서 증가 |
| 위치 반복정밀도 | 핀 도킹 ~±1 mm | 볼스크류 ~±0.05 mm(필요 이상) |
| 처리량 | 사람 속도에 묶임 | 기계 속도에 묶임(피크에 불리), 대신 사람 병렬 |
| 새로움 | 반력 접지 + 사람 위치지정 조합(선행 미발견) | 로봇 자동화에 가까워짐. Cartesian 하드 스쿠핑 자체는 미발견이나 요소별 선행 다수 |
| 캡스톤 가치 | 인간공학 측정 중심 | 전체 자동 사이클, 좌표계, 상태기계, 안전 설계까지 → **높음** |

**판단**
- **손목 부하 문제만 놓고 보면 자동 XY는 과도한 자동화다.** 반력 접지 헤드(Legacy M)만으로도 손 힘과 손목 회전은 없어진다.
- 자동 XY의 가치는 다른 데서 나온다. 가치가 생기는 조건:
  1. **작업자 손이 사이클 동안 비어야 하는 운영** — 1인 근무, 결제·토핑과 병렬
  2. **맛 세트가 고정**된 기기형 매장, 키오스크형 유인 매장
  3. **포장 제품(파인트·쿼터)을 미리 채워 두는 백오브하우스 작업**
  4. **저울로 portion을 닫는 정량 관리**가 중요한 경우
- 반대로 31종을 자주 바꾸고 피크 처리량이 중요한 대형 매장이라면 Legacy M(또는 사람)이 낫다.
- 따라서 두 구조는 대체 관계가 아니다. **다른 운영 모델을 위한 두 제품**으로 문서화한다. 캡스톤 V1은 Cartesian으로 만들되, 스쿠핑 헤드·식품 모듈·제어 로직은 두 구조에 공통으로 쓴다.

## 3. Cartesian vs 로봇팔

| 기준 | Cartesian (아키텍처 1) | 협동로봇 |
|---|---|---|
| 액추에이터 | 4 | 6–7(+ 스쿱 툴) |
| 본체 가격 | V1 BOM ~524만 원(추정, 구조·센서·안전·냉동고 포함) | UR5e US$35–48k, Doosan M0609 4,477만 원, Rainbow RB5-850 4,400만 원(본체만, `[SNIPPET]`) |
| 200 N·0.8 m 레버 강성 | 설계로 확보(~200 N/mm) | 긴 팔 끝에서의 강성·가반하중 여유는 **미검증** |
| 작업공간 | 상자형, 통 배치를 기계에 맞춰야 함 | 기존 캐비닛에 설치 가능, 배치 유연 |
| 프로그래밍 | 좌표표 + 보간(CNC식) | 역기구학·충돌 회피 |
| 위생 | 레일·스크류를 드립 차단면 위로 | 관절·케이블이 식품 위로(커버 필요) |
| 선행기술 | Cartesian 하드 스쿠핑은 미발견 | Columbia, Niska(US20240245265A1), Dexai, Dice Cream 등 다수 |

**판단:** 이 작업(정해진 통, 수직 접근, 큰 절삭력, 짧은 궤적)에서는 Cartesian이 **액추에이터 수, 가격, 강성에서 명확히 유리**하다. 대가는 배치 유연성이다. 로봇팔은 기존 매장에 그대로 넣을 수 있다는 장점 때문에 상용 로봇 가게들이 택했다(research/products.md).
