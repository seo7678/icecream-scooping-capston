## 2. 구조적 관찰

1. **모든 수공구는 일(①)의 경로·열만 바꾼다.** 절삭에 필요한 일 W ≈ u·V는 도구와 무관하게 남고(docs/07 §2), 그 일을 공급하고 반력을 버티는 주체는 여전히 손이다.
2. **u를 크게 바꾸는 것은 온도다.** 가열 스쿱·Zeroll은 표면 부착·마찰분만 건드린다.
3. **손에 드는 전동공구는 반력 문제를 풀지 못한다.** 모터가 스쿱을 돌리면 같은 크기의 반토크가 손잡이로 돌아온다(작용-반작용). 동적 손목 회전은 정적 grip 유지로 바뀔 뿐이다. 1937년 이후 반복 특허에도 상용 생존 제품이 없는 것은 이 물리와 세척·무게 문제로 설명된다(**추론**, 검증된 시장 분석 아님).
4. **자동화 쪽은 사람을 완전히 빼는 방향(로봇팔)만 있다.** 비용·속도·전용 용기 문제를 안는다.
5. **빈칸:** "사람이 위치를 정하고, 반력은 프레임이 받고, 기계는 저자유도로 stroke만 수행"하는 중간 단계 제품은 찾지 못했다(research/products.md B 요약).

## 3. 핵심 질문: 적정 온도 + 좋은 스쿱이면 충분한가?

| 관점 | 판단 |
|---|---|
| 증거 | **판정 불가.** 스쿱 종류 × 온도 × 목표중량의 통제 비교 연구를 찾지 못했다 |
| 물리 | 온도는 u를 배수로 바꾸는 가장 큰 레버다. 좋은 스쿱은 마찰·자세 일부만 바꾼다 |
| 우리 시뮬레이션 | "매우 단단함(250 kPa 가정)"에서는 어떤 제어전략도 200 N 안에서 한 번에 115 g을 못 뜬다(calc/output/load_adaptive_sim.md) → **장치도 온도관리를 전제로 한다.** 장치는 온도관리의 대체재가 아니다 |
| 남는 부분 | 적정 온도에서도 남는 것: 맛별 경도 편차(같은 캐비닛, 다른 FPDF), 피크 시간 반복, 손잡이 반력을 grip으로 버티는 구조, 파인트 눌러담기 |
| 결론 | **"적정 온도 + 좋은 스쿱"을 실험의 baseline으로 삼는다.** P0-2에서 이 조건의 잔여 부하가 G0 기준(peak grip < 20 %MVC 그리고 F < 40 N) 아래로 나오면 **기계 개발을 중단하고 측정연구 + 온도·도구 가이드로 전환한다.** |

## 4. 프로젝트 필요성에 미치는 영향

- 필요성은 **조건부**다. 근거가 약한 상태에서 기계를 먼저 만들지 않는다.
- 기계를 만든다면 그것이 이기는 영역은 ②(반력 grip)와 ③(손목 회전)이며, ①은 사람에서 모터로 옮길 뿐이다.
- 따라서 실험은 **접지 효과(②③ 제거)와 동력 효과(① 이전)를 분리**해서 측정한다(docs/17, 모드 M2 vs M1).
