# 03. Mechanism Architecture

## 유력안 A — 2DOF 독립구동

### 축 1: Linear / Sweep
리드스크류 또는 벨트 구동으로 스쿱을 아이스크림 내부로 절입·이송.

### 축 2: Scoop Rotation
감속모터로 스쿱을 회전시켜 절삭된 아이스크림을 스쿱 내부로 말아 넣음.

### 장점
- 제어 쉬움
- 각 변수 독립 실험 가능
- 학부 시제품 제작 용이

### 단점
- 모터/제어기 2개 이상
- 구조가 전동장치 조합처럼 보일 수 있음

## 유력안 B — 1 Motor + Cam/Linkage

모터 1개가 캠 또는 링크기구를 구동하고, 캠 프로파일이 스쿱의 절입·전진·회전을 시간순으로 결합.

### 연구가치
- 사람의 복합 스쿠핑 동작을 저자유도 기구로 합성
- actuator 수 감소
- 반복 궤적 재현성 향상

### 리스크
- 실제 스쿠핑 궤적 데이터가 먼저 필요
- 경도 변화 대응이 A보다 어려울 수 있음

## 현재 설계판단

V1에서는 A로 물리변수를 검증하고, 스쿠핑 궤적이 안정적으로 정의되면 B로 단순화하는 전략이 유력.
