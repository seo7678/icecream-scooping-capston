# Cup Dispensing Station

> 기본안: **작업자가 고정된 컵 스테이션에 컵을 놓는다.** 기계가 컵을 집어 옮기는 구조는 제외한다(액추에이터·위생·안전 부담 대비 가치가 낮음).

## 1. 구성 (Diagram 6)

```
 측면                                         평면
           스쿠핑 헤드 (Z ≥ Z_SAFE로 진입)          ┌──────────── 인클로저 ────────────┐
                 ┃                                │                                  │
                 ◖ ← 공 (θ = +90° 포획 상태)        │   · · · 광전 센서 빔 · · ·        │
   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 데크 높이 ─ ─ ─ ─          │   ┌──────────┐                   │
   [고정 빗 comb]   ┌──────┐                       │   │  컵 베이  │ ← 작업자 손 입구   │
                   │  컵   │ ← 테두리 = 데크 높이   │   │  ( 컵 )   │                   │
     광전 센서 ▶ · · │      │ · · ◀ (베이 입구)     │   └──────────┘                   │
                   └──────┘                       └──────────────────────────────────┘
          ┌────────────────────┐
          │ 로케이터 링(304)    │  매립 웰 → Z_SAFE 60 mm (올림 대비 사이클 ~1 s 단축)
          │ 1 kg 로드셀 + ADC  │  컵 유무 + 무게 확인
          └────────────────────┘
```

## 2. 순서

```
CHECK_CUP: 저울 > 컵 무게 임계(예: 3 g) & 안정 → 컵 있음
XY_MOVE_TO_CUP: Z ≥ Z_SAFE 에서 컵 위로
Z_DISPENSE: 베이 광전 센서 "비어 있음" 확인 → 50 mm/s 하강 → C = Z_C + R + 15 mm
EJECT: θ → −30°, 흔들기, 빗 걸기(X 후퇴) — 방식은 V1 시험으로 확정
Z_RETRACT: Z ≥ Z_SAFE
PORTION_CHECK: 헤드가 베이를 떠난 뒤 저울 안정 1 s → 질량 판정·기록
```

## 3. 컵 유무 확인 — 가장 단순한 방법

| 방법 | 장점 | 단점 | 판정 |
|---|---|---|---|
| **저울(로드셀)** | 정량 확인에 어차피 필요, 추가 센서 0 | 가벼운 컵(~5 g)은 임계를 낮게 둬야 함 | **채택** |
| 기계식 스위치 | 단순 | 컵 형태·무게에 따라 불안정, 식품 근처 가동부 | 기각 |
| 광전(반사형) | 비접촉 | 투명 컵 오검출 | 기각(베이 입구 **손 감지용**으로만 사용) |

## 4. 정량 확인 (Portion Verification)

| 항목 | 값 |
|---|---|
| 목표 M_target | 싱글레귤러 115 g (용기 포함 목표 120 g, 커뮤니티 자료 `[UNCERTAIN]`) |
| 허용 범위 | **ASSUMPTION** −5 % / +10 % (최저중량 관리 관행 반영, 매장 기준으로 교체) |
| 저울 | 1 kg 로드셀, 분해능 ≤ 0.5 g, 안정화 1 s |

| 판정 | V1 동작 | V2 이후 |
|---|---|---|
| 범위 안 | 완료, 로그 | 같음 |
| 부족 | **로그 + 화면 경고**, 작업자가 판단(손 보충 또는 재주문) | 자동 top-up: 같은 통에서 짧은 stroke(부족분 부피만큼), 1회까지 |
| 과다 | 로그 + 경고 | 로그. 과다 반복 시 맛별 보정계수 하향 |

자동 top-up은 사이클을 ~12 s 더 늘리고, 상태기계에 분기가 하나 더 생긴다. 그래서 **V1은 측정·기록만** 한다.

## 5. 맛별 portion 보정 (저울 피드백, AI 아님)

```
예측 질량   m_pred = ρ_nominal · V_integrated
보정계수    k_f ← k_f + λ · (m_meas / m_pred − k_f)        λ = 0.2 (지수이동평균, ASSUMPTION)
다음 스쿱   V_target = M_target / (ρ_nominal · k_f)
오차 경고   |m_meas − M_target| > 20 % 가 2회 연속 → 해당 통 map_valid = false → 3점 재프로브
```

k_f는 맛마다 다른 밀도(overrun), 압축(curl packing), 표면 지도 오차를 한 숫자로 흡수한다. 흩어짐(CV)은 줄이지 못한다. 편향만 잡는다(docs/15의 "부피 제어 CV 하한" 참조).

## 6. 멀티 스쿱 용기(파인트 등)

- 컵 대신 파인트 용기를 베이에 놓으면 스쿱 3회를 연속으로 배출하고, 저울이 누적 질량으로 목표 320 g을 확인한다.
- **눌러담기는 작업자가 한다**(Legacy 문서의 잔여 부하와 동일).
- 파인트 용기는 컵보다 높아서, Z_C를 용기 종류별로 등록한다.
