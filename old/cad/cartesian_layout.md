## 2. 정면 높이 (데크 = 통 테두리 = Z 0 기준)

| 항목 | 컵 올림(Z_SAFE 140) | 컵 매립(Z_SAFE 60) |
|---|---|---|
| 데크 높이(바닥에서) | ~850 mm (냉동고 상면) | 같음 |
| Z_SAFE (피벗 C 높이) | +140 | +60 |
| Z 최상단(C) | +160 | +80 |
| Z 하부 블록 | +580 | +500 |
| Z 상부 블록 | +730 | +650 |
| X 빔 중심 | ~+700 | ~+620 |
| Z 기둥 상단(최상단 위치) | +1,115 | +1,035 |
| 전체 높이(바닥에서) | ~2.0 m | ~1.9 m |
| 가장 깊은 C | −205 | −205 |
| 모멘트 레버(최심) | 807 mm | 727 mm |

**V1은 컵 매립을 기본**으로 한다(사이클 ~1 s 단축, 레버 10 % 감소).

## 3. 주요 부품 배치

| 부품 | 위치 | 비고 |
|---|---|---|
| X 레일 HGR15 × 2 | 빔 전면, 상하 간격 ≥ 80 mm | 빔 윗면에는 볼스크류 + 벨로즈 |
| X 볼스크류 SFU2010 | 빔 윗면, 고정측(BK15) = 모터 쪽 | 볼너트 로드셀(축방향) |
| Y 크로스슬라이드 | X 캐리지 판 위, 레일 간격 ≥ 120 mm | SFU1605 |
| Z 기둥 | Y 판 앞면, 기둥 측면에 HGR15 × 2 | SFU1610, 볼너트 로드셀, 가스스프링 |
| X 빔 아래 드립 트레이 | 빔 전장, 304 | 빔·레일에서 떨어지는 것을 받음 |
| 포스트 | 양 끝, 대각 브레이스 | 냉동고와 같은 베이스에 고정 |
| 인클로저 | 전체, 전면 도어(인터록) | 컵 베이만 개방 |

## 4. 제품 비전(2 × 4)

이동 브리지(양쪽 Y 레일 + HTD 벨트 + 크로스샤프트), 통 8개(2열), 컵·헹굼은 X 끝에 둔다. 좌표 예시는 `calc/cartesian_model.py`의 `LAYOUT_PRODUCT`에 있다.
