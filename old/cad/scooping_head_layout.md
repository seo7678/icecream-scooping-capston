# CAD — Scooping Head Layout

> 기능·기구학: `docs/scooping_head_mechanism.md`. 치수는 **초안**이다.

## 1. 구성과 인터페이스

```
   Z 기둥 하단 플랜지 (M6 × 4)
   ┌───────────────────────────────┐
   │ 헤드 브래킷 (알루미늄 가공)     │── θ 기어드모터 (24 V, ≥ 8 N·m, 엔코더), 출력축 Ø8 키
   │   상부 레버 l = 25 mm           │   레버 수직 기준 = θ_s +30°, 사용 범위 ±60°
   │   스템 클램프(볼락 퀵핀 #1)     │
   │   push-rod 상단 핀(볼락 퀵핀 #2)│
   └───────────────┬───────────────┘
   ════════════════╧════════════════   304 드립 우산 Ø140, 가장자리 아래로 접음 (splash zone)
                   ┃ 스템 Ø30×3 × 300 (304, 양끝 캡 용접)
                   ┃      ∥ push-rod Ø8 × 300 (304), 스템 중심에서 +25 mm 오프셋
                   ┃
                   ⊙ 피벗 핀 Ø8 (304), 스쿱 보스에 압입, 스템 하단 포크에 회전
                   ◖ 스쿱 R 35 (매장 모델), 하부 레버 l = 25 (스쿱 보스와 일체)
```

## 2. 치수표

| 항목 | 값 | 근거 |
|---|---|---|
| 스템 길이(클램프 → C) | 300 mm | 가장 깊은 C(−205)에서 헤드 하단이 데크 위 +95 mm |
| 스템 | Ø30×3, 304 | 드래그 방향 0.49 mm, σ 41 MPa @ 200 N |
| push-rod | Ø8 × 300, 304 | 좌굴 4.26 kN, 최대 축력 560 N(±60°, 7 N·m) |
| 레버 | 25 mm (상·하 동일) | 평행사변형 |
| θ 범위 | −30° … +90° | 공격 / 포획 |
| 헤드 하우징 높이 | ~100 mm | 모터·클램프 |
| 드립 우산 | Ø140, 304 | 헤드 아래 전체를 덮음 |
| 식품 모듈 질량 | ~0.8 kg(추정) | 스쿱 + 스템 + push-rod + 핀 |

## 3. 식품 모듈 분리 순서 (목표 ≤ 30 s, 공구 없음)

1. θ를 0°로(레버 중립), Z를 서비스 높이로, E-stop 또는 서비스 모드
2. 퀵핀 #2(push-rod 상단) 뽑기
3. 퀵핀 #1(스템 클램프) 뽑기 → 식품 모듈을 아래로 빼냄
4. 세척용 모듈 장착은 역순, 장착 후 θ 원점 확인 사이클

## 4. 설계 주의

- 스쿱 보스 용접부와 스템 캡 용접부는 연마(Ra ≤ 0.8 µm 목표), 내부 모서리 R ≥ 3.2 mm.
- 피벗 핀과 포크 사이는 세척수가 빠지는 열린 구조(틈새 공동 금지).
- θ 레버·모터는 드립 우산 **위**에만 둔다.
