# slop-diagnose

입력: `<분야> <형태>`. 코퍼스가 5편 이상 있어야 의미가 있다.

## 순서

1. `corpus/<분야>/<형태>/` 의 글 중 최대 8편을 고른다.
2. 각 글마다, **원문을 보지 않은 서브에이전트**(Agent 도구)에게 아래 입력만 주고 글을 쓰게 한다. 스타일 지시는 일절 주지 않는다.
   - 형태와 독자 (한 줄)
   - 원문에서 뽑은 **주제 한 줄과 핵심 사실 목록** (원문 문장을 그대로 넣지 않는다)
   - 원문과 비슷한 길이
   결과는 `baseline/<분야>/<형태>/<원문파일명>` 에 저장한다 (`baseline/` 은 git 제외).
3. 수치 비교:
   ```
   python3 pipeline/mv.py profile <분야> <형태>      # 내 수치
   python3 pipeline/mv.py stats baseline/<분야>/<형태>/*   # AI 수치
   python3 pipeline/mv.py slop baseline/<분야>/<형태>/<파일>  # 각각
   ```
   각 지표를 "내 평균 vs AI 평균" 표로 만든다. 이 표가 `profiles/<분야>_<형태>.md` 1번 표의 "AI 기본값" 칸이 된다.
4. 정성 비교: 원문과 baseline 쌍을 나란히 읽고 차이를 적는다. 구조(서두/결말/나열), 어휘, 문장 호흡, 구체성, 어조, 내가 하는데 AI는 안 하는 것. **쌍마다 2~3개, 여러 쌍에서 반복되는 것만 규칙 후보로 올린다.**
5. 결과를 `evals/diagnose_<분야>_<형태>_<날짜>.md` 에 저장한다:
   - 수치 비교 표
   - 반복되는 차이 TOP 5~10 (근거 쌍 파일명 포함)
   - `slop/patterns.json` 에 추가할 패턴 후보 (AI는 쓰고 내 코퍼스에는 없는 표현 중 반복되는 것)
   - 프로파일 규칙 후보
6. 사용자에게 후보를 보여주고 승인된 것만 `slop/patterns.json` 과 프로파일에 반영한다.

## 주의
- 이 진단의 시작점 수치(기본 AI의 슬롭 점수)가 이후 개선을 재는 기준이다. 날짜와 함께 남긴다.
- 패턴 후보는 내 코퍼스에서 같은 표현이 나오는지 `grep` 으로 확인한 뒤 올린다. 내가 쓰는 표현은 금지 목록에 넣지 않는다.
