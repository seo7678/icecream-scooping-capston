# style-interview

목표: 한 분야×형태에 대해 **실제 글 5편 + 취향 답변**을 받아 `corpus/` 와 `profiles/` 의 첫 버전을 만든다.
한 번에 한 분야×형태만 한다. 질문은 한 번에 2~3개씩.

## 1. 범위
- 분야와 형태를 정한다 (예: capstone / meeting-note). 이름은 영어 소문자 kebab-case.
- 독자가 누구인지, 얼마나 공들여 쓰는 글인지 묻는다.

## 2. 샘플 수집
- "직접 쓴 글을 5편 붙여 달라"고 요청한다. 길이는 상관없다. 카톡, 메모, 메일도 된다.
- **AI가 쓰거나 고친 글이 아닌지** 각 글마다 확인한다. 애매하면 뺀다.
- 받는 대로 `corpus/<분야>/<형태>/YYYY-MM-DD_제목.md` 로 저장한다 (날짜를 모르면 `undated_01.md`). 맥락은 `.meta.md` 에 한두 줄.
- 카톡이면 `python3 pipeline/mv.py kakao <내보낸파일> --name <내 이름> --domain <분야>` 로 내 말만 뽑는다. 방법은 `docs/COLLECT.md`.
- 5편 미만이면 5편 미만이라고 분명히 알린다. 그래도 진행은 한다.

## 3. 취향 질문 (글에서 안 보이는 것만)
- 이 형태에서 **절대 안 쓰는 말투/표현**은?
- AI 초안에서 가장 거슬렸던 문장 유형은? (실제 예를 붙여 달라고 한다)
- 격식 수준, 반말/존댓말, 이모지, 줄임말, 영어 섞는 정도
- 시작과 끝은 보통 어떻게 하나 (인사 없이 바로? 한 줄 마무리?)
- 이 형태에서 꼭 들어가는 요소 (예: 수치, 날짜, 담당자)

## 4. 프로파일 만들기
1. `python3 pipeline/mv.py profile <분야> <형태>`
2. 생성된 `profiles/<분야>_<형태>.md` 에 채운다:
   - 수치 표는 `.stats.json` 에서 옮긴다. "AI 기본값" 칸은 비워 두고 `slop-diagnose` 가 채운다.
   - 규칙은 **관찰한 것만** 적는다. 각 규칙 뒤에 근거 글 파일명과 빈도를 괄호로 단다 (예: "마무리 인사 없음 (5편 중 5편)").
   - 대표 예문은 코퍼스에서 **원문 그대로** 발췌한다. 고치지 않는다.
3. 사용자에게 보여주고 "이거 아닌데" 하는 곳을 고친다.
4. 사용자가 "AI가 쓰는 티 난다"고 한 표현은 `slop/allow.txt` 가 아니라 `slop/patterns.json` 에 추가한다. 반대로 사용자가 실제로 쓰는데 걸리는 표현은 `slop/allow.txt` 에 넣는다.

## 하지 말 것
- 샘플 3편 미만으로 규칙을 단정하기
- 사용자가 말하지 않은 취향 지어내기
- 샘플을 고쳐 쓰거나 "정리"해서 저장하기
