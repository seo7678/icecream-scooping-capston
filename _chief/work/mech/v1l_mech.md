## 0. 결론

1. **추천: L-A 이동 베드.** 팬·단열 홀더·힘 플랫폼·컵을 베드에 싣고 베드가 X로 드래그한다. 헤드는 고정 브리지에 Z + θ만 있다. Y 레인은 손으로 인덱스 핀을 옮긴다(−38 / 0 / +38). 구동 모터는 스테퍼 3개(X, Z, θ)다.
2. 단, Chief 원안 그대로(교차빔 1개)면 **강성 때문에 실패한다**. 드래그 힘이 브리지 면에 수직으로 걸리므로 **교차빔을 위아래 2개(4080, 간격 220 mm)** 로 두고, **타워는 A-프레임**(2040 경사 다리)으로 해야 한다. 교차빔 1개면 비틀림 때문에 스쿱 끝이 +3.0 mm(4080) / +7.0 mm(4040) 더 밀린다.
3. 스쿱 끝 X 변위(바닥 C = −75, 부재·레일·구동만): **0.24 mm @ 56 N, 0.43 mm @ 100 N**. 볼트 체결부까지 넣으면(가정 범위) 0.33–0.67 / 0.59–1.20 mm다. 목표 ≤ 1 mm는 공칭 하중에서 충족하고, 100 N에서는 체결부가 무를 때만 넘는다. 옆힘 변위는 0.11 mm @ F_y 30 N이다.
4. **X = TR8 리드 4 + NEMA17**, 드래그 30 mm/s에서 토크 여유 **2.25**(F_STOP 120 N 기준)이다. 40 mm/s에서는 1.69로 떨어진다. **Z = TR8 리드 2**는 μ ≥ 0.088이면 **자립**한다. 따라서 브레이크와 가스스프링은 뺀다(정전 유지 시험이 조건).
5. 베드 가속이 힘 플랫폼 F_x에 주는 관성 오차는 **1.4 N(드래그 램프 0.2 m/s²) / 3.6 N(이송 0.5 m/s²)** 이다. 등속 구간만 판정에 쓰고, 램프 구간은 m·a를 빼서 처리한다.
6. θ는 NEMA17 + 1:27 유성을 **조건부로 유지**한다. 기존 7 N·m는 200 N 하중을 가정한 값이고, V1-L에서는 τ_close가 2.0 N·m(56 N) / 3.5 N·m(100 N)이다. 기어박스 허용 토크가 **3 N·m 연속 / 5 N·m 순간**[S4]이라, V1-S 문서의 "출력 ~9 N·m"는 설계에 쓸 수 없다.
7. 기계 부품 추정은 **42–80만 원**이다(가격 가정, 범위가 넓음). 절감 레버를 모두 쓰면 26–72만 원이다. R8(총 100만 원) 안에 들려면 **기계를 40–45만 원 안에서 사야** 하고, 이는 저가 쪽 조합일 때만 가능하다. 전자·소모품과 합산하는 것은 Chief 몫이다.

## 3. 하중 경로와 경계조건

**좌표·부호.** X_M은 드래그 방향이다. 베드가 −X로 움직여 스쿱은 팬에 대해 +X로 전진한다. 절삭 반력은 스쿱에 −X(F_x), 위(+Z, F_z = 0.5 F_x, **부호 미확인**), ±Y(F_y = 0.3 F_x)로 걸린다(A28). 팬에는 같은 크기의 반대 방향 힘이 걸린다.

**드래그 힘 루프 (L-A)** — 루프 안의 모든 요소가 직렬 스프링이다:

```
스쿱 ─ 피벗 핀 ─ 스템(외팔, 222) ─ SK30×2 ─ 헤드 브래킷 ─ Z 기둥(블록 아래 외팔 ov + 322) ─ Z 블록 쌍(간격 220)
  ─ 교차빔 2개(면외 굽힘, 짝힘 R_u = F·517/220, R_l = F + R_u) ─ A-프레임 타워(다리 축력) ─ 베이스 2040
  ─ KFL08×2(고정단) ─ TR8 나사(축) ─ 황동 너트 ─ 베드 틀 ─ 데크 ─ 단일점 셀 ─ X 부동판 ─ S-빔 ─ 상판
  ─ 홀더 X 스톱 ─ 팬 턱 ─ 팬 ─ 아이스크림 ─ 스쿱
```

- **X 캐리지 컴플라이언스는 빠지는가?** *회전 항은 빠진다.* L-B에서는 X 캐리지 블록이 F·(레버 ~0.6 m)의 모멘트를 받아 기울고(레버² 항), X 빔도 굽는다. L-A에서 드래그 힘이 베드를 기울이려는 모멘트 팔은 172–252 mm뿐이고, 베드 블록은 280 mm 간격으로 넓게 둘 수 있다. 그래서 이 항은 0.001 mm다. **축 방향 구동 강성은 빠지지 않는다.** 베드를 X로 붙잡는 것이 너트이기 때문이다. 다만 나사가 짧아 0.04 mm @ 100 N이고, 드래그 중 하중 방향이 한쪽이라 백래시가 한쪽으로 붙는다. 레일은 X로 자유라 F_x를 받지 않는다.
- **새로 루프에 들어오는 것**은 (1) 포털 교차빔의 **면외 굽힘**과 (2) 타워다. 교차빔 1개로 받으면 비틀림이 된다(금지, §2.3). 드래그 모멘트를 **교차빔 2개의 짝힘**으로 바꾸고 타워를 삼각형으로 해야 부재 축력으로 흐른다. 이 두 항(0.078 + 0.108 mm @ 100 N)이 L-A의 가장 큰 항이다.
- **수직(F_z) 경로 — portion에 직접 영향**: 스쿱 → 기둥 → Z 나사·너트 → 상부 교차빔(수직 굽힘) → 타워 → 베이스 → 베드 블록 → 데크 → **단일점 셀** → 팬. 합계 0.08 mm @ F_z 50 N(셀 처짐 0.05가 대부분)이다.
- **옆(F_y) 경로**: 기둥·스템 굽힘 → Z 블록 짝힘 → 교차빔 축력 → 포털 면 안 + 무릎가새 → 베이스. 면 안이라 강하다.

## 4. 계산 요약 (단위·식·출처)

### 4.1 하중 (출력 §1)

- 1 portion: 레인 270 mm, 깊이 **14.7 mm**, A = 624 mm²(`tub_lane_planner.stroke_volume`). F = u·A(A02). 드래그 힘 레버 z_c = 21.6 mm(`scoop_model` 선분 도심).
- 속도 효과 (v/80)ⁿ(A03)은 30 mm/s에서 ×0.86이다. **보수적으로 무시**했다.

| 수준 | F_x | F_z / F_y | 쓰임 |
|---|---|---|---|
| 공칭 F_nom (u 90 kPa) | **56 N** | 28 / 17 N | 강성 목표 ≤ 1 mm |
| 설계 F_d (u 160 kPa) | **100 N** | 50 / 30 N | 강성·추력·θ 설계, 깊이 적응 시작 |
| 정지 한계 F_STOP = 1.2 F_d | **120 N** | – | 호스트 피드 홀드, 추력 여유 기준 |
| 걸림 F_JAM = 2π·η·T_LO/l | **329 N** | – | 강도 SF, 센서 과부하 (스테퍼 스톨 = 기계적 상한) |

u가 250 kPa(A02 very hard)면 1 portion에 156 N이 필요하다. 이때는 F_TARGET 100 N에서 깊이를 줄이고 **2스트로크**로 채운다(구조 하중을 올리지 않음).

### 4.2 스쿱 끝 강성 (출력 §2)

- 식(레포와 같음): 스템 δ = F·l_s³/(3EI). 기둥은 외팔 ov에 끝 모멘트 F·(헤드+스템+z_c)가 걸린다. 블록 쌍은 K_rot = k·s²/2. 추가한 식: 교차빔 δ = R·S³/(48EI), 타워 k = 2EA·cos²β/L, 나사 k = EA_r/L와 너트·지지 직렬, S-빔 k = 490 N / 0.14 mm[S10 범위의 보수 끝].
- 결과(C = −75, 부재·레일·구동): **L-A 0.24 / 0.43 mm**(231 N/mm), L-A 경량 0.80 / 1.41 mm, L-B 0.22 / 0.40 mm. 팬이 가득 찼을 때(C = +5)는 더 작다.
- **portion에 중요한 것은 X가 아니라 수직이다.** X 변위 0.43 mm에 의한 프레임 회전은 0.048°이고, 깊이 변화는 R·sin30°·φ = 0.015 mm다. X 변위는 레인 끝 벽 여유(10 mm)와 떨림(stick-slip)에만 영향이 있다. 수직 컴플라이언스는 0.08 mm @ F_z 50 N(portion 약 0.8 %)이다. Z 너트 백래시는 F_z가 위이고 W_z 43 N을 넘을 때(F_x > 85 N) 반전해 ≤ 0.1 mm(약 1 %)다. θ 백래시 1°(가정)는 0.31 mm인데, 드래그 토크가 한 방향이라 한쪽으로 붙는다.
- **소프트웨어 보상**: `z_cmd = z_target + C_z·F_z,meas`(스트로크 간·구간 적응에 적용. 드래그 중 실시간 수정은 하지 않음). **허용 조건**: 스쿱 끝 교정 시험(0 → 120 → 0 N, 3회, Z 3높이)에서 R² ≥ 0.99, 히스테리시스 ≤ 0.10 mm, 반복성 σ ≤ 10 % 그리고 ≤ 0.05 mm, 영점 복귀 ≤ 0.05 mm, 드래그 힘 진동 ≤ 20 %. 하나라도 어기면 보상하지 않는다. 체결 미끄럼을 먼저 고치고, 안 되면 F_TARGET을 낮춘다. X는 보상하지 않는다.

### 4.3 X 구동 (출력 §3)

- 동력나사[S6]: T_R = F·d_m/2·(l + πf·d_m·secα)/(πd_m − f·l·secα), η = F·l/(2πT_R). 자립 조건은 f·secα > tanλ다. TR8: d_m 7.0, d_r 6.0(가정), α 15°, μ 0.10–0.20(가정, 일반 범위 0.1–0.3[S12]).
- 스테퍼 곡선(**가정**): 0.40 N·m 평탄 → 400 rpm 이후 일정 출력(17HS19-2004S1 유지토크 0.59 N·m[S5]). **데이터시트 pull-out 곡선으로 교체해야 한다.** 요구 여유 ≥ 2(개루프).
- 요구 추력 = F_STOP 120 + 마찰 5.1 + m·a 2.3 = **127 N**. 베드 질량은 11.4 kg, 행정은 466 mm(레인 시작 → 컵 중심, 여유 포함)다.

| 리드 | 20 / 30 / 40 mm/s 여유 | η | μ_min(자립) | 이송 최대 | 스톨 추력 | 너트 미끄럼 @30 mm/s |
|---|---|---|---|---|---|---|
| 2 | 2.27 / 1.51 / 1.13 | 36 % | 0.088(자립) | 50 mm/s | 458 N | 65 fpm (표 저속 구간 밖) |
| **4** | **2.54 / 2.25 / 1.69** | 52 % | 0.176(경계) | **100 mm/s** | **329 N** | **33 fpm**(5.5–9.7 MPa 구간) |
| 8 | 1.62 / 1.62 / 1.62 | 66 % | 0.351(역구동) | 200 mm/s | 208 N | 17 fpm |

- **선정: 리드 4, 드래그 30 mm/s.** 너트 면압은 127 N / 165 mm² = 0.77 MPa로, Shigley 표 8-4의 20–40 fpm 구간 하한 5.5 MPa의 약 1/7이다[S6]. 임계속도는 1,617 rpm(지지-지지[S7])이라 **양끝 지지가 필수**다(한쪽이 자유면 567 rpm).

### 4.4 베드 관성 오차 (출력 §3.1)

- 오차는 m_top·a로 계산한다(m_top = 팬 + 아이스크림 + 홀더 + 상판 = 7.2 kg). 드래그 램프 0.2 m/s²에서 **1.4 N**(F_nom의 2.6 %), 이송 0.5 m/s²에서 **3.6 N**, 1.0 m/s²에서 7.2 N이다.
- S-빔 50 kg 위 7.2 kg의 고유진동수는 약 111 Hz다. HX711 80 SPS로 읽으면 에일리어싱되므로 **10 SPS + 평균**으로 읽는다.
- 대책: F_x 판정은 **등속 구간만** 쓴다(램프 0.15 s / 2.2 mm와 안정 0.3 s 제외). 램프 구간은 `F_meas − m_top·a_cmd`로 보정한다(m_top은 수직 셀이 매 스트로크 잰다). 스트로크마다 정지 상태에서 영점을 잡고, portion 질량은 정지 후 1 s 뒤에 잰다(A32). 이송 중 관성 성분(≤ 3.6 N)은 이송 충돌 임계 30 N(A37)보다 충분히 작다.

- **판정: 리드 2면 브레이크·가스스프링이 필요 없다**(V1-S S05 브레이크·S06 가스스프링 삭제). 조건은 세 가지다. (1) 조립 후 **정전 유지 시험**: 자중 + 5 kg을 걸고 전원을 끊은 채 두드리며 10분, 처짐 ≤ 0.1 mm. (2) 과윤활 금지(μ < 0.088이면 자립이 깨짐). (3) 나사 위 손잡이로 E-stop 뒤 수동으로 올린다.

### 4.6 θ 구동 (출력 §5)

- 7 N·m의 근거: `docs/13_engineering_calculations.md` §1 τ_close = F·R = **200 N**(A23) × 0.035 m(A05). V1-L 값은 다음과 같다.

| F_x | τ_hold = F·z_c | τ_close = F·R | PG27 3 / 5 N·m[S4] | 로드력 τ/l(l = 25) |
|---|---|---|---|---|
| 56 N | 1.22 N·m | **1.97 N·m** | 연속 정격 안 | 79 N |
| 100 N | 2.16 N·m | **3.50 N·m** | 순간 정격 안(연속 초과) | 140 N |
| 120 N | 2.59 N·m | 4.19 N·m | 순간 정격 안 | 168 N |

- 닫기 0.8 s(25 rpm)에서 모터 × 감속 × η = 4.5 N·m이고, 1.5 s에서는 기어 정격 5 N·m가 상한이다. 이중 push-rod Ø8 × 200의 좌굴 하중은 P_cr = π²EI/L² = 9.6 kN으로, 기어 순간 정격 5 N·m에서의 로드력 200 N 대비 **SF 48**이다.
- **판정**: NEMA17 + 1:27을 유지하되 **출력 ≤ 5 N·m 전류 제한**을 건다. **C-Gate: E0에서 τ_close > 3 N·m이면 교체**한다(1순위 NEMA23 + 유성, 2순위 정격이 확인된 웜 기어). 벨트 감속은 기각한다(GT2는 3.5 N·m에 출력 풀리 반경 ≥ 125 mm가 필요). 이중 push-rod는 **유지**한다(뒤집기 배출에 필요, 추가비 ~1–2만 원).

| 가드 3면 PC + 인터록(S27, 10만) | 아크릴 옆판 2 + **hold-to-run + E-stop 유지** | 완전 분리 없음 → 작업자 입회 시험만 |

## 9. 대안과 트레이드오프

**대안 1 — L-B 저가 이동 갠트리** (팬 고정, X 캐리지가 Z·θ를 싣고 움직임)
- 장점: 팬이 움직이지 않아 **힘 신호에 관성 성분이 없고**, portion 질량도 정지 대기 없이 잴 수 있다. 학생들이 3D 프린터·CNC에서 익숙한 구조다.
- 단점: 옆힘이 X빔을 비튼다(4080 한 개면 1.67 mm @ 30 N). **8080이나 닫힌 상자 단면**이 필요해 +3–5만 원이 들고 무게도 늘어난다. X 나사 800 mm는 임계 909 rpm이라 이송이 61 mm/s 이하로 제한된다. Z·θ 모터 케이블이 체인으로 움직인다.
- 이럴 때 고른다: 베드 관성 보정이 소프트웨어에서 안 풀리거나, 팬 무게가 가정(3.7 kg)보다 훨씬 클 때.

**대안 2 — L-A 경량(4040 기둥·교차빔, 2020 다리) + 소프트웨어 보상**
- 장점: 4080 대신 4040, 다리 2040 대신 2020을 써서 기계비가 약 2–3만 원 줄고(가정), 슬롯 8 부품이 준다.
- 단점: 스쿱 끝 **0.80 / 1.41 mm**(56 / 100 N)이고, 체결부 중간 가정에서는 0.97 / 1.72 mm다. F_d에서 1 mm를 넘으므로 **§4.2 보상 조건을 모두 통과해야** 쓸 수 있다. 무른 구조는 stick-slip 위험도 크다.
- 판정: 절감액에 비해 위험이 크다. **L-A에서 4080 두 곳(교차빔, 기둥)만은 줄이지 않는다.**

(L-C는 기계로는 기각한다: 3018의 Z 45 mm, FDM 베드 크기, GT2 벨트 강도. 중고 프린터는 **부품 기증원**으로만 가치가 있다.)
