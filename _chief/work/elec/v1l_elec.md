## 2. 로드셀 + HX711

### 2.1 HX711 — 데이터시트 원문에서 확인한 값

출처: Avia HX711 datasheet(GitHub 사본 `gandalf15/HX711/Datasheet_hx711_english.pdf`).

| 항목 | 값 |
|---|---|
| 출력 데이터율 | RATE=0: 10 SPS, **RATE=1(DVDD): 80 SPS** |
| 채널·게인 | A: 128/64, B: 32. 풀스케일 ±0.5·AVDD/GAIN (AVDD 5 V, A/128 = ±20 mV) |
| 안정 시간 (전원·리셋·채널/게인 변경 후) | 10 SPS 400 ms, 80 SPS 50 ms |
| 입력 노이즈 (게인 128) | 10 SPS 50 nV rms, 80 SPS 90 nV rms |
| 드리프트 (게인 128) | 오프셋 ±6 nV/°C, 게인 ±5 ppm/°C |
| 공통모드 / CMRR·PSRR | AGND+1.2 … AVDD−1.3 V / 100 dB·100 dB (10 SPS) |
| 전원·온도 | 2.6–5.5 V, < 1.5 mA, −40 … +85 °C |
| 직렬 | 25펄스 = A/128. PD_SCK High 최대 50 µs, **60 µs 넘으면 파워다운** |

→ **80 SPS로 쓴다(Chief 결정).** 흔한 녹색 모듈은 RATE가 GND에 묶여 있을 수 있다. 그러면 RATE 핀을 들어 DVDD에 잇는다(**구매 모듈 회로 확인 필요**). 셀마다 HX711을 1개씩 쓰고 채널 A/128로 고정한다(채널 전환 대기 없음).
→ 기계 담당의 에일리어싱 우려(셀 위 질량의 고유진동 ~111 Hz, S-빔 기준 추정)는 제어 T6 시험에서 확인한다. 나오면 고무 패드로 감쇠를 준다. 추정·판정은 등속 구간 평균으로 한다(제어 §1.1 ①).

### 2.2 로드셀 용량 — 과부하 스톱 전제의 판단

| | 수직 (L29) | X 수평 (L30) |
|---|---|---|
| 기계안 | 단일점 30 kg | S-빔 50 kg |
| **v1 선택** | **Seeed 단일점 20 kg** (2.0 ± 0.15 mV/V, C2, 안전과부하 150 %, 플랫폼 350 × 350) | **Seeed 단일점 50 kg** (같은 사양, 50 kg) — Chief 채택 절감 3 |
| 정격 / 안전과부하 | 196 N / 294 N | 490 N / 735 N |
| 정상 최대 하중 | ≈ 123 N (정격의 63 %) | F_STOP 120 + 관성 3.6 ≈ 124 N (25 %) |
| 걸림·최악 하중 | Z 하강력 ~500 N + 자중 → **30 kg(294 N)도 넘음** | X 스톨 추력 F_JAM 329 N (정격의 **67 %**) |
| 스톱 없이 버티나 | 아니다 (30 kg도 마찬가지) | **버틴다** |
| 기계식 스톱 역할 | **주 보호**. 정격 110–120 %(215–235 N)에서 닿게 | 2중 보호. F_STOP + 관성(124 N)에서는 닿지 않고 정격 전(≈ 250–350 N)에 닿게 |
| 노이즈 (여기 4.3 V, 80 SPS) | 0.21 g rms | 0.52 g rms (0.005 N) |
| C2 합성오차 ±0.03 %RO | ±6 g | ±15 g (F_x에는 무관한 크기) |
| 가격 | 12,720원 (검색 결과) | 15,100원 (검색 결과, 판매 페이지 SKU 확인 필요) |

- **수직을 20 kg으로 둔 이유.** Z 최대 하강력(~500 N)은 기계안 30 kg 셀의 정격(294 N)도 넘는다. 그래서 어느 쪽이든 기계식 스톱이 필요하다. 스톱이 전제라면 분해능·합성오차가 좋은 20 kg이 portion 질량 측정에 유리하다.
- **X를 50 kg으로 둔 이유.** 걸림 추력 329 N이 정격의 67 %라서 스톱이 어긋나도 셀이 파손되지 않는다. F_x 측정에는 0.005 N 노이즈면 충분하다. 20 kg이면 329 N에서 스톱에만 의존한다.
- **스톱 간극은 0.3 mm에서 시작**하되 그대로 두지 않는다. 셀의 정격 처짐을 물병 하중으로 잰 뒤 위 목표 하중에서 닿게 조정한다. 셀 처짐이 작으면(0.3 mm 미만) 0.3 mm 간극으로는 스톱이 닿기 전에 셀이 과부하된다.
- **플렉셔(Chief 채택 절감 5)**: 판스프링이 F_x 일부를 가져가므로 **현장 교정**이 조건이다. 도르래 + 물병으로 0 → 120 N을 3회 반복한다. 플렉셔 X 강성은 셀 강성(정격하중 / 실측 처짐)의 1 % 이하가 되게 얇게 만든다.
- 모서리 하중: 홀더 외곽(~480 × 285, 기계 추정)이 플랫폼 기준 350 mm를 넘는다 → 분동을 네 모서리에 놓아 오차를 확인한다(**확인 필요**).

### 2.3 분해능과 노이즈 (계산)

HX711 풀스케일은 ±0.5/128 = **±3.906 mV/V**다. 2.0 mV/V 셀은 정격하중에서 이 범위의 51 %를 쓴다.

| 셀 | counts/g | 1 LSB | 10 SPS 노이즈 (rms / p-p ≈ 6.6σ) | 80 SPS (rms / p-p) |
|---|---|---|---|---|
| 20 kg, 2.0 mV/V (여기 4.3 V 가정) | 214.7 | 4.66 mg | 0.116 / 0.77 g | 0.209 / 1.38 g |
| 50 kg, 2.0 mV/V | 85.9 | 11.6 mg | 0.291 / 1.92 g | 0.523 / 3.45 g |

- 데이터시트 입력 노이즈만 반영한 값이라 **정지 상태 60 s 로깅으로 실측**해야 한다.
- 접촉 3 N(306 g)은 20 kg 셀 80 SPS p-p(1.38 g)의 약 220배다.
- portion ±1 g는 노이즈만 보면 가능하다. 다만 합성오차(±6 g FS)·크리프 때문에 **스쿱 직전 영점 → 직후 측정(30 s 이내)**, 6 kg 부근 물병 스텝 교정, 셀과 홀더 사이 **단열 스페이서**가 전제다. ±1 g는 목표이며 E0에서 검증한다.

### 2.5 모듈 결선 주의

- 4선(E+, E−, A+, A−). 선 색은 셀마다 다르다. 누르면 값이 커지게 맞춘다. VCC 옆에 10 µF + 100 nF.
- **HX711과 Nano는 이동 베드 위에** 둔다. 베드 밖으로 나가는 선(USB, Nano 출력 2가닥, Z-높이 스위치 1가닥, GND)은 모두 디지털이다.

## 3. 온도 — K형 열전대 + MAX6675 / MAX31855

| 항목 | MAX6675 | MAX31855K |
|---|---|---|
| 판독 범위 | **0 … +1024 °C** | −270 … +1800 °C |
| 분해능 | 12-bit, 0.25 °C | 14-bit 부호 있음, 0.25 °C |
| 정확도 | 8 LSB (0 … +700 °C) | ±2 °C (−200 … +700 °C, K형) |
| 변환 시간 | 확인 필요 | 70 ms typ / 100 ms max |
| **−20 °C 측정** | **불가** | **가능** |

출처: Analog Devices 데이터시트의 검색 결과 요약. 변환식 V_OUT = 41.276 µV/°C × (T_R − T_AMB)는 데이터시트 8쪽을 인용한 라이브러리 README(RobTillaart/MAX31855_RT)로 확인했다.

**선형 근사 오차 (NIST ITS-90 K형 다항식으로 계산).** 검산값: E(−20 °C) = −0.7775 mV, E(25 °C) = 1.0002 mV.

| 냉접점 | 실제 −20 °C | 실제 −14 °C | 실제 −10 °C |
|---|---|---|---|
| 20 °C | −18.17 (+1.83) | −12.59 (+1.41) | −8.83 (+1.17) |
| 25 °C | −18.07 (+1.93) | −12.48 (+1.52) | −8.73 (+1.27) |

→ 보정 없이 쓰면 −14 °C에서 +1.4–1.5 °C 높게 읽는다. 대책은 다음과 같다.
1. 소프트웨어 **NIST 역다항식 보정**.
2. 얼음물 0 °C 점검 + 기준 온도계(L84, 빌림) 비교.
3. **비접지형 프로브**를 쓴다. 칩이 GND/VCC 단락을 고장으로 잡기 때문이다(확인 필요).
4. 절대 ±0.5 °C가 필요하면 PT100 + MAX31865(가격·사양 확인 필요).

| | D7 → 4.7 kΩ → Q1 베이스 | 허가 출력 | B–E 100 kΩ |
| | D6 → 4.7 kΩ → Q2 베이스 | 프로브 출력 | B–E 100 kΩ |
| | A0 / A1 / A2 / A3 | Z-높이 / X-창 / 레인 핀 / 발판 보조 접점 | INPUT_PULLUP, 스위치 → GND |

- 마이크로스텝(DRV8825 점퍼, 제어 §2.3): **X·Z 1/4, θ 1/8**. 스텝률 계산: X 200 step/mm × 60 mm/s = 12 kHz, Z 400 step/mm × 30 mm/s = 12 kHz, θ 119.3 step/° × 150 °/s = 17.9 kHz → 모두 30 kHz(GRBL README) 이하.
- **Uno·Nano는 USB 급전**이다(Chief 허용). USB가 빠지면 두 보드가 꺼져 스텝이 즉시 멈추고 위치를 잃는다. Z 자립이 전제다. VIN 12 V 강압(L50, 3,000원 추정)은 선택이며 총액에 넣지 않았다.
- Nano GND와 Uno GND는 **직결선**으로 잇는다(NPN 이미터 기준).

### 5.3 접지

- 스타 접지는 PSU V− 단자대 한 점이다. CNC Shield GND, Uno GND, Nano GND를 여기에 모은다. PSU FG는 알루미늄 프레임(보호접지)에 잇는다. V−와 FG가 PSU 안에서 연결되는지는 **확인 필요**하다.
- 노트북 충전기가 접지형이면 접지 루프가 생긴다 → **힘 측정 중에는 노트북을 배터리로** 돌린다.

### 5.4 E-stop · 허가선 · 프로브 배선도 (제어 요청 반영)

```
 AC 220 V ─[C14 인렛: 스위치 + T퓨즈]─> LRS-150-24 ── FG ─> 프레임(PE)
                                          │+24V                           │0V ─ 스타 접지 단자대
   +24V ─[F1 1A]─ E-stop NC(11-12) ─┬─[모터 ON 버튼 NO]─┬─ K1 코일 ─ 0V
                                    └─[K1 NO 자기유지]──┘
   +24V ─[F2 5A]─ K1 주접점 NO ─> +24V_MOTOR ─> CNC Shield VMOT (DRV8825 ×3) + 냉각팬
   스타 접지 ─ CNC Shield GND ─ Uno GND ═══ Nano GND (직결선, 케이블 체인)

 [허가선 — Uno A1 = GRBL 도어, 반전: LOW여야 허가]
   Uno A1 ─┬─ (내부 풀업 + 외부 10 kΩ → 5 V, 0.1 µF → GND)
           └─ 발판 NO(밟으면 닫힘) ── C ┐
                                       Q1 NPN      B ── 4.7 kΩ ── Nano D7
                                  GND ─ E ┘        B ── 100 kΩ ── E
   → 발을 뗌 / Nano가 D7 OFF(과부하 120 N 래치, 워치독 300 ms, R7 인터록, 레인 핀) /
     Nano 무전원 / 선 끊김 → A1 = HIGH → GRBL 도어 hold (감속 정지, 위치 유지, 닫히기 전 재개 불가)

 [프로브 — Uno A5, $6 = 1: LOW = 비접촉]
   Uno A5 ─┬─ (풀업 10 kΩ, 0.1 µF)
           └─ C ┐ Q2 NPN   B ── 4.7 kΩ ── Nano D6 ,  B ── 100 kΩ ── E
         GND ─ E ┘
   → F_z ≥ 3 N, Nano 무전원, 선 끊김이면 HIGH = 트리거 → G38.2 정지 (미무장이면 G38.2 시작 거부)

 [E-stop 보조]  E-stop NO(23-24) ── Uno A0 ── GND : 누르면 GRBL 리셋 → 재원점 강제
 [Nano 입력]    A0 Z-높이, A1 X-창, A2 레인 핀, A3 발판 보조 접점 (각 스위치 → GND, INPUT_PULLUP)
 [보드 전원]    노트북 USB → Uno, 노트북 USB → Nano (선택: 24→12 V 강압 → VIN)
```

- 접점 번호(11-12, 23-24)는 예시다. 제품 표기를 따른다.
- **E-stop이 안전 기능(정지 범주 0, 모터 전원 차단)**이다. 허가선(발판 + Nano)은 위치를 유지하는 감속 정지(범주 2)이고 펌웨어에 의존한다.
- **남는 약점**: 허가선이 **GND에 단락**되면 허가 상태로 고착된다. 끊김과 전원 상실은 정지 쪽으로 가지만, 단락은 그렇지 않다. 그래서 E-stop과 가드를 1차 방호로 두고, 매 시험 전 점검에 "발을 떼면 멈추는가, Nano USB를 빼면 멈추는가"를 넣는다.
- LY2 계열은 범용 릴레이다(강제가이드 접점 아님) → 매 시험 전 E-stop 기능을 점검한다. 이 구성은 연구실 시험용 최소 구성이며, 위험성평가서에 그렇게 적는다.

### 5.5 E-stop: 모터 전원 차단 vs ENABLE만 차단

| 기준 | 모터 전원 차단 (K1 → VMOT) — **채택** | ENABLE만 차단 |
|---|---|---|
| 소프트웨어·보드 고장과 무관한가 | 무관 | 드라이버·배선·보드가 정상이어야 동작 |
| 단일 고장 | 접점 용착 → 매회 점검으로 발견 | ENABLE 단선·설정 오류·MOSFET 단락이면 통전 지속 |
| 위치 | 잃음 → 재원점 (A0 리셋으로 강제) | 잃음 → 재원점 |
| Z 낙하 | 리드 2 자립 (기계 정전 유지 시험) | 같음 |
| 부품 | 릴레이·소켓·버튼 ≈ 13,000원 | 거의 없음 |

## 6. 배선·노이즈 주의점

1. 로드셀·열전대 선과 모터선은 10 cm 이상 떨어뜨리고, 교차는 직각으로 한다. 모터선은 상별로 꼰다.
2. 로드셀 실드는 **HX711 쪽 GND 한 점**에만 잇는다.
3. 허가선·프로브선은 케이블 체인을 지나 길어진다. 그래서 Uno 쪽에 **외부 풀업 10 kΩ + 0.1 µF**를 둔다(L49). GRBL 내부 풀업만으로는 노이즈에 약하다.
4. NPN 베이스–이미터 **100 kΩ**: Nano가 꺼지거나 핀이 Hi-Z일 때 트랜지스터가 확실히 꺼지게 한다.
5. 드라이버 VMOT에 전해 커패시터(드라이버당 ≥ 47 µF 권장, 쉴드 실장 여부 확인)를 단다. 전원이 켜진 상태에서 모터 커넥터를 뽑지 않는다.
6. DRV8825 전류는 Vref로 맞춘다(검출저항값 확인 필요).
7. HX711 PD_SCK High가 60 µs를 넘지 않게, 읽는 동안 인터럽트를 막는다.
8. 결로 대비: Nano·HX711은 홀더보다 높게, 물받이 밖에 둔다.
9. 24 V 모터 버스는 18 AWG, 신호선은 22–24 AWG. 페룰·XH 커넥터로 마감한다.
