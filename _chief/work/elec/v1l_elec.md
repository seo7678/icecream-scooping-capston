## 2. 로드셀 + HX711

### 2.1 HX711 — 데이터시트 원문에서 확인한 값

출처: Avia HX711 datasheet(GitHub 사본 `gandalf15/HX711/Datasheet_hx711_english.pdf`).

| 항목 | 값 |
|---|---|
| 출력 데이터율 | RATE=0: 10 SPS, **RATE=1(DVDD): 80 SPS** |
| 채널·게인 | A: 128/64, B: 32. 풀스케일 ±0.5·AVDD/GAIN (AVDD 5 V, A/128 = ±20 mV) |
| 안정 시간 (전원·리셋·채널/게인 변경 후) | 10 SPS 400 ms, 80 SPS 50 ms |
| 입력 노이즈 (게인 128) | 10 SPS 50 nV rms, 80 SPS 90 nV rms |
| 드리프트 (게인 128) | 오프셋 ±6 nV/°C, 게인 ±5 ppm/°C |
| 공통모드 / CMRR·PSRR | AGND+1.2 … AVDD−1.3 V / 100 dB·100 dB (10 SPS) |
| 전원·온도 | 2.6–5.5 V, < 1.5 mA, −40 … +85 °C |
| 직렬 | 25펄스 = A/128. PD_SCK High 최대 50 µs, **60 µs 넘으면 파워다운** |

→ **80 SPS로 쓴다(Chief 결정).** 흔한 녹색 모듈은 RATE가 GND에 묶여 있을 수 있다. 그러면 RATE 핀을 들어 DVDD에 잇는다(**구매 모듈 회로 확인 필요**). 셀마다 HX711을 1개씩 쓰고 채널 A/128로 고정한다(채널 전환 대기 없음).
→ 기계 담당의 에일리어싱 우려(셀 위 질량의 고유진동 ~111 Hz, S-빔 기준 추정)는 제어 T6 시험에서 확인한다. 나오면 고무 패드로 감쇠를 준다. 추정·판정은 등속 구간 평균으로 한다(제어 §1.1 ①).

### 2.2 로드셀 용량 — 과부하 스톱 전제의 판단

| | 수직 (L29) | X 수평 (L30) |
|---|---|---|
| 기계안 | 단일점 30 kg | S-빔 50 kg |
| **v1 선택** | **Seeed 단일점 20 kg** (2.0 ± 0.15 mV/V, C2, 안전과부하 150 %, 플랫폼 350 × 350) | **Seeed 단일점 50 kg** (같은 사양, 50 kg) — Chief 채택 절감 3 |
| 정격 / 안전과부하 | 196 N / 294 N | 490 N / 735 N |
| 정상 최대 하중 | ≈ 123 N (정격의 63 %) | F_STOP 120 + 관성 3.6 ≈ 124 N (25 %) |
| 걸림·최악 하중 | Z 하강력 ~500 N + 자중 → **30 kg(294 N)도 넘음** | X 걸림 283–579 N(기계 RT1: 정지 토크 0.59 N·m @ 2.0 A, μ 0.10이 상한). 스톱 케이지가 셀 몫을 ≤ 245 N으로 제한(기계 §1) |
| 스톱 없이 버티나 | 아니다 (30 kg도 마찬가지) | 283–490 N은 버팀, 579 N 상한은 정격 초과(안전과부하 735 N 안) → 스톱이 몫을 제한 |
| 기계식 스톱 역할 | **주 보호**. 정격 110–120 %(215–235 N)에서 닿게 | 2중 보호. F_STOP + 관성(124 N)에서는 닿지 않고 정격 전(≈ 250–350 N)에 닿게 |
| 노이즈 (여기 4.3 V, 80 SPS) | 0.21 g rms | 0.52 g rms (0.005 N) |
| C2 합성오차 ±0.03 %RO | ±6 g | ±15 g (F_x에는 무관한 크기) |
| 가격 | 12,720원 (검색 결과) | 15,100원 (검색 결과, 판매 페이지 SKU 확인 필요) |

- **수직을 20 kg으로 둔 이유.** Z 최대 하강력(~500 N)은 기계안 30 kg 셀의 정격(294 N)도 넘는다. 그래서 어느 쪽이든 기계식 스톱이 필요하다. 스톱이 전제라면 분해능·합성오차가 좋은 20 kg이 portion 질량 측정에 유리하다.
- **X를 50 kg으로 둔 이유.** 걸림 하중(283–579 N)이 안전과부하 735 N 안이라 스톱이 어긋나도 셀이 파손되지 않는다. F_x 측정에는 0.005 N 노이즈면 충분하다. 20 kg이면 스톱에만 의존한다.
- **스톱 간극은 0.3 mm에서 시작**하되 그대로 두지 않는다. 셀의 정격 처짐을 물병 하중으로 잰 뒤 위 목표 하중에서 닿게 조정한다. 셀 처짐이 작으면(0.3 mm 미만) 0.3 mm 간극으로는 스톱이 닿기 전에 셀이 과부하된다.
- **플렉셔(Chief 채택 절감 5)**: 판스프링이 F_x 일부를 가져가므로 **현장 교정**이 조건이다. 도르래 + 물병으로 0 → 120 N을 3회 반복한다. 플렉셔 X 강성은 셀 강성(정격하중 / 실측 처짐)의 1 % 이하가 되게 얇게 만든다.
- 모서리 하중: 홀더 외곽(~480 × 285, 기계 추정)이 플랫폼 기준 350 mm를 넘는다 → 분동을 네 모서리에 놓아 오차를 확인한다(**확인 필요**).

### 2.3 분해능과 노이즈 (계산)

HX711 풀스케일은 ±0.5/128 = **±3.906 mV/V**다. 2.0 mV/V 셀은 정격하중에서 이 범위의 51 %를 쓴다.

| 셀 | counts/g | 1 LSB | 10 SPS 노이즈 (rms / p-p ≈ 6.6σ) | 80 SPS (rms / p-p) |
|---|---|---|---|---|
| 20 kg, 2.0 mV/V (여기 4.3 V 가정) | 214.7 | 4.66 mg | 0.116 / 0.77 g | 0.209 / 1.38 g |
| 50 kg, 2.0 mV/V | 85.9 | 11.6 mg | 0.291 / 1.92 g | 0.523 / 3.45 g |

- 데이터시트 입력 노이즈만 반영한 값이라 **정지 상태 60 s 로깅으로 실측**해야 한다.
- 접촉 3 N(306 g)은 20 kg 셀 80 SPS p-p(1.38 g)의 약 220배다.
- portion ±1 g는 노이즈만 보면 가능하다. 다만 합성오차(±6 g FS)·크리프 때문에 **스쿱 직전 영점 → 직후 측정(30 s 이내)**, 6 kg 부근 물병 스텝 교정, 셀과 홀더 사이 **단열 스페이서**가 전제다. ±1 g는 목표이며 E0에서 검증한다.

### 2.5 모듈 결선 주의

- 4선(E+, E−, A+, A−). 선 색은 셀마다 다르다. 누르면 값이 커지게 맞춘다. VCC 옆에 10 µF + 100 nF.
- **HX711과 Nano는 이동 베드 위에** 둔다. 베드 밖으로 나가는 선(USB, Nano 출력 2가닥, Z-높이 스위치 1가닥, GND)은 모두 디지털이다.

## 3. 온도 — K형 열전대 + MAX6675 / MAX31855

| 항목 | MAX6675 | MAX31855K |
|---|---|---|
| 판독 범위 | **0 … +1024 °C** | −270 … +1800 °C |
| 분해능 | 12-bit, 0.25 °C | 14-bit 부호 있음, 0.25 °C |
| 정확도 | 8 LSB (0 … +700 °C) | ±2 °C (−200 … +700 °C, K형) |
| 변환 시간 | 확인 필요 | 70 ms typ / 100 ms max |
| **−20 °C 측정** | **불가** | **가능** |

출처: Analog Devices 데이터시트의 검색 결과 요약. 변환식 V_OUT = 41.276 µV/°C × (T_R − T_AMB)는 데이터시트 8쪽을 인용한 라이브러리 README(RobTillaart/MAX31855_RT)로 확인했다.

**선형 근사 오차 (NIST ITS-90 K형 다항식으로 계산).** 검산값: E(−20 °C) = −0.7775 mV, E(25 °C) = 1.0002 mV.

| 냉접점 | 실제 −20 °C | 실제 −14 °C | 실제 −10 °C |
|---|---|---|---|
| 20 °C | −18.17 (+1.83) | −12.59 (+1.41) | −8.83 (+1.17) |
| 25 °C | −18.07 (+1.93) | −12.48 (+1.52) | −8.73 (+1.27) |

→ 보정 없이 쓰면 −14 °C에서 +1.4–1.5 °C 높게 읽는다. 대책은 다음과 같다.
1. 소프트웨어 **NIST 역다항식 보정**.
2. 얼음물 0 °C 점검 + 기준 온도계(L84, 빌림) 비교.
3. **비접지형 프로브**를 쓴다. 칩이 GND/VCC 단락을 고장으로 잡기 때문이다(확인 필요).
4. 절대 ±0.5 °C가 필요하면 PT100 + MAX31865(가격·사양 확인 필요).

### 5.3 접지 (합판 프레임 반영, Red Team M6)

- 프레임이 합판이므로 보호접지 대상은 **PSU 금속 외함**이다. 인렛 접지 핀을 PSU FG 단자에 반드시 잇는다.
- 금속 부품(4080 Z 기둥, SBR16 레일, Al 10T 브래킷, 모터 몸체)은 24 V SELV 쪽이다. 정전기·노이즈 대책으로 Z 기둥 한 점에서 FG로 본딩하는 것은 **선택**이다.
- 스타 접지는 PSU V− 단자대 한 점이다. CNC Shield GND, Uno GND, Nano GND(직결선)를 여기에 모은다. V−와 FG가 PSU 안에서 연결되는지는 확인 필요하다.
- 힘 측정 중에는 노트북을 배터리로 돌린다(접지 루프 회피).

### 5.4 E-stop · 허가선 · 프로브 · 되읽기 배선도

```
 AC 220 V ─[C14 인렛: 스위치 + T퓨즈]─> LRS-150-24 ── FG ─> 인렛 PE (선택: Z 기둥 본딩)
                                          │+24V                            │0V ─ 스타 접지 단자대
   +24V ─[F1 1A]─ E-stop NC(11-12) ─┬─[모터 ON 버튼 NO]─┬─ K1 코일 ─ 0V
                                    └─[K1 NO 자기유지]──┘
   +24V ─[F2 5A]─ K1 주접점 NO ─> +24V_MOTOR ─┬─> CNC Shield VMOT (DRV8825 ×3) + 냉각팬
                                              └─ 47 kΩ ─┬─ Nano A5 (모터 전원 상태)
                                                       10 kΩ   5.1 V 제너   0.1 µF
                                                        └───────┴─────────┴── GND
   스타 접지 ─ CNC Shield GND ─ Uno GND ═══ Nano GND (직결선, 케이블 체인)

 [허가선 — Uno A1 = GRBL 도어, 반전: LOW여야 허가]
   Uno 5V ─ 10 kΩ ─┬─ Uno A1 (+ 0.1 µF → GND)
                   └── 발판 NO (보호관 L98) ──┬── C ┐ Q1 NPN   B ─ 4.7 kΩ ─ Nano D7 ;  B ─ 100 kΩ ─ E
                                             │     E ┘─ GND
                                             ├─ 100 kΩ ─ Nano 5V          (컬렉터 풀업)
                                             └─ 100 kΩ ─┬─ Nano A6        (되읽기)
                                                        └─ 10 nF ─ GND
 [프로브선 — Uno A5, $6 = 1: LOW = 비접촉]
   Uno 5V ─ 10 kΩ ─┬─ Uno A5 (+ 0.1 µF)
                   └──────────────────────────┬── C ┐ Q2 NPN   B ─ 4.7 kΩ ─ Nano D6 ;  B ─ 100 kΩ ─ E
                                              │     E ┘─ GND
                                              └─ 100 kΩ ─┬─ Nano A7 (되읽기)
                                                         └─ 10 nF ─ GND
 [E-stop 보조]  E-stop NO(23-24) ── Uno A0 ── GND : 누르면 GRBL 리셋 → 재원점
 [Nano 입력, INPUT_PULLUP, 스위치 → GND]
   A0 Z-높이 · A1 X-창 · A2 레인 −38 · A3 레인 0 · A4 레인 +38 · D8 발판 보조 접점
 [보드 전원]  노트북 USB → Uno,  노트북 USB → Nano
```

**동작**
- **허가**는 발을 밟고(NO 닫힘) Nano가 Q1을 켤 때만 A1이 LOW가 되는 상태다.
- Nano가 Q1을 켜는 조건: 무장, 래치 없음, 하트비트, **레인 스위치 정확히 1개**, VMOT ON, (Z-높이 또는 X-창). 이 조건과 120 N 정지는 제어 §8.1을 따른다.
- 발을 떼거나, Nano가 Q1을 끄거나, Nano가 꺼지거나, 선이 끊기면 A1은 HIGH가 되고 GRBL은 도어 hold(감속 정지, 위치 유지)로 간다.
- **E-stop**은 정지 범주 0이다. K1이 모터 24 V를 끊고 A0로 GRBL을 리셋한다. 해제한 뒤에도 "모터 ON" 버튼을 눌러야 전원이 돌아온다.

**되읽기(A6·A7)와 저항값 — 전자 수정**
- 제어안은 되읽기 직렬저항이 10 kΩ다. Nano가 꺼지면 그 핀은 보호 다이오드로 약 0.6 V에 묶인다(가정). 그때 발을 밟고 있으면 A1 전압은 다음과 같다. Uno 풀업은 내부 20–50 kΩ(데이터시트 확인 필요)과 외부 10 kΩ의 병렬이다.

| 되읽기 구성 | Uno 풀업 6.7 kΩ | 8.3 kΩ | ATmega VIH 최소 0.6·VCC = 3.0 V |
|---|---|---|---|
| 10 kΩ 되읽기 (제어안) | 3.24 V | **3.00 V** | 경계 → "허가"로 읽힐 수 있음 |
| **100 kΩ 되읽기 ∥ 100 kΩ 컬렉터 풀업 (채택)** | 4.48 V | **4.37 V** | 여유 있게 HIGH(정지) |

- 100 kΩ 소스 저항에서 ADC를 읽으려면 핀 쪽 10 nF(시정수 1 ms)가 필요하다. 80 SPS 샘플에는 충분하다.
- **컬렉터 풀업(100 kΩ → Nano 5 V)을 둔 이유**: 발을 떼면 Q1 컬렉터 쪽 선이 A1에서 떨어진다. 그때 풀업이 없으면 떠 있어서 되읽기 값이 정해지지 않는다. 풀업이 있으면 이 구간(발판 ↔ 베드, 케이블 체인 포함) 어디서 GND 단락이 나도 LOW로 보인다.
- 발판 ↔ Uno 구간의 단락은 발을 뗀 상태에서는 Nano가 볼 수 없다. 이 경우는 호스트의 `Pn:D` 대조가 잡는다(제어 §8.5 ②).
- **남는 한계**(제어 §8.5): 운전 중(허가 ON, 발 밟음)에 생긴 단락은 기대 상태가 '열림'이 되는 순간에만 드러난다.

**발판 접점(L62)**
- 허가선에는 NO 접점을 쓰고, 발판 상태 기록은 D8로 한다.
- 검색으로 확인한 KACON HRF-MD2는 "1a1b"다. **두 접점이 전환형(C-NO-NC 공통 단자)이면 두 회로를 분리할 수 없다.** 그 경우 D8 대신 A6 되읽기로 발판 상태를 추정하거나, 페달에 마이크로스위치 1개를 덧댄다(+1,200원).

### 5.5 E-stop: 모터 전원 차단 vs ENABLE만 차단

| 기준 | 모터 전원 차단 (K1 → VMOT) — **채택** | ENABLE만 차단 |
|---|---|---|
| 소프트웨어·보드 고장과 무관 | 무관 | 드라이버·배선·보드가 정상이어야 동작 |
| 단일 고장 | 접점 용착 → **VMOT 감지(A5)가 드러냄** + 매회 점검 | ENABLE 단선·설정 오류·MOSFET 단락이면 통전 지속 |
| 위치 | 잃음 → 재원점(A0 리셋으로 강제) | 잃음 → 재원점 |
| Z 낙하 | 리드 2 자립(기계 정전 유지 시험) | 같음 |
| 부품 | 릴레이·소켓·버튼 ≈ 13,000원 | 거의 없음 |

- LY2 계열은 범용 릴레이다(강제가이드 아님). 이 구성은 연구실 시험용 최소 구성이며, 위험성평가서에 그렇게 적는다. 매 시험 전 점검: E-stop, 발 떼기, Nano USB 빼기, 선로 자가시험.

## 6. 배선·노이즈 주의점

1. 로드셀·열전대 선과 모터선은 10 cm 이상 떨어뜨린다. 모터선은 상별로 꼰다.
2. HX711은 셀 옆(베드 위)에 둔다. 셀 자체 리드선이 닿으면 쉴드 케이블(L34)은 필요 없다. 이것이 F3a 후보다.
3. 허가선·프로브선은 케이블 체인을 지나 길다 → Uno 쪽 외부 풀업 10 kΩ + 0.1 µF. 발판 케이블 바닥 구간에는 보호관(L98)을 씌운다.
4. NPN B–E 100 kΩ: Nano가 꺼지거나 핀이 Hi-Z일 때 트랜지스터가 꺼지게 한다.
5. VMOT에 드라이버당 ≥ 47 µF. 전원이 켜진 채로 모터 커넥터를 뽑지 않는다.
6. HX711 PD_SCK High는 60 µs를 넘지 않게 한다(파워다운).
7. 결로: 전장품은 홀더보다 높게, 물받이 밖에 둔다. 합판은 방수 도장한다(L90).

### 8.2 결과 (예비비 100,000원 유지)

| 구성 | 구매+배송 | 총액 | R8 여유 (≤ 900,000 / ≤ 1,000,000) |
|---|---|---|---|
| 기준 | 988,721 | 1,088,721 | −88,721 |
| 경로 A (C13 + C16 + C17) | 941,021 | 1,041,021 | **−41,021** |
| 경로 A + C14 + C18 | 907,611 | 1,007,611 | −7,611 |
| 경로 B (F1 + F2 + F3a–h) | 931,561 | 1,031,561 | **−31,561** |
| 경로 B + C14 + C18 | 898,151 | 998,151 | **+1,849** |
| 경로 A + B | 883,861 | 983,861 | +16,139 |
| **권장: A + C14 + C18 + F3a·b·c·e·f** | **882,611** | **982,611** | **+17,389** |

- **판정**:
  - 경로 A 단독, 경로 B 단독 모두 R8을 닫지 못한다.
  - 공통 조달(C14 + C18)을 더하면 B는 +1,849원으로 겨우 닫히고, A는 −7,611원이 남는다.
  - 여유 1–2만 원은 추정 58 % 안의 잡음 수준이다. 그래서 **R8 판정은 D7 화물·C18 묶음·L20·L37 견적이 나온 뒤에 다시 한다.**
- **권장 조합의 근거**:
  - 경로 A(학교 자원)는 시험 증거를 잃지 않는다.
  - F3 중 a·b·c·e·f는 판정·온도 기록·디버깅 재료와 무관하다.
  - F1(온도 모듈)과 F3h(점토)는 남긴다.
  - 학교 자원이 없으면 "경로 B + 공통 조달"만 남는다. 이때 F1의 대가(8.3)를 받아들여야 한다.

### 8.3 F1(온도 기록 모듈 제외)의 영향 — 시험 계획 기준

| 시험 계획 항목 | 열전대가 있을 때 | 빌린 기준 온도계 수동 기록일 때 |
|---|---|---|
| 재템퍼링 규칙: 코어 열전대가 목표 ±1 K 안에 들 때까지(14–39 h, DECISIONS) | 코어에 꽂아 연속 기록 → 도달 시점 확정 | 탐침을 수시로 찔러 확인. 기록 간격이 길고 찌를 때마다 열 교란 |
| TH-1 (1주, 빌린 냉동고 최고 설정 48 h) → G-TH(온도조절기 구매, 예비비 #1) | 48 h 로그 | 수동 몇 점 → 게이트 판단 근거 약함 |
| E0·CG2의 T_cut [°C] (스트로크별) | Nano 로그에 자동 | 세션 전후 수동 값만 → 온도 효과 분석(E0 −18 / −14 °C) 약해짐 |
| 운전 중 −14 ± 1 °C 벗어나면 냉동고 복귀 | 자동 경고 | 작업자가 주기적으로 확인 |

- 결론: F1은 R2(측정 가능한 물리량) 증거를 약하게 만든다. **학교 자원이 없을 때의 마지막 수단**으로만 쓴다.
- 중간안: 알리 MAX31855 클론 + K 프로브(약 7,000원 추정)로 바꾸면 약 9,000원이 줄고 기록은 유지된다. 다만 리드타임 2–4주라 1주차 TH-1에는 기준 온도계를 써야 한다.
