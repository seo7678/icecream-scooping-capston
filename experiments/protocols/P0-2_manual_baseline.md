# Protocol P0-2 — Manual Scooping Baseline (저비용 버전)

**목적:** 적정 온도 + 최선 수공구에서 남는 작업부하(H1)와 사람 portion 편차(CV, 과다 g)를 잰다. V1 없이 1–2주 안에 할 수 있는 버전이다. 완전 계측(손잡이 모멘트, IMU)은 E1에서 한다.
**전제:** P0-7(IRB 필요 여부) 확인, 서면 동의.

## 1. 참가자

- 4–6명(가능하면 매장 경력자 1명 이상). 손·손목·어깨 부상 이력자 제외.
- 기록: 성별, 손잡이 손, 스쿠핑 경력(개월).

## 2. 장비

| 장비 | 용도 |
|---|---|
| 디지털 악력계 | MVC(3회 중 최대) |
| FSR 2–3개 + 아두이노 | 손잡이 grip(손바닥·손가락 접촉부), 사전 교정(저울 위에서 눌러 N 환산) |
| 스쿱 2종 | 매장형 표준, 열전도형(최선 수공구) |
| 저울 0.1 g, 컵 | 질량 |
| 폰 삼각대 측면 촬영(60 fps 이상) | 손목 각도, 사이클 |
| 템퍼링 냉동고, 열전대, IR | 온도 |
| 4 L 통 | 제품 |

## 3. 설계

- 요인: 스쿱 2 × 온도 2(−14, −18 °C) — 참가자 내, 순서 균형(2 × 2 Latin square)
- 조건당 연습 2회 + 측정 8회, 조건 사이 휴식 2분
- 과제: **싱글레귤러 목표 115 g 공 하나를 떠서 컵에 담기.** 매장처럼 헹굼(물컵)은 매 스쿱 후.

## 4. 절차

1. 동의 → 악력계 MVC 3회(1분 간격) → 최대값 기록.
2. FSR 착용 스쿱 확인(영점).
3. 조건 시작: 통 온도 기록 → 큐 신호 → 스쿠핑 → 컵을 저울에 → 질량 기록 → 헹굼.
4. 8회 후 Borg CR-10 자각 부하 기록.
5. 기록 템플릿: `experiments/templates/manual_baseline.csv`

## 5. 산출

| 지표 | 계산 |
|---|---|
| peak grip %MVC | FSR peak(N) ÷ MVC |
| 손목 굴곡/신전 범위 | 영상에서 손등–전완 각(Kinovea) |
| 부하 상태 손목 회전 수 | 영상 계수 |
| 사이클타임 | 큐 → 컵 |
| mass mean, SD, CV | 조건별 |
| 과다 g | mass − 115 |

## 6. 판정 (G0의 일부)

−14 °C, 최선 스쿱에서 peak grip < 20 %MVC → **G0 실패 후보**(P0-3에서 F < 40 N이면 확정: 기계 개발 중단, 측정연구로 전환).

## 7. 한계

FSR은 ±25 % 수준 오차가 흔하다 → **조건 간 상대 비교**에만 쓰고, 절대값은 E1의 교정된 계측 스쿱으로 확정한다.
