# Protocol P0-3 / E0 — Drag Force Test (스쿱 절삭력 첫 실측)

**목적:** 적정 디핑 온도에서 스쿱이 일정 깊이로 끌릴 때의 힘 F를 잰다. 이 값이 결정 게이트 G1과 모든 사이징(calc/)의 입력이다.
**범위:** drag 구간만(pitch 고정 θ = 0). dive·closing은 V1에서 잰다.

## 1. 장치

```
        푸시풀 게이지 ◀── 손으로 일정 속도로 당김(메트로놈)
             │
   ══════[캐리지]══════════   ← 리니어 슬라이드, 통 위를 가로지르는 브리지(알루미늄 바/합판)
             ┃ 수직 봉 + 깊이 칼라(스페이서 15/20/25 mm)
             ◖ 스쿱(rim 평면 수직, 개구부가 당기는 방향)
   ─────────────── 표면
   ▓▓▓▓▓▓ 4 L 통 (판에 클램프 고정) ▓▓▓▓▓▓
```

- 푸시풀 게이지 500 N급(peak hold, 가능하면 USB 로깅), 슬라이드 스트로크 ≥ 250 mm
- 스쿱: 매장과 같은 모델(P0-4), 손잡이 제거 후 봉에 고정(식품 시험품은 폐기하므로 PoC 고정 허용)
- 템퍼링 냉동고(설정 온도 ± 1 °C), 열전대(코어 5 cm, 표면 5 mm), IR 온도계

## 2. 요인

| 요인 | 수준 |
|---|---|
| 온도(코어) | −10, −14, −18 °C |
| 깊이 d | 15, 20, 25 mm |
| 제품 | 보통 바닐라류 1, 단단한 맛(초콜릿·저당 등) 1 |
| 반복 | 5 |
| (부가) 속도 | −14 °C·20 mm에서 20 / 50 / 100 mm/s 각 5회 → n 추정 |

총 90 + 15 stroke. 4 L 통 1개당 ~15–19 stroke(가정) → 통 6–7개.

## 3. 절차

1. 통을 목표 온도로 ≥ 24 h 평형(P0-5에서 확인한 시간). 코어·표면 온도 기록.
2. 냉동고에서 꺼내 판에 클램프(시험 창 시작 — 타이머). **시험 창 ≤ 3분**, 넘으면 다시 넣어 재평형.
3. 표면 평탄화(필요 시 첫 줄을 버리는 stroke).
4. 스쿱을 내려 rim이 표면에 닿는 점을 0으로(종이 한 장 끼워 걸림 확인) → 칼라로 d만큼 추가 하강·고정.
5. 게이지 영점 → 메트로놈(50 mm/s = 1초에 5 cm 눈금)에 맞춰 통 끝까지 한 번에 당김.
6. 기록: F_peak, F_mean(로깅 시), stroke 길이, 표면 온도(직후), 볼 안 chip 질량, 파괴모드(curl / 부서짐 / 걸림) + 사진.
7. 다음 stroke는 옆 줄(겹치지 않게). 순서는 깊이 무작위.
8. 템플릿: `experiments/templates/drag_force_test.csv`

## 4. 분석

- u = F_mean / A(d) [kPa] — A(d)는 `calc/scoop_model.py`의 `swept_area_mm2(0, R − d, R)` (R은 실측값)
- 온도별 u 평균과 95 % CI, 제품 간 차이
- n = 기울기 of ln F vs ln v (속도 부가 시험)
- chip 질량 / (A·L·ρ) → packing factor k_p 초벌 추정

## 5. 판정 (G1)

| −14 °C, d = 20 mm 평균 F | 판정 |
|---|---|
| < 60 N | **C(무동력 접지) 우선**, 동력 A는 보류 |
| 60–200 N | A·B 진행 |
| > 200 N | 온도관리가 전제조건. 장치 운용범위 재정의 |

결과를 `calc/scoop_model.py`의 `U_CASES_KPA`, `RATE_EXPONENT_CASES`에 반영하고 `calc/` 스크립트를 모두 다시 실행한다.

## 6. 안전·위생

- 시험 아이스크림은 먹지 않는다. 폐기.
- 게이지 최대 하중을 넘기지 않는다(걸리면 즉시 멈춤).
- 냉동 통 취급 시 장갑.

## 7. Cartesian 구조용 추가 요인 (2026-09)

현재 기준안(`docs/final_system_concept.md`)은 공격 자세 θ_s = −30°(개구부 앞-아래)로 드래그한다. 이 자세의 힘은 아직 아무도 재지 않았으므로, 같은 장치에 아래 요인을 추가한다.

| 요인 | 수준 |
|---|---|
| 공격 자세 θ_s | 0°(기존), −30°(기준안) — 봉 끝 피벗 블록을 30° 기울인 것으로 교체 |
| 깊이 d | 20, 25, 28 mm (통 벽 때문에 1 portion에 24–29 mm 필요, `calc/output/tub_lane_planner.md`) |
| 온도 | −14 °C |
| 제품 | 2 |
| 반복 | 5 |

- 총 2 × 3 × 2 × 5 = 60 stroke(통 4개 안팎).
- **수직력 F_z:** 통을 주방 저울(≥ 15 kg, 0.5 g 이상 분해능이면 충분) 위에 클램프해서 드래그 중 표시값 변화를 영상으로 기록한다. 끌어내리는 힘(스쿱이 파고듦)인지 밀어 올리는 힘인지가 Z축 사이징(`calc/output/z_axis_sizing.md`)의 입력이다.
- 산출: θ_s별 u, F_z/F_x, chip 모양(curl / 부서짐), 볼 안 chip 질량.

**Cartesian 게이트 C-Gate 0 (`docs/final_system_concept.md` §7):**

| −14 °C, θ_s = −30°, d = 25 mm 평균 F_x | 구조 결정 |
|---|---|
| ≤ 100 N | 설계 하중을 100 N으로 낮춤. 알루미늄 중형 구성(M, 100 N에서 ~1.1 mm)도 허용 |
| 100–200 N | 강관 구성(S30, 200 N에서 ~1.0 mm) 그대로 |
| > 200 N | F_TARGET 110 N을 지키면 한 stroke가 얕아진다(u = 250 kPa이면 d ≈ 12 mm, ~57 cm³). 1 portion = 작은 공 2–3개를 따로 배출(스쿱마다 컵 왕복, 기계 사이클 약 2–3배). 공격 자세를 −30°로 둔 채 부분 공을 담고 다시 절입하는 방식은 공이 빠질 수 있어 쓰지 않는다. 템퍼링 온도(−12 °C) 운영을 전제로 재검토 |
